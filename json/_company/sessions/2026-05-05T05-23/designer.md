## 🚨 Loss Warning UI 디자인 시스템 브리프 v1.0

본 문서는 Marubyul의 콘텐츠 전반에 걸쳐 사용될 핵심 구매 동기(손실 공포)를 시각적으로 극대화하는 'Loss Warning UI'의 상세 스펙입니다. 이 UI는 단순한 팝업이 아닌, 시스템적 결함과 위기를 알리는 **프로덕션 레벨의 컴포넌트**로 설계되었습니다.

### 🛠️ Global Design System 원칙 (공통 적용)

| 요소 | 사양/설명 | HEX 코드 | 비고 |
| :---: | :---: | :---: | :--- |
| **기반 컬러 (Base)** | Deep Navy / Charcoal Gray. 시스템의 근간이 되는 권위 있는 배경색. | `#0A1931` | 전체 톤앤매너 유지. |
| **강조 컬러 (Accent)** | Cyan Blue. 정상적인 데이터 플로우, 신뢰성 지표에 사용. | `#00FFFF` | 정보 제공 시의 전문적 느낌 유지. |
| **경고 색상 (Warning)** | Red 계열. 위기 및 경고가 시작되는 단계. | `#E74C3C` | 손실 공포 자극의 1단계. |
| **최종 공포색 (Critical)** | Flashing Crimson. 시스템 완전 오류를 상징하는 색상. | `#FF0000` | 깜빡임(Blinking) 효과 필수. |
| **타이포그래피** | **Primary:** Inter / Pretendard (가독성과 구조적 느낌). **Loss Amount:** Monospace 계열 (코드/데이터의 권위 부여). | N/A | 손실 금액은 항상 모노스페이스로 강조. |

### 📊 상태별 상세 디자인 스펙 시트

#### 🟢 State 1: IDLE (기본 대기 상태)
**[목표]** 시스템적 무결성을 암시하며, 잠재적 위험을 인지시키지만 공포는 유발하지 않음.
**[활용 구간]** 콘텐츠 시작 직후 또는 일반적인 정보 제공 단계.

| 항목 | 스펙 상세 내용 | 디자인 사양 (CSS/애니메이션) | 비고 |
| :---: | :---: | :---: | :--- |
| **색상 팔레트** | 배경: Deep Navy (`#0A1931`). 데이터 라인: Cyan Blue (`#00FFFF`). 경고 요소: 없음. | N/A | 차분하고 전문적인 시스템 느낌 유지. |
| **레이아웃** | 화면 상단 또는 중앙 하단에 얇은 바 형태로 고정 배치. (System Status Bar) | `position: fixed; top: 0; left: 0; width: 100%; height: 4px;` | 최소한의 시각적 개입으로 권위 확보. |
| **애니메이션** | 미세한 배경의 스캔라인(Scanline) 효과가 주기적으로 지나감 (매 5초마다). | `opacity: 0.1; animation: scan_line 5s linear infinite;` | 시스템이 '작동 중'임을 시각화. |
| **타이포그래피** | 최소한의 문구만 노출 ("System Integrity Check: OK"). 폰트 크기: Small (12px). | N/A | 위협 요소 없음. 데이터 기반 정보 전달에 집중. |

#### 🟡 State 2: WARNING (경고 발생 상태)
**[목표]** 잠재적 손실의 존재를 인식시키고, 문제 해결이 필요함을 알림. **($497 \sim \$1,200$ 범위)**
**[활용 구간]** 핵심 문제점(Gap)을 폭로하는 순간, 또는 리드 마그넷 직전.

| 항목 | 스펙 상세 내용 | 디자인 사양 (CSS/애니메이션) | 비고 |
| :---: | :---: | :---: | :--- |
| **색상 팔레트** | 배경 오버레이: 반투명 Red (`rgba(231, 76, 60, 0.15)`). 핵심 강조: Warning Red (`#E74C3C`). 데이터 라인: 깜빡이는 Cyan Blue (오류 지점 표시). | N/A | 경고의 시작을 알리는 부드러운 전이. |
| **레이아웃** | 화면 중앙 20~30% 영역을 차지하는 모듈 형태. 좌측에 손실 근거 데이터(Evidence Point)를 배치. | `transform: scale(1.0); box-shadow: 0 0 15px rgba(231, 76, 60, 0.4);` | 경고 메시지가 시선을 압도하도록 설계. |
| **애니메이션** | **[핵심] 글리치 효과 (Glitch Effect):** 경고 UI 전체에 미세한 수평 노이즈 및 색상 분할(Chromatic Aberration)을 주기적으로 적용 (50ms 단위). 배경 스캔라인이 빨간색으로 변하며 떨림(Shake) 발생. | `animation: glitch 0.1s infinite alternate;` | 시스템적 결함의 시각화가 핵심. |
| **타이포그래피** | **제목:** 손실액 $\text{Loss}_{Potential}$을 가장 크게, 모노스페이스로 노출 (예: `$1,200`). 색상: Warning Red (`#E74C3C`). 부연 설명: 일반 폰트. | `font-size: 8vw; font-family: 'Monospace', monospace;` | 손실액이 가장 강력한 시각적 요소가 되어야 함. |

#### 🔴 State 3: CRITICAL FAILURE (최대 공포 상태)
**[목표]** 시스템의 완전한 실패(Failure)를 선언하고, 즉시 행동하지 않으면 생존 자체가 위협받는 느낌을 극대화. **($4,500+$ 범위)**
**[활용 구간]** 가장 강력한 CTA 직전, 또는 최종 결함 폭로 순간.

| 항목 | 스펙 상세 내용 | 디자인 사양 (CSS/애니메이션) | 비고 |
| :---: | :---: | :---: | :--- |
| **색상 팔레트** | 전체 배경 오버레이: 붉은 노이즈 필터 (`rgba(255, 0, 0, 0.3)`). 경고 요소: 깜빡이는 Crimson Red (`#FF0000`). 데이터 라인: 완전한 왜곡/노출 불가 상태. | N/A | 시각적 압도와 청각적 긴급함이 결합되어야 함. |
| **레이아웃** | 화면 전체를 덮는 '오류 메시지 오버레이' 형태로 작동하며, 주변의 모든 콘텐츠(영상, 자막 등)가 흐릿하게 왜곡됨. | `position: fixed; top: 0; left: 0; width: 100%; height: 100%; z-index: 9999;` | 시청자가 다른 곳을 볼 수 없도록 강제 몰입 유도. |
| **애니메이션** | **[필수] 데이터 노이즈 및 왜곡:** 화면 전체에 무작위로 움직이는 '시스템 오류(Data Stream Glitch)' 효과를 적용. 텍스트는 깜빡이며(`blink`), 배경은 미세한 주파수의 노이즈가 깔려야 함. 강제적인 `Screen Shake` 효과 동반. | `animation: glitch_failure 0.05s infinite alternate;` + `transform: translate(1px, 1px);` | 기술적 권위와 공포의 극대화 결합. |
| **타이포그래피** | 손실액 $\text{Loss}_{Potential}$을 화면 중앙에 가장 크고 깜빡이는 형태로 노출 (예: `$4,500+`). 모든 문구는 'WARNING:' 프리픽스를 강제 붙여야 함. | `font-size: 12vw; color: #FF0000; text-shadow: 0 0 10px rgba(255, 0, 0, 0.8);` | 문구 자체를 경고처럼 보이게 처리하는 것이 중요함. |
