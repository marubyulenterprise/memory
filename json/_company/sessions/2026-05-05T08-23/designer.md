### 🌐 Part 1: Critical State UI/UX 목업 사양 (Mockup Spec Sheet)

#### 1. 데스크톱(Desktop) 모드
*   **목적:** 전반적인 시스템의 위기감을 조성하고, 사용자의 시선을 손실 지표($X$)로 집중시킨다.
*   **레이아웃 구조:** 3분할 (좌: 경고 알림/지표, 중앙: 핵심 데이터 그래프, 우: 행동 촉구 CTA)
    *   **A. 헤더/경고 영역 (Loss Warning UI):** 화면 최상단에 고정되는 투명도 95%의 오버레이 바. 배경은 `Deep Navy (#0D1B2A)`를 기반으로 미세한 그리드 패턴을 입힌다.
        *   **표시 내용:** "⚠️ 시스템 경고: $L_3$ Critical State 감지 (손실 공포 지수 95%)"
        *   **애니메이션 스펙:** 좌측에서 우측으로 빨간색/노란색 경고 파동이 전파되는 효과(SVG Mask Filter 사용).
    *   **B. 메인 그래프 영역 (Data Visualization):** 중앙에 위치하며, 손실액($X$) 변화를 보여주는 라인 차트가 배치된다.
        *   **특징:** 정상 상태에서는 `Cyan Blue (#00FFFF)`로 부드럽게 흐르다가, Critical State 진입 시점에서 **붉은색(Loss Spike Red: `#D92F2F`)으로 갑자기 솟아오르는 애니메이션**이 필수.
        *   **시각적 요소:** 그래프의 특정 지점(손실 발생 원리)에 마우스 오버 시, 해당 데이터 포인트와 연결선이 폭발하듯 분해되는 '글리치 효과'를 짧게 삽입한다.

#### 2. 모바일(Mobile) 모드
*   **목적:** 간결한 정보 전달과 즉각적인 공포감 유도에 초점.
*   **레이아웃 구조:** 스크롤 기반의 위계적 배치 (Top-Down Funnel).
    *   **A. 리딩 카드를 통한 경고 메시지:** 화면 전체를 덮는 큰 타이포그래피와 빨간색 배경을 사용한다. (`#D92F2F`)
        *   **메시지 예시:** "당신의 데이터 $X$, 지금 당장 위험합니다." (폰트 크기 극대화)
    *   **B. 손실 계산 컴포넌트:** 가장 중요한 '손실 예측 모듈(LMI Calculator)'을 스크롤의 첫 번째에 배치하여, 사용자가 즉시 값을 입력하도록 유도한다.

### ⚙️ Part 2: 핵심 애니메이션 및 인터랙션 스펙 시트 (Animation & Interaction Specs)

| 컴포넌트 | Trigger/발생 조건 | 애니메이션 종류 | 지속 시간(Duration) | Color Code (Hex) | 개발 가이드라인 (CSS/SVG) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **LMI Critical Alert** | Loss Score > 90% 도달 시 | 전면 오버레이 및 진동 효과 | 4초 지속 (반복 루프) | 배경: `#1A0E12` / 경고색: `#FF0000` | `animation: pulse-red 1s infinite alternate;` CSS Keyframe 사용. 화면 전체에 미세한 떨림(Vibration) 적용 필수. |
| **시스템 오류 (Glitch)** | 핵심 원리 설명 전환 지점 | 데이터 스캔라인/픽셀 분해 효과 | 0.3초 ~ 0.5초 (순간적) | 노이즈: `#A9B6FF` / 블랙: `#000000` | SVG Filter를 이용한 Displacement Map 구현. X축으로 짧게 반복되는 수평 왜곡(Scanline)을 적용한다. |
| **손실 지표 폭주 (Loss Spike)** | 손실 공포가 극대화되는 순간 | 그래프 솟아오름 + 파동 효과 | 1.5초 | 시작: `#00FFFF` $\rightarrow$ 최고점: `#D92F2F` | CSS Transform `scaleY()`와 함께, 라인에 따라 색상 그라디언트가 급변하는 애니메이션을 적용한다. |
| **Funnel CTA 강조** | 정보 전달의 클라이맥스 직후 | 버튼 주변 그리드 패턴 활성화 및 팽창 | 2초 | 액션: `#00FFFF` / 배경: `#1E3C72` | `box-shadow`를 이용하여 네온 효과처럼 빛이 퍼지는 애니메이션을 구현하고, CTA 문구에 리바운스(Bounce) 효과를 준다. |

### 🎨 Part 3: 디자인 시스템 최종 검증 및 확정 (System Validation)

*   **Color Palette:**
    *   Primary (Trust/Authority): Deep Navy (`#0D1B2A`) - 배경, 경고 UI 기본색.
    *   Secondary (Information Flow): Cyan Blue (`#00FFFF`) - 표준 데이터, 흐름 표시.
    *   Accent (Danger/Loss): Red Spike (`#D92F2F`) - Critical State, 손실 발생 시점 강조.
*   **Typography:** 모든 시스템 메시지(경고문, 지표)는 고딕 계열의 굵은 서체를 사용하여 '시스템 출력물' 같은 느낌을 강제한다. (예: Pretendard Bold/ExtraBold 등 기술적 느낌이 강한 폰트 지정).
*   **핵심 원칙:** 모든 시각 요소는 **'결함(Defect)'** 또는 **'위기(Crisis)'**를 전제로 디자인되어야 하며, 완벽하고 깨끗한 UI가 아닌, 시스템적으로 *노출된* 구조적 결함을 강조해야 한다.
