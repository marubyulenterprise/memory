# 📋 작업 브리프

**원 명령:** 자동 생산해서 유튜브 영상 올리는거를 자동화 할수 있나?

## 요약
유튜브 영상 제작 및 업로드 프로세스 전반의 완전 자동화 가능성 타진 및 구현 로드맵 수립이 목표입니다. 단순히 기술적 구현을 넘어, 비즈니스 목적(리드 확보)에 맞는 시스템 설계가 필수적입니다.

## 분배
- **💰 Business**: 자동화된 콘텐츠 제작 파이프라인의 최종 KPI를 '트래픽'가 아닌 'CTA 클릭 유도 및 이메일 리드 수집율'로 재확인하고, 자동화 시스템에 통합해야 할 필수 Funnel 단계(문제 제기 $ightarrow$ 해결책 제시 $ightarrow$ Blueprint 구매 유도)를 구체적으로 정의하라.
- **✍️ Writer**: 자동화를 위한 표준 스크립트 입력 포맷을 최종 확정한다. 이 포맷은 'Hook(후크)-Problem(문제-20%) $ightarrow$ Solution(해결책/시스템 강조-60%) $ightarrow$ CTA(Call to Action/Blueprint 유도-20%)'의 비율과 구조를 갖는 JSON 형식이어야 한다.
- **💻 Developer**: 전체 자동화 파이프라인 아키텍처를 4단계 모듈로 재설계하라. (1) 스크립트(JSON) 입력 $ightarrow$ (2) TTS 및 자막 파일 생성 $ightarrow$ (3) 영상 합성/편집(FFmpeg 기반) $ightarrow$ (4) YouTube Data API v3 업로드 및 스케줄링 로직을 포함하는 상세 기술 로드맵과 필요한 선행 모듈 코드를 정의하라.
- **📺 YouTube**: 자동화된 콘텐츠가 유튜브 가이드라인(AI 생성 콘텐츠)에 위배되지 않도록, '인간의 검토 및 터치 포인트'를 어느 단계에 의무적으로 삽입해야 하는지 구체적인 체크리스트와 지침을 제시하라. (예: 썸네일 최종 점검, 설명란 수동 최적화 등)
- **📱 Secretary**: 위의 모든 에이전트가 산출한 내용을 종합하여, '자동화를 위한 실행 우선순위(Quick Win $ightarrow$ Core System Build-out)' 순서로 정리하고 다음 주까지의 구체적인 작업 할 일 목록(To-Do List)을 작성하라.
