# 📈 시스템적 결함 폭로 기반 A/B 테스트 변수 정의서

이번 지시는 Funnel 전체의 전환율(CVR)을 극대화하기 위한 핵심 심리 트리거를 정량적으로 검증하는 것을 목표로 합니다. 모든 변수는 가설 수립에 초점을 맞췄으며, 개발팀에 전달할 수 있는 구체적인 텍스트와 로직으로 정의합니다.

## I. 긴급성 타이머 (Urgency Timer) A/B 테스트 가설

긴급성은 단순한 시간 감소가 아니라 **'지금 행동하지 않았을 때의 손실(Loss)'**과 연동되어야 합니다. 다음 세 가지 메커니즘에 대해 분리된 테스트를 진행해야 합니다.

| 변수 그룹 | A (기준/Baseline) | B (손실 기반 Trigger) | C (행동 지연 연동 Decay) | KPI 및 측정 목표 |
| :--- | :--- | :--- | :--- | :--- |
| **가설 명칭** | 단순 시간 경과 카운트다운 (24시간 남음 등) | **손실 폭발형 타이머:** '최대 혜택 상실' 강조. | **관심도 지연 Decay Timer:** 사용자 활동(스크롤, 체류 시간)이 없을 때만 감소율 증가. | $\text{Time}_{\text{Gap}}$ 유지 시간이 늘어나고, CTA 클릭률이 증가하는 그룹 확인. |
| **시작 시점** | LP 진입 즉시 (상단 고정 배너 또는 헤드라인 근처) | 리드 마그넷 다운로드 직후, 혹은 시스템 결함(Gap) 폭로가 최고조에 달했을 때. | 사용자가 페이지 내에서 10초 이상 활동을 멈춘 시점 (Behavioral Pause Detection). | **변수:** $T_{\text{Start}}$ |
| **감소율/메커니즘** | 선형 감소 (Linear Decay): 일정하게 줄어듦. | 비선형적(Exponential) 감소: 특정 임계점을 넘으면 급격히 줄어들며 위기감을 극대화. | 활동 감지 시 멈춤, 5초 이상 공백 발생 시 감소율이 2배로 가속됨 (Penalty System). | **변수:** $\text{Rate}_{\text{Decay}}$ |
| **시각적 연출** | 단순 카운트다운 숫자와 배경색 변화. | `[경고]` 문구 삽입 및 빨간색/깜빡임 효과를 활용한 시각적 압박. ("이 기회는 *당신*의 시스템에 치명적인 결함입니다.") | 타이머 주변에 '활동 감지 중...' 상태 표시기를 넣어 사용자가 스스로 행동할 동기를 부여. | **측정:** 페이지 이탈률, CTA 클릭 지연 시간. |

## II. 잠재적 비용 측정 (Pain Point Costing) A/B 테스트 가설

단순히 "문제를 해결하세요"가 아니라, "**이대로 놔두면 당신에게 어떤 손해(Cost)가 발생하는지**"를 수치화하여 공포감을 극대화해야 합니다. 가장 효과적인 제시 단계는 **'시스템적 결함 폭로 직후'**입니다. (사용자가 문제의 심각성을 처음 인지하는 순간).

### 1. 비용 유형 정의 및 Copy Set (실행 가능한 문구)

| Cost Type | 설명 (무엇을 측정할 것인가?) | A/B Test Copy Option Set (선택지) |
| :--- | :--- | :--- |
| **시간 비용** (Time Loss) | 무지를 유지하는 데 소비되는 비가역적 시간. | **Option 1:** "현재의 방식으로는 연간 최소 400시간의 불필요한 학습 및 오류 수정에 매몰될 위험이 있습니다."<br>**Option 2:** "결함을 파악하는 순간에도, 당신은 이미 3주 분량의 핵심 기회를 놓치고 있습니다. (Opportunity Cost)" |
| **금전 비용** (Financial Loss) | 직접적으로 손해 보는 자원(돈). | **Option 1:** "이 시스템적 결함을 해결하지 못할 경우, 최소 $\text{X}$원의 추가 지출로 이어지는 것이 통계적으로 확인되었습니다."<br>**Option 2:** "(직접적 언급 회피): 이 간극을 메우기 위한 시간/자원 투입 비용은 현재 책정된 예산을 초과하고 있습니다." |
| **권위/신뢰 비용** (Credibility Loss) | 잘못된 지식으로 인해 발생할 수 있는 사회적 손실. | **Option 1:** "진짜 전문가들은 이 결함을 인지하는 것만으로도 이미 절반의 신뢰도를 잃고 시작합니다."<br>**Option 2:** "가장 위험한 것은 '안전하다'는 착각입니다. 잘못된 방법론은 당신의 전문성을 퇴보시킵니다." |

### 2. Funnel 단계별 최적 제시 시점 및 로직 정의

| Funnel 단계 | 핵심 심리 상태 | Costing 적용 목표 | 최적 CTA/배치 위치 |
| :--- | :--- | :--- | :--- |
| **1단계: 문제 제기 (Gap Discovery)** | 불안감, 의문 발생. ("뭔가 잘못됐어?") | **시간 비용**과 **권위 비용**을 결합하여 위협 수준 높이기. | 시스템 다이어그램 폭로 후의 첫 팝업/배너. (최초 인지 시점) |
| **2단계: 해결책 탐색 (Consideration)** | 필요성 인식, 대안 모색. ("어떻게 해야 하지?") | **금전 비용**을 활용하여 '비용 대비 효익'의 차이 강조. | 저가형 미끼 상품(워크시트) 페이지 내, 아쉬움을 자극하는 영역. |
| **3단계: 구매 결정 (Final CTA)** | 결핍 극대화, 행동 필요성 최고조. ("지금 안 사면 큰일 나겠다.") | 모든 비용 유형을 총집합하여 '지연에 따른 누적 손실'로 제시. | 최종 랜딩 페이지 하단 CTA 직전의 밴너 또는 카운트다운 타이머 옆. |

***

**[요약 실행 가이드]**
1.  **개발팀:** Urgency Timer는 단순 시간이 아닌, **'활동 중지 시간(Inactive Time)'에 연동된 비선형적 감소율($\text{Rate}_{\text{Decay}}$)** 로 구현할 것.
2.  **카피라이팅:** 모든 콘텐츠에서 '시스템적 결함 폭로 $\to$ 손실 측정 (Costing) $\to$ 해결책 제시'의 흐름을 의무화한다.
