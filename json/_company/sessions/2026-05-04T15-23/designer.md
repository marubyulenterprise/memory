## 🏗️ Marubyul 표준 에셋 키트 V2.0 최종 사양서 (Master Asset Kit Specification)

**목표:** 모든 콘텐츠 채널(YouTube, 블로그, 인스타 카루셀 등)에 통합 적용 가능한 '시스템적 권위'를 극대화하는 표준 비주얼 자산 패키지를 확정합니다. 이 가이드는 개발/디자인팀에게 전달할 **최종 구현 사양서**입니다.

---

### 🟣 [Asset 1] Misconception Alert (오해 경고)
*   **활용 목적:** 시청자나 독자가 가진 일반적이고 잘못된 통념(Misconception)을 구조적으로 인식시키며, 본 콘텐츠가 제시하는 원리 기반의 권위를 선점합니다.
*   **톤앤매너:** 긴급성, 경고, 명확한 오류 지점 식별. (Deep Navy/Cyan Blue 대비 사용)

| 구분 | 사양 상세 | 기술 스펙 및 애니메이션 가이드라인 |
| :--- | :--- | :--- |
| **배경 박스** | 직사각형 강조 박스 (Corner Radius 8px 권장) | `Background Color`: `#0A1931` (Deep Navy, Hex Code). `Border Color`: `#4DFFFF` (Cyan Blue, Hex Code). |
| **텍스트** | "🚨 오해 경고" + 핵심 Misconception 문구 | `Font-Family`: Pretendard Bold. `Text Color`: `#FFFFFF`. |
| **애니메이션** | 1. **등장 효과:** 박스 전체가 좌측에서 미끄러지듯(Slide-in) 나타나며, 경고 아이콘(`🚨`)은 번개 모양 애니메이션과 함께 깜빡임(Blink)으로 등장합니다. (0.5초) <br> 2. **텍스트 강조:** "오해 경고" 문구가 타이핑 효과(Typewriter Effect)로 서서히 나타나며, 핵심 단어는 `Cyan Blue`가 짧게 플래시됩니다. |
| **사용 규칙** | *반드시* 콘텐츠의 도입부 또는 주제 전환 직후 배치하여 시청자의 주의를 강제적으로 집중시키고, 다음 내용에 대한 기대감을 조성합니다. |

### 🌐 [Asset 2] System Flow Diagram Placeholder (시스템 흐름 다이어그램)
*   **활용 목적:** 추상적인 개념이나 복잡한 프로세스(Mini Checklist $\rightarrow$ Worksheet $\rightarrow$ Blueprint)를 시각적 시스템 아키텍처 관점에서 구조화하여 제시합니다.
*   **톤앤매너:** 논리적, 연결성, 고도화된 기술력. (그리드 패턴과 선형 흐름 강조)

| 구분 | 사양 상세 | 기술 스펙 및 애니메이션 가이드라인 |
| :--- | :--- | :--- |
| **플로우 박스** | 각 단계별 노드를 표현하는 직사각형/타원 형태의 컴포넌트. | `Primary Color`: `#1E3A8A` (Deep Navy). `Highlight Color`: `#4DFFFF` (Cyan Blue, 선택적 강조). |
| **연결선 (Connection Line)** | 플로우의 방향성과 논리적 연결을 보여주는 곡선 또는 직선 벡터 요소. | `Line Color`: `#1E3A8A` (Deep Navy). `Stroke Width`: 3px. <br> *핵심 경로*는 Cyan Blue (`#4DFFFF`)로 오버레이되어야 합니다. |
| **애니메이션** | 1. **진행 순서:** 플로우가 시작되면 가장 첫 번째 노드부터 순차적으로(Staggered) 등장합니다. (0.2초 간격). <br> 2. **연결선 애니메이션:** 각 노드가 나타날 때, 이전 노드와 현재 노드를 연결하는 선이 마치 전기가 흐르는 것처럼 (`Path Drawing` 효과) 부드럽게 그려지며(Draw-on), 플로우를 따라 이동합니다. (0.4초) |
| **사용 규칙** | 모든 '원리 제시' 콘텐츠의 핵심 구조물로 사용하며, 각 박스 내부에는 반드시 간결한 아이콘과 1줄 요약 설명이 병기되어야 합니다. |

### ✨ [Asset 3] Funnel CTA Visual Break (전환 유도 브레이크)
*   **활용 목적:** 콘텐츠 시청의 절정(클라이맥스/원리 제시 완료) 직후, 다음 단계로 넘어갈 구조적 필요성(Blueprint 구매)을 극대화하며 자연스럽게 행동을 유도합니다.
*   **톤앤매너:** 전환점, 가치 증명, 강력한 행동 촉구 (시스템 완성 느낌).

| 구분 | 사양 상세 | 기술 스펙 및 애니메이션 가이드라인 |
| :--- | :--- | :--- |
| **레이아웃** | 중앙 정렬된 3단 구조 (문제 인식 $\rightarrow$ 해결책 제시 $\rightarrow$ 최종 액션) | 배경: 깊은 블랙에 미세한 그리드 패턴 오버레이. |
| **메시지 계층** | 1. "만약 이 원리를 직접 구현하려면?" (질문/Pain Point) <br> 2. "Marubyul의 [Blueprint]가 그 간극을 메웁니다." (해결책 제시) <br> 3. "**지금 다운로드하여 시스템을 완성하세요.**" (CTA 명확화) |
| **애니메이션** | 1. **브레이크 효과:** 화면 전체에 미세한 노이즈/글리치(Glitch) 효과가 짧게 발생하며 시청자의 주의를 리셋시킵니다. (0.1초). <br> 2. **CTA 강조:** 'Blueprint' 단어와 다운로드 버튼은 Cyan Blue 색상으로 강력하게 빛나며(Glow Effect), 마치 시스템이 최종적으로 완료되는 듯한 느낌을 주며 중앙에서 팝업됩니다. <br> 3. **버튼 액션:** 클릭 유도 버튼(`CTA`)은 마우스 오버 시 그리드 패턴의 전기가 흐르는 것처럼 미세하게 반짝이는 효과를 추가합니다. |
| **사용 규칙** | 영상/블로그 포스팅의 **마지막 10~20초 구간**에 의무적으로 배치되어야 합니다. 이 자산 자체가 콘텐츠의 '결론'이자 다음 단계로 가는 '다리' 역할을 해야 합니다. |
