| 요소 | 목적/기능 | 색상 코드 (HEX) | 적용 범위 |
| :--- | :--- | :--- | :--- |
| **Primary Accent** | 핵심 행동 유도(CTA 버튼 배경) | `#007bff` (Cyan Blue) | Hover, Active 상태의 주 색상. 활력과 기술적 신뢰감 부여. |

### ✨ II. 마이크로 인터랙션 및 애니메이션 스펙 (필수 적용)

모든 CTA 모듈은 다음의 3가지 이상의 미세한 애니메이션 효과를 통합하여 *살아있는* 느낌을 주어야 합니다.

1. **Hover Effect: Subtle Lift & Glow:**
    *   **스펙:** 마우스 포인터가 버튼 위에 올라가는 순간, 버튼 전체가 Y축으로 2px 상승(TranslateY(-2px))하고, 모서리 주변에 `#007bff`의 은은한 박스 그림자(Box-Shadow: 0 4px 15px rgba(0, 123, 255, 0.4))가 점멸하듯 나타납니다.
    *   **지속 시간:** 0.2초 (Ease-in/out).

2. **Active Effect: Hydraulic Compression:**
    *   **스펙:** 클릭 다운(mousedown)하는 순간, 버튼이 Y축으로 1px 하강하고 너비와 높이가 각각 98%로 수축하며, 색상이 일시적으로 `#0056b3` (Darker Blue)로 깊어집니다.
    *   **지속 시간:** 0.1초 (즉각적인 피드백).

3. **Loading/Success State: Data Flow Animation:**
    *   **스펙:** 클릭 성공 후, 버튼 내부의 텍스트가 순간적으로 *데이터 로딩(Data Streaming)*처럼 좌우로 흐르는 시각적 애니메이션을 보여주며 '다운로드 시작' 또는 '리드 확보 완료' 메시지로 전환됩니다. (실제 로딩 바 대신, 데이터 플로우를 연상시키는 미세한 선/점의 이동).

### 📦 III. CTA 모듈 디자인 변형 및 상태별 스펙

사용되는 콘텐츠 맥락(Context)에 따라 세 가지 유형의 버튼을 정의합니다.

#### 🅰️ 타입 A: [Standard Authority Button] - (가장 일반적, 모든 페이지 기본 적용)
*   **목표:** 신뢰를 바탕으로 즉각적인 액션을 유도.
*   **레이아웃:** 직사각형, 모서리 라운딩(8px). 중앙 정렬.
*   **텍스트 예시:** "시스템 블루프린트 받기 (무료)"

| 상태 | 배경색/배경 패턴 | 텍스트 색상 | 인터랙션 스펙 |
| :--- | :--- | :--- | :--- |
| **Default** | `#007bff` (Cyan Blue) | `white` | 미세한 그라디언트(Linear Gradient: #008fff to #0056b3). |
| **Hover** | (위의 Lift/Glow 적용) | `white` | 배경색이 10% 밝아지며, Glow 효과 발현. |
| **Click** | `#0056b3` | `white` | Hydraulic Compression 및 데이터 로딩 애니메이션 시작. |

#### 🅱️ 타입 B: [Urgency Timer Module] - (결핍감 극대화, 중반부 배치 권장)
*   **목표:** 시간적 희소성(Scarcity)을 이용해 구매 결정 지연 방지.
*   **레이아웃:** 버튼 주변에 타이머 컴포넌트가 결합된 직사각형 모듈.
*   **텍스트 예시:** "남은 기회: ⏰ [02일 14시간] 즉시 다운로드"

| 상태 | 배경색/배경 패턴 | 핵심 요소 및 애니메이션 스펙 | 주의 사항 |
| :--- | :--- | :--- | :--- |
| **Default** | `#ffcc00` (Amber) - 경고성 색상 | `Deep Navy` | 타이머가 1초마다 카운트다운하는 시각적 피드백 필수. |
| **Hover** | `#ffbb33` (Darker Amber) | 위 Lift/Glow 적용. | 시간이 곧 사라진다는 느낌을 강조하도록 애니메이션 속도를 빠르게 설정. |
| **Timer End** | `#cc0000` (Error Red) | "기회 마감! 놓치지 마세요." | 타이머가 0이 되는 순간, 배경 전체에 경고 메시지가 오버레이됨. |

#### 🇨️ 타입 C: [System Diagnostic CTA] - (최종 결제 직전/권위적 분위기 조성)
*   **목표:** 구매를 '결정'이 아닌 '시스템의 다음 단계 진입'으로 포지셔닝. 가장 전문적인 느낌.
*   **레이아웃:** 단순한 버튼 형태가 아닌, 작은 패널(Pill shape) 형태에 시스템 다이어그램 연결점처럼 배치.
*   **텍스트 예시:** "▶️ Blueprint를 통해 시스템적 결함 진단 시작"

| 상태 | 배경색/배경 패턴 | 인터랙션 스펙 | 효과 (Effect) |
| :--- | :--- | :--- | :--- |
| **Default** | `transparent` (투명) | `#003d7e` (Deep Navy) | 테두리(Border): 2px Solid `#007bff`. 마치 전선 연결점 같은 느낌. |
| **Hover** | 배경이 미세하게 채워지기 시작함 (`rgba(0, 123, 255, 0.1)`). | 위 Lift/Glow 적용. | 버튼 주변에 Cyan Blue의 그리드 패턴이 아주 빠르게 깜빡이며 시선 집중 유도 (Micro-detail). |
| **Click** | `#007bff` 배경으로 전환. | 데이터 로딩 애니메이션 후, CTA가 다음 Funnel 단계로 부드럽게 스크롤 이동하는 효과 연동 필수. |
