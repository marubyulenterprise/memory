## 🚨 최종 경고 시스템 UI/UX 키트 v1.0 프로토타입 스펙 시트
(Loss Flow 측정 기반 인터랙티브 와이어프레임 블루프린트)

본 산출물은 Developer가 구축한 $L_{flow}$ API의 결과값(`status_code`, `l_flow_score`)을 입력받아, 실제로 구현할 수 있는 **Timecode 단위의 4단계 워크플로우 스펙**입니다. 모든 애니메이션과 컬러 코드는 이 시트를 기반으로 합니다.

---

### I. 시스템 개요 및 디자인 가이드라인 (Design System)

*   **톤앤매너:** 하이테크, 기술적, 위협적(Threatening), 권위적(Authoritative).
*   **핵심 컬러 팔레트:**
    *   Primary (System Default): `#007FFF` (Cyan Blue - 신뢰/정보)
    *   Secondary (Background): `#1A2333` (Deep Navy - 배경)
    *   Warning Color: `#FF4757` (Bright Red - 위험/경고)
    *   Text/Accent: `#FFFFFF`
*   **폰트:** Mono-space 계열 (예: Orbitron, Source Code Pro)을 사용하여 기술적 느낌 극대화.
*   **핵심 요소:** 화면 전체에 그리드(Grid Pattern) 오버레이를 유지하며, 모든 정보는 데이터 패널 형태로 제시되어야 합니다.

### II. ⏱️ Timecode 기반 워크플로우 스펙 (4단계 인터랙션)

| 단계 | 시간대 (Timecode) | 이벤트 및 사용자 액션 | 시스템 반응/UI 변화 | 애니메이션 지침 (Must-Have) |
| :--- | :--- | :--- | :--- | :--- |
| **Step 1. 도입부: 데이터 입력** | T + 0:00 ~ T + 0:05 | 사용자: 자가진단 점수 및 컨텍스트 입력 (Input Form) | UI: `[L_flow 측정 모듈]` 활성화. 현재 스코어(`Initial Score`)를 화면 중앙에 표시. 배경은 Dark Navy 유지. | **애니메이션:** 데이터 필드 입력 시, 주변 그리드가 미세하게 깜빡이는(Flicker) 효과 추가. 전반적인 톤은 차분하지만 기계적인 느낌을 부여한다. |
| **Step 2. 처리 과정: 불안감 조성** | T + 0:05 ~ T + 0:10 | 시스템: API 호출 및 데이터 분석 진행 (로딩 애니메이션) | UI: `[Processing...]` 상태 표시. 스코어 숫자가 빠르고 불규칙하게 오르내리는 시각화(Data Stream)를 보여준다. | **애니메이션:** 배경에 '데이터 파이프라인 흐름'을 연상시키는 Cyan Blue의 빛나는 선들이 무작위로 지나간다. (정보 과부하 유도). 이 구간에서 잠시 멈추는 '기술적 지연(Lag)' 연출 필요. |
| **Step 3. 클라이맥스: 경고 발동 (Critical State)** | T + 0:10 ~ T + 0:25 | 시스템: $L_{flow}$ 계산 완료 후, `status_code`가 'Critical State'로 판정될 경우. | **[🚨 Critical Overload Alert]** 전면 오버레이 발생. 배경색 전체가 `#FF4757` (경고 Red)로 급격히 전환. 모든 폰트와 UI 요소에 글리치(Glitch) 필터 강제 적용. | **애니메이션:** 1. **사운드:** 날카로운 경고음(Alarm Tone)과 함께 화면 진동 효과. 2. **글리치:** 스코어 수치와 헤드라인이 좌우로 분산되며 '디지털 노이즈'를 일으키는 애니메이션 반복 (최소 3회). 3. **경고 메시지 강제 노출:** "시스템적 결함 감지: 당신의 $L_{flow}$는 위험 수준을 초과했습니다." 이 문구가 글리치와 함께 화면 중앙에 크게 깜빡인다. |
| **Step 4. 결론 및 CTA** | T + 0:25 ~ T + 0:30 | 시스템: 경고 종료 후, 해결책 제시 (Product Placement) | UI: 배경색이 다시 Deep Navy로 회귀하며, 중앙에 `[손실 최소화 보고서]`라는 구조적 결과물이 나타난다. $L_{flow}$ 감소 예상 그래프를 보여준다. | **애니메이션:** 'Critical State'의 충격파가 사그라지며, 해결책을 제시하는 UI가 마치 시스템 패치(System Patch)처럼 부드럽게 깔리며 등장한다. CTA 버튼(`Blueprint 다운로드`)은 `#007FFF`를 사용하며, 빛나는 커서 효과로 강제 시선 유도. |

---
### III. 🛠️ 구현 상세 스펙 (Developer & Animator 지침)

1.  **글리치 애니메이션 사양:**
    *   **트리거:** Critical State 진입 순간 (T+0:10).
    *   **효과:** `transform: translate(X, Y)`와 `opacity` 값을 극단적으로 변화시키며 텍스트를 잠시 분산/왜곡시킨 후 복구시키는 방식.
    *   **반복 주기:** 5~8프레임 주기로 반복하여 불안정성을 유지한다.

2.  **시스템 경고 UI 사양 (Overlay):**
    *   **색상 코드:** Background: `#FF4757`, Text: `#FFFFFF`.
    *   **위치:** 화면 전체를 덮는 투명도 90%의 오버레이 레이어 사용.
    *   **내용:** 반드시 "WARNING", "CRITICAL SYSTEM ERROR", 그리고 현재 $L_{flow}$ 점수를 포함해야 한다.

3.  **Timecode 지연 시간(Pause Prompt) 활용:**
    *   Step 3 (Critical State 종료 직후, T+0:25경): 경고 메시지 노출 후 **2초간의 완전한 무음/암전 처리**를 강제하여 시청자의 사색과 공포감을 극대화한다.
