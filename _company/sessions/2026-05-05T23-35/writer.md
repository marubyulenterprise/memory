# 🎬 ASV 경고 스크립트 초안 (총 5편)
*(각 스크립트는 약 40~60초 분량으로 예상됩니다.)*

## 1. [오류 1] ‘프롬프트 = 제어’라는 환상 (The Prompt Fallacy)
**주제:** 단순히 명령하는 것으로는 시스템을 통제할 수 없다.
| 시간대 | 내용 (화자: 권위적, 경고성 톤) | 비주얼/사운드 연출 지침 |
| :--- | :--- | :--- |
| **[0-5초] 후킹** | "AI에 아무리 길고 정교한 프롬프트를 넣어도, 결과물이 완벽할 거라고 믿으시나요? 잠깐 멈추세요. 지금 당신의 방식은 근본적인 착각일 수 있습니다." | 잔잔한 시작 $\to$ 갑자기 노이즈(Glitch) 효과 발생하며 화면 일시정지. (RED 경고 UI 오버레이). |
| **[5-25초] 문제 제기** | "대부분의 초보자들은 복잡한 결과물을 얻으려면 '명령어'가 충분히 길어야 한다고 착각합니다. 하지만 AI는 명령을 따르는 기계가 아닙니다. 그것은 확률에 기반해 텍스트를 생성하는 예측 엔진일 뿐입니다." | 데이터 흐름도(Pipeline) 다이어그램이 빠르게 지나감. '지시(Instruction)'와 '확률(Probability)'이라는 단어에 글리치 강조. |
| **[25-40초] ASV 유발/CTA** | "논리적 빈틈 하나, 데이터 구조의 결함 하나가 시스템 전체를 무너뜨립니다. 프롬프트만으로는 이 근본적인 '시스템 아키텍처'의 오류를 절대 잡을 수 없습니다. 당신의 자동화 파이프라인에 숨겨진 **결함을 진단**해야 합니다." | 화면 전체가 빨간색 경고 모드(Critical State)로 전환. 타이포그래피에 깜빡임 효과 의무 적용. |
| **[40-60초] 마무리 CTA** | "당신의 시스템이 정말 작동 가능한지, 불안정하지 않은지? 지금 바로 [Marubyul ASV 진단]을 받아보십시오. 이것만이 통제 불능의 위험에서 탈출할 유일한 길입니다." | 화면에 'ASV Diagnosis Required' 문구 고정 노출. (강력하고 권위적인 폰트). |

## 2. [오류 2] 데이터 입력 = 자동화 완료 (The Data Dumping Error)
**주제:** 데이터를 넣는 것 자체가 해결책이 아니다. 구조화가 핵심이다.
| 시간대 | 내용 (화자: 전문적, 비판적 톤) | 비주얼/사운드 연출 지침 |
| :--- | :--- | :--- |
| **[0-5초] 후킹** | "수백 개의 데이터를 모았고, 이제 AI에 '붙여넣기'만 하면 모든 게 해결될 거라 기대하십니까? 그 기대를 당장 멈추세요." | 넘쳐나는 데이터(이미지/텍스트 Blob)를 카메라가 비춤. 마치 폐기물처럼 느껴지게 연출. |
| **[5-25초] 문제 제기** | "우리는 데이터를 '정보의 덩어리'로만 인식합니다. 하지만 시스템이 요구하는 것은 '형태(Schema)'입니다. 구조화되지 않은 데이터는 AI에게 노이즈일 뿐, 중요한 변수 간의 관계성, 즉 '숨겨진 결함 패턴'을 읽어낼 수 없습니다." | 비정형 텍스트가 쌓여있다가 갑자기 깨지는 애니메이션 효과. 스키마(Schema)를 나타내는 명확한 격자무늬 그래픽 등장. |
| **[25-40초] ASV 유발/CTA** | "분석 결과가 표면적인 통계에 그친다면, 그것은 진단이 아닙니다. 막대한 기회비용을 놓치게 만드는 근본 원인(Root Cause)의 결함을 무시하는 것과 같습니다. 시스템적 관점에서 데이터 자체를 재설계해야 합니다." | 그래프들이 엉켜서 의미 없이 움직이는 애니메이션 $\to$ 갑자기 빨간색 X표 표시. |
| **[40-60초] 마무리 CTA** | "당신의 데이터를 단순한 자료가 아닌, 강력한 '시스템 자산'으로 만들려면? 지금 당장 전문적인 [데이터 구조 진단(ASV)]이 필요합니다." | 화면에 'Schema Mapping Required' 문구와 함께 결함 경고 UI 노출. |

## 3. [오류 3] 도구 독립적 사용 (The Silo Thinking Error)
**주제:** 도구를 파편적으로 쓰는 것은 물리적인 단절을 의미한다. 연결이 핵심이다.
| 시간대 | 내용 (화자: 기술적, 명료한 톤) | 비주얼/사운드 연출 지침 |
| :--- | :--- | :--- |
| **[0-5초] 후킹** | "AI 도구, Zapier, 외부 API... 각각의 기능을 개별적으로 활용하고 계신가요? 잠깐만요. 그건 시스템이 아닙니다." | 여러 개의 독립된 블록(도구 아이콘)들이 화면에 분리되어 떠다니는 모습 연출. |
| **[5-25초] 문제 제기** | "실제 자동화 시스템은 파편적인 조합이 아니라, 하나의 연속된 '파이프라인'입니다. 한 도구가 내보내는 최종 출력물(Output)을 다음 도구의 새로운 입력값(Input)으로 재해석하는 이 연결 고리, 즉 Integration Layer를 무시하는 것이 가장 큰 결함입니다." | 블록들 사이의 끊어진 선(Broken Link)이 강조되고, 그 자리에 녹색/빨간색 경고 UI가 깜빡임. |
| **[25-40초] ASV 유발/CTA** | "이 단절은 물리적인 시스템 오류입니다. 데이터가 다음 단계로 넘어가는 과정에서 정보의 손실이나 오역이 발생합니다. 이 결함을 눈으로 직접 확인하지 못하면, 당신의 자동화는 언제든 멈출 수 있습니다." | 파이프라인 다이어그램에 끊어지는 부분이 빨간색 전기 스파크처럼 연출됨. |
| **[40-60초] 마무리 CTA** | "도구들이 제대로 연결되어 하나의 거대한 시스템으로 작동하는지, 그 '통합 아키텍처'의 결함을 진단해야 합니다. 지금 바로 [시스템 연결성 ASV 점검]을 받으세요." | 화면에 'Integration Gap Alert' 문구와 함께 강력한 CTA 노출. |

## 4. [오류 4] (가상 오류) ‘결과물 = 최종 목표’라는 환상
**주제:** 결과물 자체에 만족하지 않고, '왜' 이 과정이 필요한지 물어야 한다.
| 시간대 | 내용 (화자: 통찰력 있는, 사색 유발 톤) | 비주얼/사운드 연출 지침 |
| :--- | :--- | :--- |
| **[0-5초] 후킹** | "자동화 시스템을 구축하는 목적이 '결과물' 그 자체에만 머물러 있지는 않습니까? 만약 지금 당신의 목표가 오직 결과물이라면, 이미 치명적인 함정에 빠진 겁니다." | 아름답게 완성된 자동화 대시보드 화면(Mockup)이 비치지만, 어딘지 모르게 공허함. |
| **[5-25초] 문제 제기** | "우리는 시스템 구축을 '문제 해결'로만 생각합니다. 하지만 본질은 문제입니다. 이 과정을 통해 우리가 진정으로 포착해야 할 것은, 외부의 문제가 아니라 우리 시스템 자체에 내재된 '구조적 결함(Structural Flaw)'입니다." | 질문 부호(?)와 오류 코드 같은 글자가 화면 전체를 덮으며 불안감을 조성. |
| **[25-40초] ASV 유발/CTA** | "결과가 좋았다고 안심하는 순간, 시스템은 다시 무너집니다. '왜 이 과정이 필요한지'에 대한 근본적인 질문 없이는, 아무리 좋은 결과도 일회성 이벤트에 그칩니다. 우리는 결함의 원리를 찾아야 합니다." | 웅장한 배경음악이 갑자기 끊기며, 고주파 노이즈(High Pitch Noise)만 남김. |
| **[40-60초] 마무리 CTA** | "단순히 성공적인 결과를 얻는 것을 넘어, 당신의 시스템을 영구적으로 안정화시키는 방법. 저희가 그 근본 원리를 진단해 드립니다. [시스템적 결함 분석(ASV)]이 필수입니다." | 'Root Cause Analysis'라는 문구를 강조하며 권위적인 톤으로 마무리. |

## 5. [오류 5] (가상 오류) ‘지식 축적이 곧 힘’이라는 오만
**주제:** 지식을 쌓는 것보다, 지식을 시스템에 녹여내는 능력이 중요하다.
| 시간대 | 내용 (화자: 경고적, 패러다임 전환 유도 톤) | 비주얼/사운드 연출 지침 |
| :--- | :--- | :--- |
| **[0-5초] 후킹** | "가장 많이 공부하고, 가장 많은 '지식'을 축적했다고 자부하는 분들. 지금 그 자신감이 당신의 시스템에 치명적인 결함을 만들고 있습니다." | 책이나 자료들이 쌓여있는 거대한 서재/사무실 이미지가 등장하지만, 그 위에 붉은 경고등이 깜빡임. |
| **[5-25초] 문제 제기** | "지식 자체가 힘인 시대가 아닙니다. 문제는 '정보를 어떻게 시스템적 구조로 변환하여 작동하게 만드는가'입니다. 방대한 지식을 그냥 보유만 하는 것은, 무거운 데이터 더미에 불과합니다." | 뇌의 뉴런 연결망(Network) 이미지가 복잡하고 혼란스럽게 연출됨. (지식 = 노이즈). |
| **[25-40초] ASV 유발/CTA** | "진짜 문제는 '정보 과부하'입니다. 지식을 파이프라인에 맞춰 구조적으로 결합시키고, 작동하는 시스템으로 재구성하지 못하면, 아무리 똑똑한 사람도 오류를 피할 수 없습니다." | 복잡하게 얽힌 실타래가 풀리지 않는 애니메이션 $\to$ 강제로 한 방향으로 정리되는 과정(시스템화)을 보여줌. |
| **[40-60초] 마무리 CTA** | "지식의 양이 아닌, 지식을 '통제하는 구조'를 판매해야 합니다. 당신의 무한한 지적 자산에 결함 없는 시스템 아키텍처를 이식하세요. [시스템 재설계 ASV 진단]을 받으십시오." | 'Structure is Power' 등의 문구를 강력하게 제시하며, 권위적인 마무리 톤 유지. |
