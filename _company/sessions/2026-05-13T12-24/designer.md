### 🛠️ 필수 애니메이션 에셋 라이브러리 V3.0 스펙 시트
**(Figma/Lottie Export 준비 완료)**

#### 1. [Asset 1] 크리티컬 경고 타이머 (Critical Warning Timer)
*   **목표:** 사용자가 무심코 지나치는 '안전한 정보' 구간에 갑작스러운 긴급성을 주입한다. 시간 제한을 통해 공포와 불안감을 조성하는 것이 핵심이다.
*   **구성 요소:**
    1.  `[Timer Display]` (숫자 카운트다운, 24시간 포맷)
    2.  `[Warning Bar]` (배경색 변화를 통한 시각적 긴장감)
    3.  `[System Message Box]` (결함 유도 문구 표시 영역)
*   **상호작용 로직 (Critical Path):**
    1.  **Start State (T=0s):** `Warning Bar`가 옅은 주황색(`Hex: #FFB800`)으로 나타나며, 타이머는 '시간 미정' 또는 '데이터 검증 대기 중...' 문구와 함께 느리게 카운트다운 시작.
    2.  **Interruption Point (T=3s):** `System Message Box`가 화면 상단 중앙에서 **갑자기 플립인(Flip-In)** 되며, 배경 사운드 톤이 급격히 낮고 낮은 주파수의 경고음으로 전환됨. 문구: "경고: 시스템 구조적 결함 감지 (Error Code: DATA_GAP_0x4B)"
    3.  **Escalation Point (T=5s~):** `Warning Bar`의 색상이 점진적으로 주황색 $\rightarrow$ 빨간색(`Hex: #FF2D2D`)으로 변하며, 타이머가 틱(Tick)하는 사운드와 함께 숫자가 급격히 빠르게 카운트다운됨. **(핵심 로직)**
    4.  **End State (T=0s):** 경고창 전체가 화면을 뒤덮으며 "접근 금지. 즉시 진단 장치 확인 필요."라는 문구와 함께 애니메이션 정지.

#### 2. [Asset 2] 데이터 노이즈 오버레이 필터 (Data Noise Overlay Filter)
*   **목표:** 시각적 혼란(Visual Disorientation)을 주어, 시청자가 본 내용 자체에 대한 신뢰도를 의심하게 만든다. 정보가 깨지거나 오류난 것처럼 보이게 한다.
*   **구성 요소:**
    1.  `[Chromatic Aberration Layer]` (색상 분리 효과)
    2.  `[Static/Scanline Pattern]` (TV 노이즈 및 스캔라인 패턴)
    3.  `[Glitch Code Overlay]` (랜덤하게 깜빡이는 헥사 코드 문자열)
*   **상호작용 로직 (Interruption & Ambiguity):**
    1.  **Start State:** 애니메이션 시작 시, 모든 콘텐츠 위에 매우 약한(Opacity 5%) 스캔라인 패턴이 주기적으로 움직이며 깔림. 이는 배경처럼 보이게 하여 인지하지 못하게 한다.
    2.  **Trigger Event (Focus Loss/Confusion):** 화면에 전문 용어($E_d$ 관련 키워드)가 언급되는 순간, 필터의 Opacity가 급격히 증가(Opacity 40% 이상). 동시에 `Chromatic Aberration` 효과를 강하게 적용하여 이미지의 경계선이 빨강-청록색으로 분리되어 보인다.
    3.  **Peak Noise State:** 노이즈 패턴과 글리치 코드가 무작위로 깜빡이며 배경 전체가 '데이터 패킷 손상'된 것처럼 보이게 함 (깜빡임 주기: 100ms ~ 200ms). 이 상태는 시청자가 **정보의 완전성을 의심**하도록 유도하며, 마치 화면 자체가 고장 난 것 같은 느낌을 준다.
    4.  **Recovery:** 필터가 갑자기 사라지면서(Fade Out) 깨끗한 화면으로 돌아오지만, 동시에 "처리 오류 발생"이라는 작은 팝업 메시지가 좌측 하단에 짧게 나타나며 위기감을 남긴다.

#### 3. [Asset 3] 시스템 강제 알림창 (Forced System Alert Pop-up)
*   **목표:** 시청자가 가장 편안하고 '안심'했다고 느끼는 순간(예: 해결책 제시 직후, 요약 정리 단계), 화면 위에 외부에서 강제로 메시지를 띄워 위기감을 조성한다.
*   **구성 요소:**
    1.  `[Alert Box]` (중앙 정렬의 경고창 프레임)
    2.  `[Lock/Warning Icon]` (심각성을 나타내는 아이콘)
    3.  `[Actionable Code Field]` (사용자가 무언가를 입력해야 할 것 같은 느낌을 주는 필드)
*   **상호작용 로직 (Cognitive Dissonance Trigger):**
    1.  **Initial State:** 일반적인 콘텐츠 진행 중, 배경에 미세한 펄스(Pulse Effect)가 주기적으로 감지되지만 무시할 수 있는 수준으로 유지된다.
    2.  **Interruption Timing:** 내용 전달의 성공적 결론 직후 (예: "따라서 해결책은 A입니다."라는 문장 끝), 화면이 잠시 어두워지고, 중앙에 `Alert Box`가 **강제적으로 팝업(Modal Pop-up)** 된다.
    3.  **Message Display:** 경고창 제목: "**[SYSTEM ALERT] 접근 권한 위반 의심 감지 (Level 3)**". 본문은 "현재 제공된 정보만으로는 구조적 결함을 완전히 파악할 수 없습니다. 추가 진단이 필수입니다."와 같은 문구로 구성.
    4.  **Action Flow:** 경고창 하단에 `[진단 코드 입력 필드]`를 배치하고, '확인' 버튼을 누르기 전에 **'결함 보고서 제출 (Submit Defect Report)'** 라는 텍스트 링크를 노출하여 다음 단계(CTA)로 자연스럽게 유도한다.
