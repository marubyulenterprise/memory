### 🚀 1. [인스타그램용] 권위 확립형 카루셀 (7장 구성)

**📌 목표:** 사용자에게 '현재의 지식으로는 부족하다'는 결핍감을 느끼게 하고, 시스템적 접근 방식만이 해결책임을 설득합니다.
**🎨 디자인 가이드:** 각 페이지마다 경고 UI(#cc0000 강조)를 사용하고, Marubyul의 로고와 톤앤매너(Deep Navy/Cyan Blue)를 일관되게 적용해야 합니다.

#### **[카루셀 구조 및 카피]**

**👉 Slide 1: (HOOK / 경고)**
*   **제목:** 🚨 AI에게 데이터를 '그냥' 던지는 건, 사상누각입니다.
*   **본문:** 자료를 많이 붙여넣는다고 해서 마법처럼 완벽한 결과물이 나오지 않습니다. 당신의 데이터 주입 방식에 치명적인 결함이 있습니다. (Swipe 👉)
*   **핵심 메시지:** 양(Quantity) ≠ 질(Quality). 원리적 접근이 필수입니다.

**👉 Slide 2: (MISCONCEPTION ALERT / 오해 제시)**
*   **제목:** [오류 지점 #1] 데이터 '양'에만 의존하는 착각
*   **본문:** "관련 자료를 모아 넣기만 하면 AI가 맥락을 알아줄 거야." 라고 생각하셨나요? ❌ 아닙니다. AI는 쓰레기를 아무리 많이 주입해도, 구조화되지 않은 데이터에서 통찰력을 뽑지 못합니다.
*   **원리적 결함:** **맥락적 필터링 부재.** 어떤 데이터를 *왜*, *어떻게* 가중치를 부여해야 하는지 설계 능력이 부족하기 때문입니다.

**👉 Slide 3: (PRINCIPLE / 해결 원리 제시)**
*   **제목:** ✅ 진짜 AI 전문가의 데이터 아키텍처 방식
*   **본문:** 성공적인 프롬프트는 '데이터 더미'가 아닙니다. [1] **선별 기준 정의** $\to$ [2] **관계성 매핑** $\to$ [3] **출력 역할 할당** 이라는 3단계 필터링 과정을 거쳐야 합니다.
*   **시각화:** 데이터 요소 간의 연결 고리(Relationship)를 화살표나 다이어그램으로 보여줍니다.

**👉 Slide 4: (MISCONCEPTION ALERT / 오해 제시)**
*   **제목:** [오류 지점 #2] '블록 단위'로만 생각하는 오류
*   **본문:** "이 데이터를 넣고, 저 데이터도 넣어줘." → 이렇게 독립적인 사실들만 나열하고 결과물만 요청하면 안 됩니다. 🧱 이들은 서로 연결되어야 의미를 갖습니다.
*   **원리적 결함:** **구조화 및 계층성 결여.** 데이터 간의 상호작용(Interaction)이나 우선순위(Hierarchy)가 없으면 AI는 혼란에 빠집니다.

**👉 Slide 5: (PRINCIPLE / 해결 원리 제시)**
*   **제목:** ✅ 시스템적 사고로 데이터를 구조화하는 법
*   **본문:** 모든 데이터 요소에 **[A $\to$ B] 관계 정의**가 필요합니다. '이것이 저것의 전제 조건이다', '이 프로세스가 다음 단계에 영향을 준다'와 같이 논리적 연결점을 명시해야 합니다.
*   **실행 가이드:** 데이터를 단순 나열 대신, 순서도(Flowchart)나 역할 분담 매트릭스로 제시하세요.

**👉 Slide 6: (MISCONCEPTION ALERT / 오해 제시)**
*   **제목:** [오류 지점 #3] '답'만 요구하는 게으름
*   **본문:** 데이터를 넣고 "최종 보고서 작성해 줘"라고 명령하는 순간, 당신은 AI가 생각할 기회까지 막는 겁니다. 답을 요구하기 전에 스스로 검토하게 만들어야 합니다.
*   **원리적 결함:** **사고 과정(Thinking Process) 생략.** 논리적 타당성을 스스로 검증하거나, 특정 관점에서 오류를 찾아내도록 강제하는 루틴이 없습니다.

**👉 Slide 7: (CTA / 최종 전환)**
*   **제목:** 🔥 이 모든 '시스템 결함'을 한 번에 잡는 법은?
*   **본문:** 단순히 이론만으로는 부족합니다. 데이터 전처리부터 결과물 검증까지, **Marubyul이 설계한 표준 아키텍처**가 필요합니다. 우리의 [블루프린트]를 통해 당신의 AI 시스템을 완벽하게 구축하세요.
*   **CTA 버튼:** 🔗 프로필 링크에서 '시스템 청사진' 다운로드 받기 (선착순 한정)

### 📽️ 2. [유튜브 쇼츠용] 스크립트 초안 (50초 분량)

**🎬 목표:** 빠른 속도감과 충격적인 메시지로 시선을 잡고, '시스템적 원리'를 핵심 권위 요소로 각인시킵니다.
**🎤 연출 지침:** 톤은 강하고 전문적이며, 배경 음악은 긴장감을 유지하며 점진적으로 고조되어야 합니다. 자막과 경고 UI(#cc0000) 사용을 의무화합니다.

| 시간대 | 내용 (Voice Over / V.O.) | 화면 연출/자막 가이드 |
| :---: | :--- | :--- |
| **(0-5s)** | **V.O.:** 잠깐! AI에게 데이터를 이렇게 주입하고 있진 않습니까? (갑자기 멈춤) 이건 치명적인 오류입니다. | **[후크]** 충격적 배경음악, 화면에 빨간 경고창: "🚨 DANGER ZONE" <br>자막: 당신의 프롬프트는 이미 실패했습니다. |
