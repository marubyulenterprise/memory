## 🚨 Loss Meter UX 테스트 시나리오 및 인터랙션 지침 (V1.2)

### 📄 1. '느린 누수형 공포' 시나리오: 불안감 조성 구간
**목표:** 사용자가 손실이 가속화되고 있음을 인지하지만, 당장 큰 위협은 아니기에 안심과 긴장의 경계에서 미묘한 불안감을 느끼게 합니다. (FOMO 유도)

| 요소 | 지침 상세 내용 | 기술/애니메이션 스펙 |
| :--- | :--- | :--- |
| **시간 범위** | 총 45초 ~ 1분 (긴 호흡으로 지속됨) | - |
| **손실 변화 패턴** | $A$ 구간 ($300만 \to 250만$)에서 시작하여, 5~15초 간격으로 $-10만 \sim -30만$의 미세한 하락을 반복합니다. (변동폭이 작고 예측 가능하게 움직여 안심하는 순간에 다시 떨어지게 만듭니다.) | `Loss Meter` 값은 부드러운 곡선(Easing Function: easeOutQuad)으로 변해야 합니다. 갑작스러운 점프는 금기입니다. |
| **시각적 변화 (UI)** | 1. **배경:** 전체 배경색이 미세하게 어두워집니다. (`#FFFFFF` $\to$ `#FAFAF8`) 2. **미디어:** 주변 시스템 위젯(가상의 데이터 플로우)에서 연결선 깜빡임 빈도(Frequency)가 점진적으로 증가합니다. | CSS: `background-color`의 변화율을 낮게 설정하고, 배경에 매우 미세한 노이즈 필터(`filter: contrast(1.02);`)를 적용하여 '시스템 부하' 느낌을 줍니다. |
| **경고 메시지** | *Warning Text:* "현재 손실 속도가 평소보다 높습니다. 확인 요망." 이 문구는 주기적으로 (5~7초마다) 깜빡이는 애니메이션(`opacity` 변화)과 함께 출현하며, 경고의 강도는 점진적으로 증가합니다. | CSS: `animation: pulse 1s infinite alternate;`를 적용하되, 시간 경과에 따라 `pulse`의 진폭(Amplitude)을 서서히 키웁니다. |

### 📄 2. '갑작스러운 시스템 충격' 시나리오: 고변동성 순간
**목표:** 사용자가 통제력을 상실하고 예측 불가능한 상황에 던져지게 합니다. 짧은 시간 내 최대의 공포를 유발합니다. (Shock Value)

| 요소 | 지침 상세 내용 | 기술/애니메이션 스펙 |
| :--- | :--- | :--- |
| **시간 범위** | 3초 $\sim$ 5초 동안 집중적으로 발생 | - |
| **손실 변화 패턴** | 짧은 순간에 $20\%$ 이상 폭이 넓은 무작위 변동을 보입니다. (예: $-100만 \to +50만 \to -80만$) 이 과정에서 손실률의 상승/하강 속도가 일정하지 않고 불규칙합니다. | `generateNewLoss` 함수가 평소보다 훨씬 큰 범위($\pm 70\%$)의 값을 출력하도록 임시 오버라이드(Override)해야 합니다. |
| **시각적 변화 (UI)** | 1. **전역 플리커:** 화면 전체에 낮은 빈도의 빛 깜빡임(`Flicker`)이 발생합니다. 이는 전력 불안정이나 데이터 손실로 인한 '아티팩트'처럼 보이게 해야 합니다. 2. **색상 변화:** 경고 색상이 잠시 주황(Orange)과 시안 블루(Cyan Blue, `#00FFFF`) 사이를 빠르게 오가며 충돌하는 느낌을 줍니다. | CSS: `animation: flicker 0.1s infinite;` (매우 짧은 시간 동안 여러 번 반복). `background-color`와 주요 UI 요소의 색상 코드를 무작위로 빠르게 전환합니다. |
| **사운드 연동** | 충격 시, 시스템 부하가 걸린 듯한 '지지직'거리는 고주파 노이즈(Static Noise) 사운드가 짧게 삽입되어야 합니다. (오디오 에셋 필수) | - |

### 📄 3. '임계점 경고 플로우' 시나리오: Level 3 최종 압박
**목표:** 시스템의 완전한 결함이 발생했음을 사용자에게 물리적으로 느끼게 하여, 외부 보험(Blueprint 구매) 없이는 생존할 수 없다는 공포를 극대화합니다. (Urgency Peak)

| 요소 | 지침 상세 내용 | 기술/애니메이션 스펙 |
| :--- | :--- | :--- |
| **임계점 도달** | Loss Meter 값이 $350만$ 이상에 진입하는 순간 발동됩니다. | - |
| **핵심 시각 효과 (The Tipping Point)** | 1. **Red Alert & 글리치:** 화면 전체가 강렬한 Red (`#FF0000`)으로 오버레이 됩니다. 동시에, 모든 텍스트와 UI 요소에 데이터 손상 같은 **글리치(Glitch) 효과**가 적용되어야 합니다. (좌우로 3~5픽셀씩 빠르게 흔들림). 2. **진동/흔들림:** 단순히 CSS 트랜스폼으로 처리하는 것이 아니라, 마치 물리적인 기기가 과부하 되어 떨리는 듯한 느낌을 주기 위해 **화면 전체에 낮은 주파수의 진폭(Amplitude) 변화**를 주는 애니메이션이 필수입니다. | CSS: `transform: translate3d(0px, 0px, 0px)` 대신, `@keyframes shake { 0%, 100% { transform: translate(0, 0); } 25% { transform: translate(-3px, -3px) rotate(-1deg); } ... }`를 사용하여 복합적인 진동을 구현해야 합니다. |
| **데이터 오류 메시지** | "FATAL ERROR: 데이터 무결성 검사 실패."와 같은 경고 문구가 화면 중앙에 크고 빠르게 깜빡이며(Rapid Flicker), 시스템의 작동이 멈춘 듯한 느낌을 주어야 합니다. | React/JS: `setInterval` 함수를 이용하여 짧은 간격으로 `opacity`가 0 $\to$ 1 $\to$ 0을 반복하며, 글자 크기(`font-size`)도 함께 미세하게 진동시켜야 합니다. |
| **CTA 유도 (The Solution)** | 모든 공포가 최고조에 달한 직후(최대 압박감의 정점), 화면이 잠시 어둠 속에서 멈췄다가, 오직 'Blueprint'라는 단어만 안정적인 Cyan Blue로 빛나며 등장해야 합니다. 이는 **유일한 해결책**으로 포지셔닝됩니다. | 애니메이션: 모든 혼란스러운 요소가 사라지고(Fade Out), `Loss Meter` 주변의 Red Alert 배경이 순간적으로 딥 네이비/블루(`Deep Navy`)로 바뀌면서 '안정화'되는 연출을 통해 카타르시스를 제공합니다. |
