# 🚨 Anomaly Signal V2.0: 기술 사양서 (Tech Spec Sheet)

## 1. 디자인 원칙 및 목표
*   **목표:** 단순 경고(Warning)가 아닌, **시스템의 내부 오류를 감지하는 과정(Detection Process)**을 시각화하여 전문적 권위를 확보한다.
*   **톤앤매너:** 사이언 블루/딥 네이비 그리드 시스템 기반 위협적 긴장감. Red Alert 색상 지양.
*   **핵심 메커니즘:** **데이터 왜곡(Data Distortion)**과 **불규칙한 패턴(Irregular Pattern)**을 통해 위기감을 표현한다.

## 2. 컬러 팔레트 및 타이포그래피 (Color & Typeface)
| 구분 | 코드 (Hex) | 사용 용도 | 비고 |
| :--- | :--- | :--- | :--- |
| **Primary Background** | `#0A1931` (Deep Navy) | 기본 배경, 정보 구조의 안정성 확보. | 그리드 기반의 깊은 어둠 표현. |
| **System Core Color** | `#00FFFF` (Cyan Blue) | 정상 작동 상태, 시스템 요소 연결선(Line). | 신뢰성과 첨단 기술 느낌 유지. |
| **Anomaly Alert Color** | `#FF6B6B` (Soft Red/Coral) | 임계치 초과, 위기 감지 순간의 시각적 충격 담당. | '경고'보다는 '결함 인지'에 초점. |
| **Highlight Text** | `#FFFFCC` (Off-White) | 중요 메시지 강조, 가독성 확보. |

**타이포그래피:**
*   **폰트:** Orbitron 또는 Montserrat (모든 플랫폼에서 유사한 기계적, 구조적 느낌을 주는 Sans-serif 필수).
*   **스타일링:** 모든 텍스트는 **Monospace/Digital Display** 스타일로 처리되어 시스템 로그를 보는 듯한 느낌을 강화해야 합니다.

## 3. Anomaly Signal 컴포넌트 상세 스펙 (Motion & Structure)

### A. 배경 애니메이션: 임계치 초과 시퀀스
*   **발동 조건:** Loss Index 값이 설정된 `Critical Threshold`를 돌파하는 순간 (데이터 기반).
*   **시각 효과:**
    1.  **(0.0s - 0.2s) Pre-Anomaly:** 전체 화면의 `#0A1931` 배경 위에 미세한 사이언 블루 그리드 패턴이 정상적으로 깜빡인다.
    2.  **(0.2s - 0.5s) Trigger Point:** 특정 데이터 포인트를 중심으로 **노이즈(Noise)**와 **왜곡된 글리치(Glitch Effect)**가 발생하며 화면 전체의 색감이 급격히 불안정하게 떨린다 (Anomaly Alert Color `#FF6B6B` 미세 노출).
    3.  **(0.5s - 1.0s) Stabilization/Hold:** 그리드가 일시적으로 끊어지고, 데이터 플로우가 역방향으로 흐르는(Reverse Flow) 시각적 오류가 나타나며 **'STRUCTURAL INTEGRITY FAILURE DETECTED'** 문구가 `#FF6B6B`로 깜빡인다.
*   **출력 포맷:** Lottie/After Effects (애니메이션 루프 및 트리거 포인트 지정).

### B. 경고 메시지 박스: 'Anomaly Box'
*   **용도:** 핵심 결함 문구, 위험 수치 제시 시 사용.
*   **레이아웃:** 화면 중앙 하단 또는 좌측 상단에 고정된 투명도가 높은 블랙/딥 네이비 직사각형 모듈.
*   **디자인 요소:** 박스 주변에 얇은 **빨간색 경고 테두리(Dotted Line)**가 추가되어야 하며, 내부에는 시스템 오류 메시지 형태의 코드가 배경으로 흐른다 (Subtle Scrolling Code).
*   **애니메이션:** 부드럽게 나타나기보다는, 마치 데이터 스트림이 강제로 **'인젝션(Injection)'** 되는 듯한 빠른 팝업 효과를 사용해야 합니다.

### C. 타이포그래피 강조: 'Data Breach Marker'
*   **용도:** 핵심 용어("구조적 결함", "Loss Index")가 화면에 등장할 때마다 적용.
*   **효과:** 해당 단어를 일반 폰트가 아닌, **`[ERROR CODE: XXXX]`**와 같은 시스템 로그 형식으로 순간 변환시킨 후, 원래 문장으로 돌아오는 짧은 글리치 효과를 부여한다.
