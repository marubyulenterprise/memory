### 🎯 I. 핵심 성과 지표 (KPI) 정의 및 산정식

| KPI 명 | 목표/지표 | 측정 방법론 및 공식 | 중요성 (Business Impact) |
| :--- | :--- | :--- | :--- |
| **1. $E_d$ 레벨 상승 기록 수 ($N_{E_d}$)** | 시청자/사용자가 '결함 자각'을 경험한 횟수 및 최고 도달 레벨. | **[측정 항목]** 사용자 세션 중, 경고(Level 1) $\to$ 의심(Level 2) $\to$ 와해(Level 3) 단계로 진입하여 체류 시간이 측정된 총 이벤트 횟수. / $N_{E_d} = \sum (\text{Stage Transition Events})$ | **[가장 중요]** 콘텐츠의 '불안감 주입 성공 여부'를 수치화한 핵심 지표. 높을수록 구매 전환 가능성이 높음. |
| **2. 진단 장치 접근률 (Funnel Conversion Rate, $CVR_{Funnel}$)** | 전체 유입 사용자 중, 최종 목표인 '진단 장치(MVP/Blueprint)' 페이지에 도달한 비율. | $$C V R_{F u n n e l} = \frac{\text{최종 진단 장치 접근 세션 수}}{\text{총 마케팅 접점 트래픽 수}} \times 100$$ | **[핵심 매출 지표]** 모든 콘텐츠와 캠페인의 최종 목표 달성률. 이 비율 증대가 곧 수익화의 핵심입니다. |
| **3. 단계별 결함 자각 유도율 (Defect Awareness Rate, $DAR$)** | 특정 콘텐츠/접점(A)을 거친 사용자가 다음 단계(B)에서 높은 불안감($E_d$ 레벨 상승)을 느꼈는지의 비율. | $$D A R = \frac{\text{다음 단계 진입 시 } E_d \text{ Level이 최소 1단계 이상 증가한 사용자 수}}{\text{접점 A를 거친 총 사용자 수}} \times 100$$ | **[콘텐츠 최적화 지표]** 콘텐츠가 '정보 전달'을 넘어 '불안함 증폭'이라는 본래 임무를 수행했는지 측정합니다. |

### ⚙️ II. 시스템 로깅 프로토콜 (개발팀 필수 구현 사항)

모든 사용자 액션은 다음 메타데이터 필드를 통해 반드시 기록되어야 합니다.

| 데이터 필드명 | 유형 | 설명 및 예시 값 | 로깅 목적 |
| :--- | :--- | :--- | :--- |
| **`user_id`** | String | 익명화된 사용자 고유 ID (필수). | 개인별 여정 분석. |
| **`timestamp`** | Datetime | 이벤트 발생 시간. | 시계열 변화 감지 및 패턴 파악. |
| **`source_channel`** | Enum | 유입 채널 (YouTube, Instagram Reel, Organic Search 등). | 마케팅 채널별 효율성 분석. |
| **`content_stage`** | Enum | 사용자가 현재 경험하는 콘텐츠 단계 (Hook $\to$ Misconception Alert $\to$ Principle Intro...). | 어떤 스토리텔링 지점에서 이탈이 발생하는지 추적. |
| **`ed_level_pre/post`** | Integer | 이벤트 발생 전/후의 $E_d$ 레벨 (1: 경고, 2: 의심, 3: 와해). | 불안감 상승 곡선 측정 ($N_{E_d}$ 계산 근거). |
| **`event_type`** | Enum | 사용자 행동 (Scroll Down $\to$ CTA Click $\to$ Video Pause $\to$ Exit). | 구체적인 이탈/진행 지점 파악. |
| **`cta_clicked`** | Boolean | 특정 CTA 버튼을 클릭했는지 여부 (True/False). | 직접적인 전환 시도 기록. |

### 📉 III. 단계별 이탈 지점 분석 보고서 양식 정의 (Drop-off Report Template)

이 표준화된 보고서는 마케팅, 콘텐츠, 개발 팀 간의 커뮤니케이션 허브로 사용됩니다.

**[보고서 제목] Funnel Drop-Off Analysis: [측정 기간] - [캠페인명]**

| 분석 영역 | 측정 지점 (Stage) | 예상 $E_d$ 레벨 | 주요 이탈 원인 가설 (Hypothesis) | 데이터 증거 (Metric) | 권고 수정 방향 (Action Item) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Entry** | 1. 콘텐츠 시작 $\to$ 문제 제기(Stage 1) 진입 | $E_d$: 0 $\to$ 1 | *가설:* 후크의 자극성이 부족하여 즉각적인 공포감 유발 실패. | 이탈률: X% (특정 3초 지점) / 평균 시청 시간: Y분 | **[수정]** 오프닝 사운드/글리치 빈도 및 강도를 20% 상향 조정 필요. |
| **Mid-Funnel** | 2. 원리 제시(Stage 2) $\to$ 해결책 예고(Stage 3) 진입 | $E_d$: 1 $\to$ 2 | *가설:* 핵심 개념이 너무 추상적이어서 사용자가 지루함을 느낌 (정보 과부하). | 이탈률: Z% / 페이지 스크롤 깊이: 평균 N% | **[수정]** 전문 용어 사용을 최소화하고, 비유적 예시(Analogy)를 즉각적으로 제시해야 함. |
| **Exit/CTA** | 3. 진단 장치 접근 버튼 클릭 $\to$ 최종 결제 페이지 (LP) | $E_d$: 2 $\to$ 3+ | *가설:* CTA의 긴급성 또는 가격에 대한 심리적 저항감 발생. | CVR: A% / 이탈 지점: "가격 정책" 섹션에서 급격한 감소. | **[수정]** 결제 직전 '손실 회피(Loss Aversion)'를 자극하는 문구("이대로 방치하면 1년 뒤 OO을 놓칩니다.") 추가 필요. |
