### 📦 최종 UI/UX 비주얼 시스템 패키지 (V3.0)

#### 1. 핵심 컴포넌트: Loss Meter & Critical Red Alert ($X$)
손실액 $X$의 수치화 경험을 극대화하기 위해, 타이포그래피와 애니메이션 로직에 집중했습니다.

**A. 손실액($X$) 타이포그래피 규격:**
*   **폰트 패밀리:** `Roboto Mono` 또는 시스템 모노스페이스 (기술적/데이터 기반 느낌)
*   **색상 코드:** `#D90000` (Critical Red, 딥 레드 계열의 공포감 유발 색)
*   **크기 규격:**
    *   최대값: `vw` 기준 15% 이상 (화면 가득 채우는 느낌)
    *   평상시 표시: 72px ~ 96px
*   **애니메이션 로직 (CSS/JS 필수):**
    1.  **초기 노출:** `opacity: 0`에서 `opacity: 1`로 부드럽게 등장하는 것이 아니라, **'글리치(Glitch)' 효과**를 주어 마치 시스템이 불안정하게 데이터를 불러오는 것처럼 표현합니다. (duration 0.2s)
    2.  **실시간 업데이트:** 수치가 변경될 때마다 단순 변환이 아닌, **짧은 깜빡임(Rapid Flicker)**과 함께 `scale(1.05)`로 순간적으로 줌인하는 효과를 반복 적용하여 시청자의 눈에 충격파처럼 각인되게 합니다.
    3.  **임계치 도달:** Red Alert 상태 진입 시, 손실액 $X$ 주변으로 **빨간색 노이즈 패턴 오버레이(Noise Overlay)**가 1초간 강하게 깜빡이며 전체적인 불안감을 증폭시킵니다.

**B. Critical Red Alert UI 요소 (CSS/HTML Snippet):**
```css
/* 배경 변화 */
body.alert-active {
    background: linear-gradient(rgba(179, 0, 0, 0.8), rgba(139, 0, 0, 1)); /* 그라디언트로 깊이감 부여 */
    transition: background 0.5s cubic-bezier(0.25, 0.46, 0.45, 0.94);
}

/* 경고 타이틀 애니메이션 */
.alert-header {
    animation: glitch-text 1s infinite steps(8); /* 단계별 깜빡임 구현 */
    color: #FF3333; 
    text-shadow: 0 0 5px rgba(255, 51, 51, 0.7); /* 발광 효과 추가 */
}

@keyframes glitch-text {
    /* 실제 구현 시 JS를 활용한 무작위 위치 이동 및 색상 변화가 필수적입니다. */
}
```

#### 2. 핵심 컴포넌트: ASV 기반 CTA 모듈 (Escape Hatch)
단순한 '클릭'이 아닌, '위기 탈출을 위한 필수 보험료 지불(Mandatory Necessity)'로 포지셔닝하는 대비색 CTA입니다.

**A. 디자인 원칙:**
*   공포스러운 빨간색 영역과 극명하게 분리된 색상을 사용하여 **시각적 안도감/대비효과**를 제공합니다. (Red $\leftrightarrow$ Cyan Blue)
*   버튼의 모양은 단순한 사각형이 아닌, '시스템 패치' 또는 '생존 장치 활성화' 같은 느낌을 주도록 모서리를 살짝 각지게 디자인합니다.

**B. 스펙 시트:**
*   **CTA 색상 코드:** `#00AACC` (Action Cyan Blue)
*   **보조/호버 색상:** `#007AA8` (깊이감 있는 블루)
*   **폰트:** `Inter Bold` 또는 시스템 산세리프 계열 (명확하고 즉각적인 느낌)
*   **애니메이션 로직:** 마우스 오버 시, 버튼 전체가 **'충전(Charge)'되는 듯한 전기적 효과(Electric Pulse)** 애니메이션을 주어 클릭이 단순 구매가 아닌 '시스템 활성화 행위'처럼 보이게 합니다.
