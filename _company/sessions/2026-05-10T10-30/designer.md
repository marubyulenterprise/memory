## 💻 컴포넌트 A: Loss Index 위젯 (LossIndexWidget)
사용자의 구조적 결함 누적 정도를 실시간으로 시각화하는 핵심 요소.

### 1. 데이터 바인딩 및 API 명세
*   **필수 입력 데이터:** `user_id` (string), `time_elapsed_minutes` (float, 경과 시간), `data_gap_score` (number, 누락 정보에 따른 점수).
*   **API Endpoint:** `GET /api/v2/loss-index/{user_id}`
*   **요청 파라미터 예시:** `?timestamp=YYYYMMDDHHmmss&session_key=XYZ123`
*   **응답 Payload (JSON):**
    ```json
    {
      "status": "success",
      "loss_index": 78.5,  // 최종 계산된 Loss Index 값 (0~100)
      "unit": "%",         // 단위
      "gradient_value": 0.6 // 위젯 배경에 적용될 색상 강도 (0.0 ~ 1.0)
    }
    ```

### 2. 애니메이션 및 UI 스펙 (GSAP/CSS 기준)
*   **초기 상태:** `opacity: 0`, `transform: translateY(50px)`
*   **트리거:** 컴포넌트가 로드된 후 100ms 지연 타이밍에 시작.
*   **애니메이션 시퀀스:**
    1.  **Index 수치 애니메이션:** 0부터 응답값(`loss_index`)까지 부드러운 커브(EaseOutQuad)로 **카운트업 효과** 적용 (Duration: 1s). 숫자가 올라가는 동안 `#FF3B30` 색상으로 플리커링 효과 추가.
    2.  **그래프 애니메이션:** Loss Index 값에 비례하여 배경의 컬러 그라디언트가 점진적으로 채워지며 상승하는 시각적 흐름(Flow)을 구현 (Duration: 1.5s).
    3.  **반복 로직:** `setInterval` 함수를 사용하여 최소 60초마다 API 호출 및 위의 애니메이션 재실행.

## 🚨 컴포넌트 B: Anomaly Signal 경고 모달 (AnomalySignalModal)
사용자의 인지적 공백(Context Gap)이 임계점을 넘어섰을 때 발생하는 강제 인터럽션 UI.

### 1. 트리거 조건 및 액션
*   **발동 조건:** Loss Index가 특정 임계치(`Threshold > 75`)에 도달하거나, 사용자가 지정된 핵심 콘텐츠를 일정 시간 이상 탐색하지 않을 경우 (Idle Time Out).
*   **표시 방식:** 화면 전체를 가리는 오버레이 모달 형태로 강제 표시.

### 2. 애니메이션 및 인터랙션 스펙
*   **진입 애니메이션:** 배경이 어두워지면서(Overlay: `rgba(0, 0, 0, 0.8)`) 중앙의 경고 박스가 **빠르게 '팝인'되는 효과** (Scale-up + Fade-in)를 사용.
*   **텍스트 강조 애니메이션:** 핵심 문구("결함이 감지되었습니다.", "지금 즉시 행동해야 합니다.")는 타이핑(Typewriter) 효과와 함께 순차적으로 등장하며 긴급성을 극대화.
*   **사운드 스펙 (SFX):** 경고음(Warning Siren, 0.5초 길이의 낮은 주파수 반복음)과 함께 화면 진입 시 강력한 **'시스템 알람' 사운드**를 재생해야 함.

### 3. API 바인딩 및 데이터
*   **Endpoint:** (None - 클라이언트 측 로직 트리거)
*   **표시 정보:** 경고 발생의 원인(`source: context_gap` 또는 `source: high_loss`)을 모달 하단에 작은 글씨로 표시하여 신뢰도를 높임.

## 🏗️ 컴포넌트 C: 시스템 아키텍처 플로우 다이어그램 (SystemFlowDiagram)
복잡한 원리를 시각적으로 분해하여 '시스템의 권위'를 부여하는 재사용 가능 모듈.

### 1. 구조 및 기술 스펙
*   **형태:** 그리드 패턴 기반의 벡터 연결선(SVG 필수). 모든 노드는 사각형 또는 다이아몬드 형태의 컨테이너로 구성.
*   **색상 바인딩:** 메인 흐름은 `#00BCD4` (Cyan Blue)로, '오해'나 '위험 지점'으로 빠지는 경로는 `#FF3B30`을 사용.
*   **애니메이션:** 플로우 다이어그램의 각 노드는 순차적으로 나타날 때(Sequential Load), **선이 그려지듯이 연결되는 모션 (Stroke-dashoffset)** 효과를 적용해야 함. (총 2~3초에 걸쳐 완주).

### 2. 재사용 지침
*   **Placeholder:** 다이어그램의 빈 공간은 항상 `[여기에 핵심 원리 설명]` 형태의 가이드라인을 유지하고, 이 영역이 애니메이션으로 채워지는 과정을 보여주는 것이 중요함. (빈 페이지는 공백처럼 보이게 디자인할 것).
