# ✍️ Writer — 전체 퍼널에 사용될 핵심 마이크로 카피라이팅(Micro-copywriting) 세트를 전면 재정비하십시오. '진단 보고서 접근', '손실액 측정 시작' 등 사용자가 상호작용하는 모든 버튼과 경고 메시지 텍스트가 '위협적이고 긴급한 시스템 알림'의 톤앤매너를 유지하도록 통일해야 합니다. 특히, 손실 공포(Loss Fear)를 극대화할 수 있는 문구 (예: '현재 데이터 부족으로 인한 예상 손실액 $X$ 발생')를 다양한 상황별로 최소 10개 이상 작성하십시오.

✍️ Writer: 작업 시작합니다.

## 🚨 마이크로 카피라이팅 세트 재정비 (시스템 경고/손실 공포 기반)

CEO님의 지시에 따라, 퍼널 전반에 사용될 모든 인터랙션 요소(버튼, 알림창, 경고 메시지 등)의 문구를 '위협적이고 긴급한 시스템 알림' 톤앤매너로 전면 재정비했습니다. 단순 정보 제공이 아닌, **시스템 결함 발견으로 인한 손실 공포(ASV)**를 극대화하는 것이 핵심입니다.

---

### I. [🚨 경고/알림창 (System Alert) 카피]
사용자가 콘텐츠 소비 중 '결함을 인지'했을 때 나타나는 전면적인 시스템 알림 문구 세트입니다. 빨간색 배경과 함께 노출되어야 합니다.

| 상황 | 제목 (Headline - 굵게, 큰 글씨) | 본문 메시지 (Body Copy - 위협적 어조) |
| :--- | :--- | :--- |
| **1. 데이터 부족 감지** | **[CRITICAL ALERT: DATA DEFICIENCY DETECTED]** | 현재 사용하시는 정보는 검증되지 않은 레벨입니다. 이 구조적 결함으로 인해 예상 손실액이 $X$만큼 발생했습니다. 즉시 진단이 필요합니다. |
| **2. 시간 경과에 따른 손실** | **[WARNING: TIME-BASED DEGRADATION IN PROGRESS]** | 시스템 로그 분석 결과, 해당 프로세스를 방치할 경우 분당 평균 $Y$의 자원/시간 손실이 예상됩니다. 중단 프로토콜을 적용하십시오. |
| **3. 오해 기반 위험 경고 (ASV)** | **[PROTOCOL VIOLATION: MISCONCEPTION RISK LEVEL]** | 현재 접근한 정보는 AI 자동화 시스템 아키텍처의 근본 원리를 오인하고 있습니다. 이 오류를 방치할 경우, 전체 파이프라인가 가동 중단될 수 있습니다. |
| **4. 핵심 기능 부재 경고** | **[SYSTEM FAILURE: CORE LOGIC MISSING]** | 현재 단계에서 필수적인 '손실 측정(Loss Meter)' 로직이 누락되어 있습니다. 이는 곧 예측 불가능한 규모의 손해로 직결됩니다. 진단 모듈 접근을 권장합니다. |
| **5. 행동 유도 경고 (강제성)** | **[ACTION REQUIRED: MITIGATION IS MANDATORY]** | 임시 방편으로는 해결되지 않습니다. 시스템적 결함을 해소하고 리스크를 최소화하기 위해, 전문적인 검증 절차(진단 보고서)가 필수입니다. |

### II. [💾 손실 공포 극대화 문구 (Loss Fear Triggers)]
이 메시지들은 다양한 시점(예: Loss Meter 업데이트 구간, 챕터 전환 지점 등)에서 사용자에게 '무언가를 놓치고 있다'는 느낌을 주기 위해 사용되어야 합니다.

1. **[손실 측정 시작]** "경고: 현재 데이터셋의 불완전성으로 인한 잠재적 손실액 $X$가 실시간으로 계산되고 있습니다."
2. **[검증 필요성 강조]** "이 정보만으로는 70%의 리스크가 커버되지 않습니다. 나머지 30%는 진단 시스템을 통해 확인해야 합니다."
3. **[지연 비용 경고]** "지금 바로 검토하지 않을 경우, 예상되는 시간당 손실액은 $Y$로 급증합니다."
4. **[시스템의 권위 강조]** "우리의 분석 결과에 따르면, 일반적인 방법으로는 이 결함을 감지할 수 없습니다. 고도화된 시스템 아키텍처가 필요합니다."
5. **[결론 유도]** "이 모든 오류는 결국 '구조적 무지'에서 비롯됩니다. 진단 보고서로 근본 원인을 파악하십시오."
6. **[마지막 경고]** "경고: 이 페이지를 벗어나는 순간, 손실액 측정은 중단되지 않습니다. 다음 단계가 필요합니다."

### III. [🖱️ CTA/버튼 카피 (Call to Action)]
사용자가 선택할 여지를 없애고 '생존을 위한 필수 행동'처럼 느껴지게 강제하는 버튼 문구입니다.

| 기존 개념 | 위기감 극대화 톤앤매너 (최종) | 비활성화 상태 메시지 |
| :--- | :--- | :--- |
| 진단 보고서 접근 | **🚨 [긴급] 손실 리스크 진단 보고서 열람하기** | 시스템 결함이 감지되었습니다. 분석을 진행하십시오. |
| 다음 단계로 이동 | **[필수] 위기 관리 프로토콜 실행 (Next Step)** | 전제 조건(진단) 미충족: 이 버튼은 비활성화됩니다. |
| 더 알아보기 | **[경고 레벨 상승] 상세 결함 분석 모듈 접근** | 현재 정보로는 충분하지 않습니다. 전문적인 검증이 필요합니다. |
