### 📐 [핵심 컴포넌트별 상세 기술 사양]

#### 1. 타이머 기반 경고 메시지 (Timer-based Warning Message: `ComponentA`)
*   **위기감 역할:** 시간이 제한된 '결함 보고'의 긴급성과 법적 강제성 부여.
*   **기술 구현 요소:** Lottie JSON (또는 SVG 애니메이션) + JavaScript Timer API.
*   **필수 로직 스펙:**
    1.  **초기 상태:** 배경에 Deep Navy/Cyan Blue 그라데이션이 흐르며 "진단 시간 카운트다운 중..." 메시지 노출.
    2.  **타이머 작동 (핵심):** 30초부터 역순으로 카운트다운(예: `T-15s`). 시간이 지날수록 경고 색상(빨간색 계열)의 강도가 점진적으로 증가해야 합니다.
    3.  **위기 고조 트리거:** 남은 시간이 임계점(예: 5초 이하)에 도달하면, 배경에 `[WARNING: SYSTEM INTEGRITY DEGRADATION]` 이라는 글리치 효과가 오버레이되고, 사운드 스펙(`ERROR_CHIME`)이 발동됩니다.
    4.  **최종 상태:** 타이머 종료 시, 메시지가 "진단 기회 만료. 데이터 누락 감지."로 변경되며 강제적인 다음 단계(CTA)를 유도해야 합니다.

#### 2. 데이터 노이즈 패턴 (Data Noise Pattern: `ComponentB`)
*   **위기감 역할:** 시스템의 불안정성과 사용자 정보의 '누락' 가능성을 시각적으로 암시.
*   **기술 구현 요소:** SVG 원본 파일 + CSS Pseudo-element/Animation.
*   **필수 로직 스펙:**
    1.  **트리거 조건 (우선순위):** 마우스가 특정 영역(예: 본문 텍스트나 CTA 근처)에 **호버되는 순간(Hover)**, 혹은 사용자가 페이지를 **스크롤할 때마다(Scroll Delta)** 무작위로 활성화되어야 합니다.
    2.  **시각적 표현:** 검은색 배경 위에 녹색/Cyan Blue 계열의 폰트가 비정형적으로 노이즈처럼 흐르는 패턴을 구현합니다. (예: `01a3f4e8b7...` 같은 무작위 문자 스트림).
    3.  **애니메이션 특성:** 이 노이즈는 일정 시간(예: 500ms) 후에 **자연스럽게 사라지거나** 혹은 **다른 패턴으로 치환**되어야 합니다. (단순히 깜빡이는 것이 아니라, 데이터가 흘러내리는 듯한 느낌).
    4.  **기술적 제약:** 이 노이즈는 주 콘텐츠 위에 레이어 형태로 오버레이(Overlay) 되어야 하며, 가독성을 해치지 않도록 투명도(`opacity`)와 불투명도를 섬세하게 조절해야 합니다.
