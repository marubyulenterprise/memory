### 💾 Loss Meter Core Asset Specification (애셋 사양서)

**목표:** 시청자가 '손실 공포'가 시스템적으로 작동하고 있음을 인지하게 하여, 서비스 가치를 지식 전달이 아닌 생존 장치(ASV)로 인식시키기 위함.
**출력 형식:** 애니메이션 Keyframe 레퍼런스 또는 After Effects/Premiere Pro용 컴포넌트 템플릿 (PSD/AEP 구조 권장).
**공통 사양:**
*   **해상도:** 1920x1080 (4K급 고화질을 염두에 두고 제작된 에셋이므로, 모든 요소는 벡터 기반으로 설계되어야 함.)
*   **프레임 레이트:** 30 FPS 이상 (부드러운 애니메이션 구현 필수).
*   **핵심 변수:** `$X$` (손실 금액), `T` (남은 시간 카운터)

#### 1. [STATE 1] 초기 안전 상태: 'Baseline Safety' 컴포넌트

| 요소 | 사양 및 로직 정의 | 애니메이션/키프레임 요구 사항 |
| :--- | :--- | :--- |
| **$X$ 값 표시** | $0 \sim 50만 원$ 사이의 안정적, 느린 변동. (손실액이 아닌 잠재적 가치 감소로 표현) | 부드러운 선형 보간(Smooth Linear Interpolation). 숫자가 떠오르는 듯한(Floating Up) 효과 적용. |
| **배경/색상** | 차분하고 신뢰감을 주는 색상 팔레트 (딥 블루 계열, 무채색 배경). | 미세한 노이즈(Subtle Grain Noise)를 배경에 깔아 '현실적 데이터' 느낌 부여. |
| **경고 타이머 (T)** | 비활성화 상태. 표시 자체는 존재하나 색상이 회색/무채색으로 처리되어 위협도가 없음을 명시. | 텍스트 애니메이션만 적용. 카운트다운 로직은 가짜(Mock)로 작동함. |
| **핵심 동작** | 시스템이 안정적으로 데이터를 측정하고 있음을 시각적으로 보여줌. (권위적인 느낌 강조) | 느리고 일정한 리듬감 유지. |

#### 2. [STATE 2] 위협 감지/경고: 'Pre-Alert Warning' 컴포넌트

| 요소 | 사양 및 로직 정의 | 애니메이션/키프레임 요구 사항 |
| :--- | :--- | :--- |
| **$X$ 값 표시** | $50만 원 \rightarrow 150만 원$ (급상승). 손실액이 증가함에 따라 글자 크기와 색상이 점진적으로 커지며 위협도를 높여야 함. | 가속도 변화(Acceleration Curve)를 주어 수치가 빨라지는 느낌 연출. **색상 전환:** 블루 $\rightarrow$ 오렌지 (경고). |
| **배경/색상** | 배경에 낮은 빈도의 깜빡임 효과(Flickering effect) 도입. 경계선 주변에 미세한 Red Glow를 추가함. | 화면 좌우 가장자리에 얇은 주황색/붉은색 'Scan Line'이 주기적으로 지나가게 애니메이션화. |
| **경고 타이머 (T)** | 활성화됨. 남은 시간($T$)이 명확하게 카운트다운되며, 시간이 줄어들수록 깜빡임(Blinking) 효과 강화. | **애니메이션:** 틱톡(Tick-Tock) 사운드 이펙트와 연동되는 강력한 시각적 타이머 애니메이션 필수. (빨간색으로 채워지는 Bar 형태 추천). |
| **핵심 동작** | 시스템이 정상 범위를 벗어났음을 경고하며, 사용자에게 '주의'를 촉구하는 단계. | 리듬감 있는 템포 변화(Tempo Shift)가 가장 중요함. |

#### 3. [STATE 3] 임계치 초과/패닉 모드: 'Critical Panic Mode' 컴포넌트 (최종 클라이맥스 자산)

| 요소 | 사양 및 로직 정의 | 애니메이션/키프레임 요구 사항 |
| :--- | :--- | :--- |
| **$X$ 값 표시** | 수치 변동의 예측 불가능성 극대화. 1초에 여러 번, 급격히 오르내림 (예: $+50만 \rightarrow -20만 \rightarrow +80만$). 손실액이 최대치로 폭발적으로 증가하는 느낌을 주어야 함. | **가장 중요한 부분:** 글리치(Glitch) 효과와 강렬한 줌 인/아웃 애니메이션을 결합해야 합니다. 수치가 불안정하게 떨리는 듯한(Jittering) 움직임 필수. |
| **배경/색상** | 전체적으로 빨간 경고등(Critical Red Alert) 필터가 화면을 지배함. 배경에 데이터 노이즈, 스캔라인이 매우 빠르게 깜빡여서 시각적 과부하를 유발해야 함. | **애니메이션:** 고빈도 주파수의 플래시 효과와 함께 전체적인 색상 왜곡(Chromatic Aberration) 적용. |
| **경고 타이머 (T)** | '시간 임계치 초과' 메시지 등장. 카운트다운은 멈추거나, 무의미하게 급속히 돌아가는 형태로 불안감을 극대화함. | 경고 문구에 강한 진동(Vibration) 애니메이션 적용.
| **핵심 동작** | 사용자에게 '지금 당장 무언가를 해야 한다'는 생존 본능적 공포를 유발하는 최대치 상태. | 모든 시각 요소가 통제 불가능하게 폭주하는 느낌을 줘야 함. |
