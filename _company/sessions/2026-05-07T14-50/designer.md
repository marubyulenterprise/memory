### 🔴 Marubyul: 손실 측정 시스템 (Loss Meter System) 디자인 브리프 V3.0

**1. 핵심 비주얼 컨셉:**
*   **테마:** Cyberpunk/Technical Emergency Alert
*   **목표 감정:** 공포(Fear), 긴급성(Urgency), 압박감(Pressure).
*   **핵심 원칙:** 모든 시각적 요소는 '시스템이 오류를 감지하고 경고하는 과정'처럼 보이게 디자인되어야 합니다.

**2. 컬러 팔레트 (Color Palette) 확정 및 역할 부여**

| 명칭 | Hex Code | 사용 목적 | 비주얼 가이드라인 |
| :--- | :--- | :--- | :--- |
| **Deep Navy (Authority)** | `#0D1B3A` | 기본 배경, 시스템의 깊이, 권위. 전체 화면의 주된 어둠색으로 사용. | 낮은 채도의 짙은 네이비. 시각적 안정감을 제공하며 위기 상황을 강조하는 기반 역할. |
| **Electric Cyan (System Logic)** | `#00FFFF` | 표준 데이터 표시, 시스템 흐름(Flow), 정상 작동 상태의 하이라이트. | 디지털 느낌의 차가운 민트/사이안 블루. 기술적이고 청량한 '정보'의 색상. |
| **Critical Red (Danger Alert)** | `#FF3366` | 손실액($X$) 증가, 경고 임계치(Threshold), 패닉 상태 표시. | 시선을 강탈하는 채도 높은 마젠타-레드 계열. 위협과 즉각적인 행동을 유발함. |
| **Neutral White/Gray** | `#CCCCCC` | 일반 텍스트, 보조 정보. (높은 대비율 유지) | 너무 밝지 않은 회색으로 사용하며, 데이터가 '읽히는' 느낌을 부여. |

**3. 타이포그래피 가이드라인 및 글리치 효과(Glitch Effect)**

*   **메인 폰트:** `Orbitron` 또는 유사한 기하학적 모노스페이스(Monospace) 스타일의 기술적 폰트. (예: Source Code Pro 등).
    *   *이유:* 시스템 메시지, 디스플레이 창 같은 느낌을 주어 전문성과 인공적인 긴급성을 극대화합니다.
*   **손실액($X$) 타이포그래피:**
    1.  **기본 상태:** `Electric Cyan`의 모노스페이스 폰트로 표시. 숫자는 약간 낮은 대비율로 처리하여 '측정 중인 데이터'처럼 보이게 합니다.
    2.  **경고/패닉 상태 (Glitch):** 손실액 수치가 급격히 변동하거나 임계치를 넘을 때, 다음 애니메이션 로직을 적용합니다.
        *   **애니메이션:** 폰트가 순간적으로 **좌우로 미세하게 떨리거나(Jitter)**, 혹은 **픽셀 단위로 분해되었다가 재조립되는(De-sync/Scan Line)** 글리치 효과를 짧게 삽입해야 합니다.
        *   **색상 변화:** 일반 Cyan에서 `Critical Red` 계열로 순간 전환되며 함께 글리치합니다.

### 🎥 최종 에셋 제작 사양 (Editor's Kit)

#### A. 손실 측정 애니메이션 루프 클립 사양서 (Loopable Clip Spec Sheet)
(총 길이: 4초 / 반복 가능, 핵심은 '점진적인 긴장감 고조')

| Timecode | 상태 변화 및 메시지 | 시각 효과 및 로직 지침 | 사용 색상 (Hex) |
| :--- | :--- | :--- | :--- |
| **0:00 - 1.5s** | **[STATE 1] Baseline Safety:** "System Status Check..." / 손실액 $X$: 안정적 변동 ($0 \sim 20$만원). | 배경에 미세한 Cyan 그리드 패턴 애니메이션(Scan-in) 적용. 숫자는 부드러운 선형 상승 효과(Smooth Fade Up). 경고 타이머는 무채색 유지. | `#0D1B3A`, `#00FFFF` |
| **1.5s - 3.0s** | **[STATE 2] Pre-Alert Warning:** "WARNING: Data Integrity Compromised." / 손실액 $X$: 가파른 상승 ($20 \rightarrow 80$만원). | 텍스트가 진동하며 (Jitter) 크기가 증가하고, `Electric Cyan`에서 점진적으로 `Critical Red`로 색상이 오염(Bleeding)되기 시작. 배경 그리드 패턴이 빨간색 노이즈와 결합함. | `#FF3366`, `#0D1B3A` |
| **3.0s - 4.0s** | **[STATE 3] Critical Alert / Peak Loss:** "CRITICAL BREACH! IMMEDIATE ACTION REQUIRED." / 손실액 $X$: 급격한 폭증 ($80 \rightarrow 250$만원). | 화면 전체가 순간적으로 `Critical Red` 필터로 뒤덮임. 글리치 효과(De-sync)를 최대 강도로 적용하며, 수치가 가장 높은 지점에서 **빨간색 타이머 카운트다운**이 폭발하듯 나타나야 함. (Loop Point: 4.0s $\rightarrow$ 0.0s로 급격하게 끊어지며 반복). | `#FF3366` (주요), `#0D1B3A` (배경) |

#### B. 오버레이/그래픽 패키지 사양서 (Overlay Pack Spec Sheet)
(다양한 배경 영상에 덧씌워 권위와 긴급성을 부여하는 재사용 가능한 자산들)

1.  **[Scanline Noise Overlay]:**
    *   **목적:** 모든 영상 클립에 아날로그/디지털 디스플레이의 느낌을 주어 '데이터 화면' 같은 몰입감을 높입니다.
    *   **사양:** 반투명한 직사각형 격자 노이즈 패턴 (Deep Navy 배경 위에서 Electric Cyan 톤으로 보이도록). 주기적으로 미세하게 움직이는 애니메이션 적용.
2.  **[System Breach Border]:**
    *   **목적:** 중요한 정보나 $X$ 값이 표시되는 영역을 시각적으로 분리하고, 경계가 무너지는 느낌을 부여합니다.
    *   **사양:** 얇은 사각형 프레임 형태. 정상 상태에서는 `Electric Cyan`의 점선으로 시작하나, 위협 임계치에 도달할 때 프레임 모서리에서부터 **붉은색 글리치 라인**이 스캔되듯 번져나갑니다.
3.  **[Warning Stamp/Seal]:**
    *   **목적:** 콘텐츠가 '시스템 생성 경고'라는 권위를 부여합니다.
    *   **사양:** 오른쪽 하단 모서리에 배치 가능한, 반투명한 직사각형 스탬프 형태. 텍스트: "WARNING" 또는 "DATA BREACH". 색상: `Critical Red` 배경에 흰색/Cyan 글자. (Stamp 애니메이션: 빠르게 나타났다 사라지는 진동 효과 필수).
