## 📋 Marubyul 콘텐츠 제작 시스템화 가이드 V1.0 (3개월 반복 활용 템플릿 세트)

### 📸 Template Set 2: 인스타그램 릴스 & 카루셀 마케팅 카피라이팅 템플릿

**[목표]** 짧은 시간 안에 높은 전문성을 유지하며 '클릭'을 유도한다. (공격적이고 구체적인 CTA 필수)
**[구조]** Hook $\rightarrow$ Problem/Loss Quantification $\rightarrow$ Solution Urgency (CTA).

#### 🅰️ 릴스(Reels)용 고효율 카피 구조 (15초~45초 영상 전용)

| 요소 | 작성 가이드라인 | 예시 포맷 |
| :--- | :--- | :--- |
| **Hook 문구 (첫 2초)** | 시각적/질문형. 수치(%)와 시간(h)을 반드시 포함하여 궁금증 유발. | "⚠️ 잠깐! 당신이 자동화에 쓰는 이 방법, 사실 [X]%를 손해 보고 있습니다." / "AI로 돈 벌기 전에, 이거 모르면 3배의 비용 손실 각오하세요." |
| **본문 카피 (Caption)** | 영상에서 다룬 결함을 재확인시키며, 공포 규모를 확대. 전문 용어 사용으로 권위 확보. | "대부분이 [쉬운 방법 A]로 끝낸다고 생각하지만, 시스템적 관점에서 보면 [변수 X]가 빠지면서 발생하는 기회비용 손실은 무시할 수 없습니다. 이 정도 결함이라면 이미 적자입니다." (→ **손실액을 구체적으로 언급**) |
| **CTA 문구 (Call to Action)** | 프로필 링크 클릭이 '선택'이 아닌 '생존 필수'처럼 느껴지도록 강제. | "✅ 3개월 안에 이 손실을 막고 싶다면? 저희가 분석한 [Blueprint]를 확인하세요. (프로필 링크)" / "더 이상 추측하지 마세요. Loss Index 계산기에서 당신의 결함을 직접 진단해 보세요." |
| **해시태그 세트** | 전문성과 긴급성을 혼합 (하이브리드). | `#시스템아키텍처 #자동화원리 #비즈니스결함 #LossIndex #AI전문가` |

#### 🅱️ 카루셀(Carousel)용 구조화 포맷 (정보 밀도 높음)

| 슬라이드 순서 | 내용 구성 목표 | 필수 키워드 및 액션 |
| :--- | :--- | :--- |
| **Slide 1 (Hook)** | 제목: 질문형 경고. 시청자가 '나에게 해당된다'고 느끼게 한다. | "🚨 당신의 자동화 시스템, 지금도 이 결함을 안고 있습니다." / "[숫자]가지 오해! AI 초보자들이 반드시 피해야 할 함정 3가지" |
| **Slide 2~4 (Problem)** | 구체적인 '오류 사례' 제시. 시각적 대비(Before $\rightarrow$ After) 활용. | "❌ 통념: [방법 A]. → ✅ 진실: 시스템은 [변수 B]를 요구함." / 각 슬라이드마다 손실액/시간을 수치로 명시. |
| **Slide 5 (Solution)** | 해결책의 존재 자체만 언급. 구체적인 방법론은 숨긴다. | "이 모든 것을 한 번에 설계하는 원리적 틀(Framework)이 필요합니다." / *Blueprint라는 개념*을 제시하며 전문성을 유지. |
| **Slide 6 (CTA)** | 행동 유도. 가장 강력하고 직관적인 요청. | "**[선택]** 더 이상 추측으로 시간 버리지 마세요. 프로필 링크에서 [Loss Index 진단] 받기." |

### 🚀 Template Set 3: 유튜브 쇼츠용 자극적 질문 목록 (Quick Hooks)

**[목표]** 스크롤을 멈추게 하는 즉각적인 궁금증 유발 질문. 영상 시작 후 0~2초에 사용한다.
**[규칙]** 모든 질문은 '쉬운 방법'이 있다는 통념을 전제로 하되, 그 이면에 '결함'이 있음을 암시해야 한다.

1.  **(효율성 공포)** "AI 자동화, 매번 30분씩 수동으로 작업하는 분들 주목하세요. 당신은 지금 [시간]을 버리고 있습니다."
2.  **(비용 손실 공포)** "자동화 시스템 구축 비용? 사실 도구값만 아는 게 가장 큰 오해입니다. 진짜 손실액은 이거예요." (→ 실제 결함에 의한 기회비용 암시)
3.  **(원리 무지 공포)** "대부분의 사람들이 '이렇게 하면 된다'고 알려주는 방법, 그 원리를 아세요? 90%는 구조적 오류가 있습니다."
4.  **(통제력 상실 공포)** "여러분의 비즈니스 흐름이 예측 불가능한 순간에 시스템이 멈춘다면? 누가 책임질까요?" (→ '시스템 통제력'의 중요성 강조)
