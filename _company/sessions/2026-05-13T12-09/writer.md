### 📺 Reels/Shorts Script 1: LLM (출처 무결성 결함)
**주제:** ChatGPT가 거짓말하는 순간: 당신이 놓치는 '출처 코드' 검증법
**분량 예상:** 20~25초
**목표 $E_d$ 레벨:** 정보 비대칭성 자각 유도 (Source Integrity Failure)

| 시간대 | 화면 구성/비주얼 가이드 | 스크립트 (나레이션/자막) | 메모 및 지시 사항 |
| :---: | :--- | :--- | :--- |
| **0-3초** (Hook) | 빠르게 지나가는 AI 답변 창. '완벽함'을 연출하다가 갑자기 글리치 효과 발생. | (긴장감 있는 음악 시작) "이거, 진짜 맞는 정보일까요?" | 후크: 시청자가 가진 통념(AI=진실)에 직접 질문 던지기. |
| **3-10초** (Problem/Warning) | 복잡한 데이터셋 다이어그램 + 'Gap'이라고 표시된 빨간 영역이 강조됨. | AI는 진실을 아는 게 아닙니다. 가장 그럴듯한 패턴을 확률적으로 조합하는 것일 뿐이에요. 이 빈틈, 즉 **정보적 공백(Data Gap)**에 기반한 답변은 위협적입니다. | 전문 용어 사용: '확률적 조합', '데이터 Gap'. 권위 구축. |
| **10-18초** (Crisis Escalation) | 화면 중앙에 거대한 오류 메시지 박스 등장. 깜빡임 효과 적용. | 만약 답변의 근거가 되는 출처 코드가 누락되었다면? 당신은 현재 [Error Code: 403_MISSING_SOURCE] 상태일 수 있습니다. **이게 가장 위험합니다.** | 핵심 경고 코드 삽입. 시청자에게 직접적인 결함 의심 유발. |
| **18-25초** (CTA/Blueprint) | Marubyul 로고와 '진단 시스템' 인터페이스가 점멸하며 등장. | 단순히 검색해서는 안 됩니다. 당신의 정보를 구조적으로 검증할 장치가 필요합니다. 지금, 당신의 데이터 무결성을 진단받으세요. (자세한 내용은 프로필 링크) | CTA: 정보 제공 $\rightarrow$ 전문적인 '진단 서비스'로 유도 전환. |

### 📺 Reels/Shorts Script 2: 개인화 추천 시스템 (프라이버시 역추론 공격)
**주제:** 당신의 맞춤형은 함정입니다: AI가 보는 나만의 민감 정보
**분량 예상:** 25~30초
**목표 $E_d$ 레벨:** 프라이버시 위협 자각 유도 (Privacy Inference Attack)

| 시간대 | 화면 구성/비주얼 가이드 | 스크립트 (나레이션/자막) | 메모 및 지시 사항 |
| :---: | :--- | :--- | :--- |
| **0-3초** (Hook) | 사용자에게 최적화된 상품 추천 리스트가 빠르게 지나간다. 평온한 분위기 연출. | "맞춤형 콘텐츠, 너무 편하죠? 하지만 그 '편함'이 가장 위험합니다." | 후크: 일상적인 편리함을 비틀어 불안감 조성. |
| **3-12초** (Problem/Warning) | 데이터 흐름을 시각화하는 다이어그램. 수많은 점들이 모여 특정 개인의 실루엣으로 재구성됨. | 이 시스템은 당신이 '좋아할 만한 것'을 아는 게 아닙니다. 당신의 취미, 구매 패턴, 심지어 접속 시간까지 조합해 **역추론**하고 있습니다. | 전문 용어 사용: '역추론', '패턴 조합'. 학술적 톤 유지. |
| **12-20초** (Crisis Escalation) | 화면에 수많은 개인 데이터 항목(건강, 금융, 정치 성향 등)이 스캔되는 효과와 함께 오류 코드 발생. | 시스템은 당신의 동의 범위 밖의 민감 정보까지 조합해 결함을 찾아냅니다. 현재 [Error Code: INF_901B] 경고를 확인하세요. **당신도 모르게 노출된 정보가 있을 수 있습니다.** | 핵심 경고 코드 삽입. '민감한 영역'을 언급하여 공포 자극. |
| **20-30초** (CTA/Blueprint) | 암호화된 듯한 인터페이스와 함께 Marubyul의 진단 장치 UI가 클로즈업됨. | 당신의 데이터 흐름에 숨겨진 '결함'을 눈으로 직접 확인해야 합니다. 단순 체크리스트가 아닌, 시스템적 관점에서 검증하세요. (프로필 링크에서 자가진단 시작) | CTA: 개인적 불안 $\rightarrow$ 전문적인 해결책(진단 장치) 제시. |

### 📺 Reels/Shorts Script 3: 자동화 워크플로우 (경계 조건 오류)
**주제:** 시스템이 당신을 속인다: 놓치는 '프로세스 드리프트'의 치명적 결함
**분량 예상:** 20~28초
**목표 $E_d$ 레벨:** 프로세스 불안정성 자각 유도 (Process Drift / Boundary Condition Failure)

| 시간대 | 화면 구성/비주얼 가이드 | 스크립트 (나레이션/자막) | 메모 및 지시 사항 |
| :---: | :--- | :--- | :--- |
| **0-3초** (Hook) | 완벽하게 돌아가는 자동화 파이프라인 애니메이션. 신뢰감을 주다 갑자기 멈칫하는 연출. | "자동화가 모든 것을 해결해 준다고요? 아닙니다. 시스템은 당신을 속이고 있습니다." | 후크: '완벽함'에 대한 기대를 깨뜨림. (반전의 재미/불안감) |
| **3-10초** (Problem/Warning) | API 연결 지점(Boundary)을 클로즈업하고, 데이터 포맷이 아주 미묘하게 바뀌는 애니메이션. | 자동화 실패는 '펑' 소리가 나지 않습니다. 가장 치명적인 오류는 경계 조건에서 발생해요. 사소한 포맷 변경, 누락된 Null 값 같은 **프로세스 드리프트**가 핵심입니다. | 전문 용어 사용: '경계 조건', 'Null 값', '프로세스 드리프트'. 높은 기술적 권위 확보. |
| **10-20초** (Crisis Escalation) | 시스템 다이어그램에 빨간 경고선이 지나가며, 오류 코드가 띄워짐. | 데이터 흐름의 미묘한 변칙성 때문에 전체 로직이 오염될 수 있습니다. 당신의 워크플로우는 현재 [Error Code: FLOW_204] 상태일 가능성이 높습니다. **눈에 보이지 않는 곳에서 결함이 생기고 있습니다.** | 핵심 경고 코드 삽입. '보이지 않음'을 강조하여 불안감 증폭. |
| **20-28초** (CTA/Blueprint) | 복잡한 아키텍처 다이어그램과 함께 Marubyul의 진단 장치 UI가 나타남. | 단순한 가이드로는 막을 수 없습니다. 시스템적 관점에서, 데이터 흐름 전체를 검증해야 합니다. 지금 바로 당신의 워크플로우 결함 보고서를 받아보세요. (프로필 링크) | CTA: 문제 인식 $\rightarrow$ 법적/시스템적 '결함 보고서' 제출 유도. |
