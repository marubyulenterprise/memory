## 🚨 ASV Critical State Copy Set (3가지 버전)
**(톤앤매너: 전문적 권위, 시스템 오류 메시지, 공포 유발)**

### 1. [기술적 결함 강조형] - '시스템 생존'에 초점
(가장 높은 기술적 전문성을 요구하며, 사용자가 스스로의 지식 부족을 깨닫게 만듭니다.)

| 구성 요소 | 카피라이팅 내용 | UI 적용 가이드 (Designer 반영) |
| :--- | :--- | :--- |
| **[SYSTEM ALERT]** | `WARNING: CRITICAL FAILURE DETECTED. ASV THRESHOLD VIOLATION.` | 모달 최상단에 붉은색 경고 배너로 깜빡임 적용. |
| **[헤드라인]** | **FAULT DIAGNOSIS REQUIRED.** (진단 결함 필요) <br> *당신의 아키텍처는 단일 실패점(SPOF)을 간과했습니다.* | 고정폭 폰트, 글리치 노이즈 효과와 함께 표시. |
| **[본문 내용]** | 현재 시스템 구조는 복합적인 리스크를 안고 있습니다. 핵심 로직의 중복성 검증 실패, 외부 의존성(Dependency) 관리 미흡 등 다층적 취약성이 관찰됩니다. 이 상태로 운영될 경우 예측 가능한 지점에서 서비스가 전면 다운될 확률이 90% 이상입니다. | 짧은 문장 단위로 끊어 읽히게 구성하여 긴장감 유지. |
| **[강제 질문/CTA]** | **❓ 당신의 백업 계획(BCP)은 현재 작동합니까?** <br> **ASV 진단을 통해 시스템적 리스크를 즉시 측정하십시오.** | '진단하기' 버튼 위에 빨간색 경고 텍스트 오버레이. |

### 2. [손실 공포 강조형] - '비용과 시간'에 초점
(가장 실질적인 위험을 숫자로 제시하여, 당장의 금전적/시간적 손해를 상기시킵니다.)

| 구성 요소 | 카피라이팅 내용 | UI 적용 가이드 (Designer 반영) |
| :--- | :--- | :--- |
| **[SYSTEM ALERT]** | `CRITICAL WARNING: FINANCIAL & OPERATIONAL RISK DETECTED.` | 경고창 배경에 'LOSS' 키워드가 깜빡이게 처리. |
| **[헤드라인]** | **CURRENT MODEL IS UNSUSTAINABLE.** (현재 모델은 지속 불가능합니다.) <br> *지연된 진단은 기회비용 손실로 직결됩니다.* | 위기 상황을 상징하는 폰트(Distressed Font) 사용. |
| **[본문 내용]** | 단순한 '버그'가 아닙니다. 이는 구조적 결함이며, 시간당 예상되는 비즈니스 손실액(ALE)은 현재 진단되지 않은 리스크로 인해 예측 범위를 벗어날 수 있습니다. 지금의 무지함이 가장 큰 비용입니다. | '비용', '손실', '예측 범위' 등의 키워드에 하이라이트 적용. |
| **[강제 질문/CTA]** | **⌛ 이 리스크를 감당할 자본적 여유가 있습니까?** <br> **즉각적인 ASV 점수 측정으로 잠재 손실을 시뮬레이션하세요.** | CTA 문구에 'Loss Simulation' 등 전문 용어 삽입. |

### 3. [지식 권위 강조형] - '오해와 진실'에 초점
(사용자가 스스로의 지식을 의심하게 만들고, 전문가의 도움이 필요하다는 인상을 심어줍니다.)

| 구성 요소 | 카피라이팅 내용 | UI 적용 가이드 (Designer 반영) |
| :--- | :--- | :--- |
| **[SYSTEM ALERT]** | `PROTOCOL VIOLATION: SELF-ASSESSMENT INSUFFICIENT.` | 시스템이 사용자를 '불완전한 존재'로 인식하는 듯한 뉘앙스. |
| **[헤드라인]** | **STOP ASSUMING OPTIMALITY.** (최적이라 가정하지 마십시오.) <br> *당신이 아는 것은 현상일 뿐, 구조적 원리가 아닙니다.* | 질문형 문장을 통해 사용자의 '인지적 결함'을 지적. |
| **[본문 내용]** | 일반적인 가이드라인이나 '팁'만으로는 시스템의 근간을 이해할 수 없습니다. 저희가 제시하는 프레임워크는 당신이 간과한 3차원적인 연결고리(Interconnection)에 기반하며, 이 영역은 외부 진단 없이는 접근 불가능합니다. | '프레임워크', '연결고리', '접근 불가능' 등의 고급 용어 사용으로 권위 확보. |
| **[강제 질문/CTA]** | **🧠 구조적 취약성을 직접 진단해 보시겠습니까?** <br> **BluePrint ASV 진단만이 당신의 시스템에 경고등을 켤 수 있습니다.** | CTA 버튼 근처에 "Warning: Unauthorized Access Attempt" 같은 가짜 보안 메시지 배치 고려. |
