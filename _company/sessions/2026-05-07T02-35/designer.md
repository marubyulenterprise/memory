## I. 핵심 컬러 및 시스템 가이드라인
| 요소 | 색상 코드 (Hex) | 용도/의미 | 비고 |
| :--- | :--- | :--- | :--- |
| **경고 메인** | `#CC0000` | 위기 경고, Critical Alert 표시, CTA 강조. | 강렬한 위험 신호. 모든 주요 액션에 사용. |
| **배경/권위색** | `#1A0000` | 배경의 딥 네이비 계열, 시스템 프레임워크, 섹션 구분선. | 깊은 전문성과 통제권을 상징. 어두운 분위기 조성. |
| **강조 포인트** | `#FFD700` | 경고가 임박했음을 나타내는 깜빡이는 전력 표시(Blinking Indicator). | 주의를 집중시키며 긴급성을 높임. |

## II. 컴포넌트 상세 디자인 스펙 (Actionable Components)

### 1️⃣ 손실액 계산기 UI: [Structural Loss Meter]
*   **위치:** 구매 결정 섹션 바로 위. 사용자가 '손해'를 시각적으로 인지하는 지점.
*   **컨셉:** 배터리 충전 게이지가 아닌, **'시스템 자원 고갈 경고계(Depletion Warning Gauge)'** 형태.
*   **구조 및 스펙:**
    *   **레이아웃:** 와이드 바 타입 (Width: 100%, Height: 80px). 중앙에 핵심 수치를 표시.
    *   **시각화 요소:** 게이지 바를 세 개의 분할 영역으로 나눔.
        1.  **[시간 손실] Time Cost:** 남은 시간(혹은 해결까지 필요한 최소 시간)을 시계 바늘/게이지로 표현. (초기: 🔴 `#CC0000` / 완료 임박: 🟡 `#FFD700`)
        2.  **[재정 손실] Financial Cost:** 누적되는 기회비용을 수치와 함께 그래프 형태로 표시. (단위: ₩)
        3.  **[경고 레벨] Vulnerability Index:** 전체 시스템의 위험도를 나타내는 아이콘 세트(🚨, ⚠️, ✅). 현재 상태는 반드시 `🚨`가 강조되어야 함.
    *   **애니메이션 로직 (필수):** 게이지 바 전체에 걸쳐 미세하고 주기적인 **글리치 노이즈 효과(Glitch Noise)**를 적용하여 시스템 오류의 느낌을 유지. 시간 손실 값이 갱신될 때마다 '틱' 하는 사운드와 함께 게이지가 하강하는 애니메이션을 삽입.

### 2️⃣ 최종 구매 CTA 버튼: [Protocol Activation Switch]
*   **위치:** 페이지 최하단, 가장 눈에 띄는 곳. (반드시 스크롤로 내려오게 유도)
*   **컨셉:** 단순한 버튼이 아닌, **'시스템 오버라이드(System Override)'** 또는 **'비상 프로토콜 활성화 스위치'**처럼 보이도록 설계.
*   **스펙:**
    *   **형태:** 직사각형 형태보다 약간 둥근 사다리꼴에 가깝게 디자인하여, '물리적인 장치를 조작하는 느낌'을 부여. (Padding: Top/Bottom 20px, Left/Right 60px).
    *   **색상:** 배경은 **`#CC0000`**. 버튼의 가장자리에 미세한 네온 라이트 효과(Neon Glow)를 주어 긴급성을 높임.
    *   **텍스트:** "프로토콜 즉시 활성화 (System Protocol Activation)" 또는 "생존 시스템 패치 설치".
    *   **애니메이션 로직:** 마우스를 올렸을 때 (Hover), 버튼이 살짝 전기적인 **스파크 효과(Electric Spark Effect)**를 내며 밝기가 급격히 증가해야 함. 클릭 시, '클릭' 사운드와 함께 화면 전체가 찰나의 순간 어두워지며 시스템 부팅 같은 연출 필요.

### 3️⃣ 전반적 경고 시스템 컴포넌트 세트 (System Alert Kit)
*   **목표:** 페이지의 모든 섹션에 통일된 긴장감을 부여하고, 신뢰성 있는 '진단 보고서' 느낌을 강화함.
*   **A. 헤더/섹션 분리선 (Divider):**
    *   **디자인:** 단순한 실선 대신, **데이터 플로우 연결 선(Data Flow Line)** 형태를 사용. 좌우 끝에서 시작하여 중앙으로 오면서 미세하게 끊어지거나 노이즈가 들어간 패턴을 적용.
    *   **색상:** `#1A0000` (배경과 유사하지만 대비되는 진한 톤).
*   **B. 경고 박스/인용구 (Warning Box):**
    *   **활용:** 중요한 데이터나 고객의 '결함'을 언급할 때 사용.
    *   **디자인:** 배경에 아주 미세한 **격자무늬(Grid Pattern)**를 깔고, 테두리를 `#CC0000`으로 처리. 좌측 상단 또는 하단 모서리에 `[CRITICAL ALERT]`와 같은 작은 시스템 뱃지(Badge)를 삽입해야 함.
*   **C. 데이터 시각화 Placeholder:**
    *   **디자인:** 차트나 그래프를 보여줄 공간은 일반적인 막대/꺾은선형이 아닌, **'시스템 로그 아웃풋(System Log Output)'**처럼 보이게 해야 함. 텍스트 기반의 코드 블록 느낌을 주되, 데이터가 플로우차트를 통해 연결되는 다이어그램 형태를 유지해야 합니다.
