## 🛠️ 시스템 표준 애니메이션 컴포넌트 스펙 시트 (V3.0)

### I. 자산 개요 및 공통 가이드라인

| 요소 | 사양 | 상세 설명 |
| :---: | :---: | :--- |
| **형식** | Lottie/SVG Animation | 모바일 및 웹 환경에서 최적의 성능과 커스터마이징을 보장합니다. (JSON export 필수) |
| **사이즈** | 1920x1080 px 기준, 루프(Loop) 가능하도록 설계 | 필요에 따라 가로/세로 비율 변형이 가능한 모듈식 구조여야 합니다. |
| **핵심 색상 팔레트** | **Primary Warning:** `#FF4B4B` (강렬한 빨간색), **System Error:** `#8E24AA` (딥 퍼플/마젠타 계열), **Background Grid:** `#0A1931` (거의 검정에 가까운 네이비) | 색상 코드는 CSS 변수(`--color-warning`)로 지정되어야 합니다. |
| **공통 애니메이션** | 글리치(Glitch), 깜빡임(Flicker), 왜곡(Distortion), 타이핑 효과(Typewriter). | 모든 에셋에 공통적으로 적용될 수 있는 기본 모션 필터를 정의합니다. |

### II. 5가지 핵심 컴포넌트 상세 스펙 (Technical Specs)

#### 1️⃣ Asset #001: [⚠️ SYSTEM ALERT: PROTOCOL DRIFT DETECTED ⚠️]
*   **용도:** 콘텐츠의 클라이맥스. 시청자가 안심하는 순간, 가장 강력한 위협을 던져 $E_d$ 스파이크를 유발할 때. (필수 사용)
*   **트리거:** `T+N초`에 맞춰 강제 호출되어야 합니다.
*   **애니메이션 로직 (Lottie/SVG):**
    1.  **Start (0~0.5s):** 화면 전체가 딥 네이비 배경의 미세한 그리드 패턴으로 시작합니다. 좌우로 노이즈 필터(Noise Filter)를 적용하며 깜빡입니다.
    2.  **Warning Text 등장 (0.5~1.5s):** `[SYSTEM ALERT: PROTOCOL DRIFT DETECTED]` 텍스트가 중앙에 폭발적으로 나타나며, 글리치 효과와 함께 순간적으로 왜곡됩니다. (글자 단위로 짧게 반복되는 깜빡임 필수).
    3.  **Visual Impact (1.5~2.5s):** 화면 전체가 빨간색(Warning Color)으로 빠르게 플래시 됩니다. 동시에 배경의 그리드 패턴이 **좌표계 오류(Grid Distortion)**를 일으키며 일그러지는 모션이 발생합니다.
    4.  **End/Loop (2.5초 이후):** 텍스트는 깜빡임과 함께 진동하며 유지되고, 주변에 시스템 경고 사운드를 연상시키는 짧은 하이톤의 '삐-' 소리가 반복됩니다.

#### 2️⃣ Asset #002: [PROTOCOL_FLAW: INCOMPLETE]
*   **용도:** 정보 비대칭성을 폭로할 때. 일반적인 지식이나 시스템 흐름도의 특정 단계가 누락되었음을 암시합니다. (W1-A 활용)
*   **트리거:** 다이어그램이나 프로세스 플로우가 제시된 직후, 해당 플로우 위에 겹쳐서 나타나야 합니다.
*   **애니메이션 로직 (Lottie/SVG):**
    1.  **Initial State (0~0.5s):** 화면 중앙에 노란색 점멸 경고 박스(`Warning Box`)가 등장합니다.
    2.  **Code Reveal (0.5~1.5s):** `PROTOCOL_FLAW:` 부분이 타이핑 효과로 나타납니다. 이후 `INCOMPLETE` 부분의 글자가 **좌우로 지터링(Jittering)** 되며 불안정하게 깜빡입니다.
    3.  **Visual Effect:** 텍스트 주변으로 마치 데이터 전송에 오류가 난 것처럼, 작은 사각형 노이즈 입자(Pixel Noise)들이 미세하게 떨리면서 배출됩니다.
    4.  **Duration:** 짧고 반복적인 불안감을 주기 위해 5~8초 간격으로 루프되거나, 다음 애니메이션과 연결되어야 합니다.

#### 3️⃣ Asset #003: [DATA_SET: UNVALIDATED]
*   **용도:** 제시된 정보 자체가 출처가 불분명하거나 신뢰성이 떨어진다는 의혹을 제기할 때. (W1-B 활용)
*   **트리거:** 통계 자료나 인포그래픽이 화면에 나타날 때, 해당 데이터 위에 오버레이 됩니다.
*   **애니메이션 로직 (Lottie/SVG):**
    1.  **Appearance (0~1s):** 박스형 UI가 투명하게(Opacity 50%) 등장하며 배경의 데이터를 미세하게 왜곡시키는 필터가 걸립니다.
    2.  **Code Reveal (1~2s):** `DATA_SET:` 부분이 깔끔한 시스템 글꼴로 나타납니다. 이후 `: UNVALIDATED` 부분은 **빨간색으로 점진적인 색상 변화(Gradient Shift)**를 일으키며 경고합니다.
    3.  **Core Effect:** 텍스트 주변을 따라 데이터가 무너지는 듯한 `데이터 파편화(Data Fragmentation)` 애니메이션이 발생하며, 배경 그리드 패턴에 짧은 '오류 라인'이 수평으로 지나갑니다.

#### 4️⃣ Asset #004: [MISSING_COMPONENT_ERROR]
*   **용도:** 시스템 아키텍처나 프로세스 흐름에서 필수적인 구성 요소가 의도적으로 또는 실수로 누락되었음을 강조할 때. (일반적 권위 부여)
*   **트리거:** 다이어그램 설명 직후, 빈 공간이나 비어있는 박스를 가리킬 때 사용합니다.
*   **애니메이션 로직 (Lottie/SVG):**
    1.  **Focus Area (0~0.5s):** 화면의 특정 좌표(Placeholder)에 빨간색 점멸 사각형 포커스 에셋이 강제적으로 나타납니다.
    2.  **Message Reveal (0.5~1.5s):** `[MISSING_COMPONENT_ERROR]` 텍스트가 시스템 오류 코드처럼 글리치 효과와 함께 깜빡입니다.
    3.  **Guidance:** 하단에 작은 문구로 "Requires Component ID: [XXXX]"를 표시하여, 해당 내용이 전문적이고 기술적인 문제임을 강조합니다.

#### 5️⃣ Asset #005: Warning Box (Misconception Alert)
*   **용도:** 블로그나 교육 자료 등 비교적 정적인 콘텐츠에서 '오해'를 경고하며 시각적 브레이크 역할을 할 때. (학술적 권위 유지)
*   **트리거:** 텍스트 내용의 흐름이 전환될 때, 또는 오개념을 제시할 때 사용합니다.
*   **애니메이션 로직 (Lottie/SVG):**
    1.  **Background:** Deep Navy 배경에 Cyan Blue와 그리드 패턴이 적용된 강조 박스 형태를 유지합니다.
    2.  **Title Alert:** 상단에 작은 빨간색 점멸 띠(Banner)가 나타나고, 그 아래 본문 제목 (`MISCONCEPTION ALERT`)이 타이핑 효과로 등장합니다.
    3.  **Internal Effect:** 박스 내부의 경고 문구는 고정되지만, 배경 그리드 패턴은 미세하게 수평/수직으로 진동하는(Breathing) 애니메이션을 넣어 지루함을 없애고 '경계심'을 유지시킵니다.
