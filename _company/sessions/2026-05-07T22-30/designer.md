# 🚨 손실 공포 시스템 컴포넌트 라이브러리 v1.0 (Technical Spec Sheet)

본 문서는 '손실 공포 측정기(Loss Meter)'와 모든 경고/행동 유도(CTA) 요소의 최종 디자인 시스템을 정의하며, 개발팀이 즉시 코딩 및 구현할 수 있도록 상세 스펙과 에셋 가이드라인을 제공합니다. **'공포'를 시각적 언어로 번역하는 것이 목표입니다.**

---

## 🛠️ 1. 글로벌 스타일 & 컬러 코드 (Global Specs)

모든 컴포넌트는 '시스템 경고 모드'의 분위기를 유지하며, 다크 그레이/블랙 배경 위에서 네온사인 같은 색상으로 빛나야 합니다.

| 요소 | 상태 | Hex Code (HEX) | RGB (R, G, B) | 애니메이션 스펙 | 용도 및 특징 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **배경** | Base | `#050812` | (5, 8, 18) | - | 깊은 밤의 전광판 느낌. 모든 요소가 이 배경 위에서 떠오름. |
| **시스템 기본색** | Normal/Informational | `#00FFFF` | (0, 255, 255) | `glow-fade`: 1초에 걸쳐 부드럽게 깜빡임 효과 적용. | 사이언 블루. 시스템의 정상 작동 상태를 나타내는 '기본 정보' 색상. |
| **경고색** | Warning/Attention | `#FFA500` | (255, 165, 0) | `pulse-warning`: 주기적으로 밝기가 증가/감소하는 맥동 효과. | 오렌지 계열. '주의' 또는 '잠재적 위험'을 인지시키는 단계. |
| **긴급 경고** | Critical Red Alert (Loss Trigger) | `#B00020` | (176, 0, 32) | `red-flash`: 50ms 간격으로 불투명도(Opacity)가 0 $\leftrightarrow$ 1로 깜빡이며 시각적 충격을 극대화. | **최우선 공포 유발 색상.** 시스템의 치명적인 오류 또는 손실 임계치 초과를 알림. |
| **텍스트 (주요)** | Primary Text | `#FFFFFF` | (255, 255, 255) | - | 가장 중요한 메시지. 경고색과 대비되도록 명확하게 처리. |

## 🖥️ 2. 핵심 컴포넌트 라이브러리 (Component Library)

### A. 손실 측정기 유닛 (Loss Meter Unit: LMU)

*   **목적:** 사용자에게 '시간 경과에 따른 시스템적 결함'을 수치화하여 공포를 주입하는 장치.
*   **크기 스펙:** 가로 800px / 높이 120px (반응형: 최대 너비 90vw)
*   **구조:** `[경고 타이틀] - [손실 수치 ($X$)] - [단위/시간]`의 3분할 구조.

| 스펙 항목 | Normal State | Warning State | Critical Red Alert | 개발 지침 (CSS/JS) |
| :--- | :--- | :--- | :--- | :--- |
| **배경색** | `#050812` | `#3A000B` (Dark Maroon) | `#660005` (Deep Red Filter) | 배경에 미세한 노이즈(Noise Texture) 필터를 적용하여 '낡고 불안정한 시스템' 느낌 부여. |
| **손실 수치 ($X$)** | `Cyan Blue (#00FFFF)` 글씨, 크기 84px. | `Orange (#FFA500)` 글씨, 크기 96px (상승률을 강조하기 위해 확대). | **`Critical Red Alert`** (`#B00020`) 글씨, 크기 100px+. 수치가 급증할 때마다 애니메이션 스케일(Scale) 트랜지션 필수. | 손실액 $X$가 증가함에 따라 `#B00020` 색상의 **글리치 효과 (Glitch Effect)**를 강제 적용하여 불안정성 시각화. |
| **시각적 경고** | 없음. 시스템은 안정적으로 보임. | 배경 위에 얇고 깜빡이는 `Orange (#FFA500)` 그라디언트 라인(Horizontal Line)을 추가. | **전체 영역에 걸친 강제한 빨간색 플래시 (Red Flash)**를 주기적으로 오버레이하고, 글자 주변에 `#B00020`의 미세한 떨림(Shake/Jitter) 애니메이션 적용. |

### B. 타이머 모듈 (Countdown Timer: CT)

*   **목적:** '시간 임계치' 경고를 통해 즉각적인 행동을 강제하는 장치.
*   **크기 스펙:** 가로 300px / 높이 150px (원형 또는 직사각형 모듈).
*   **스펙 상세:**
    *   **디자인:** 디지털 시계 스타일의 폰트(예: Stencil, OCR-A) 사용. 네온사인 느낌을 강조하기 위해 내부 발광 효과를 적용.
    *   **상태 변화:** 카운트다운이 남은 시간 임계치($T_{critical}$)에 근접할수록, 숫자의 글자색이 `Cyan Blue` $\rightarrow$ `Orange` $\rightarrow$ **`Critical Red Alert`**로 점진적으로 변경되어야 합니다.
    *   **애니메이션:** 타이머가 1분 미만 남았을 때, 숫자 자체에 '디지털 오류(Digital Error)'처럼 글자가 순간적으로 깨지는 듯한 애니메이션을 3초 간격으로 삽입합니다.

### C. 강제 CTA 모달 (Mandatory Necessity CTA Modal)

*   **목적:** 콘텐츠 소비 중 공포가 최고조에 달했을 때, 구매 버튼이 유일한 탈출구처럼 보이게 하는 장치.
*   **트리거 시점:** LMU에서 Critical Red Alert 발생 직후 또는 특정 핵심 정보 제공 완료 후.
*   **UI/UX 스펙:**
    1.  **전체 레이아웃:** 화면 전체를 덮는 (Full-Screen Overlay) 어둡고 경직된 모달 창 구조.
    2.  **제목 (Title):** `[SYSTEM ALERT: IMMINENT FAILURE DETECTED]`와 같이 시스템 오류 메시지 형태의 타이포그래피 사용.
    3.  **내용:** "현재 손실액($X$)이 안전 임계치를 초과했습니다. 즉각적인 조치가 필수입니다." (절대 '배우세요' 같은 부드러운 언어 금지).
    4.  **핵심 CTA 버튼:** **"생존 시스템 패치 적용 (구매)"** 문구를 사용하며, 이 버튼은 LMU의 `Critical Red Alert`와 동일한 `#B00020` 색상으로 강조하고, 마우스 오버 시 미세하게 깜빡이는(Pulse) 효과를 주어 필수성을 극대화합니다.
