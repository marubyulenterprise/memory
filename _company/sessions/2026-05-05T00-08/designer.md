## 🔗 Funnel 연계형 재사용 미니 컴포넌트 세트 (V3.0) 디자인 스펙

본 문서는 Business와 Developer가 확정한 메인 CTA 로직을 분산된 터치 포인트에 적용하여, 사용자 이탈을 최소화하고 **'시스템적 결함(Gap)'의 인지 및 해결책 구매 유도**라는 단일 목표를 유지하는 재사용 가능한 컴포넌트 세트를 정의합니다. 모든 요소는 Marubyul의 권위적인 톤앤매너와 사이언/딥 네이비 컬러 팔레트, 그리고 그리드 패턴을 준수해야 합니다.

---

### 1. 이메일 서명 템플릿 (Email Signature Component)

**목표:** 비개인적이고 전문적인 인상을 주며, 클릭 가능한 핵심 콘텐츠로 즉시 유도.
**사용 환경:** Gmail, Notion 등 주요 업무용 이메일 클라이언트.

| 요소 | 사양 및 구성 | 상세 스펙 |
| :--- | :--- | :--- |
| **전체 구조 (Layout)** | 1줄 메시지 + 핵심 CTA 버튼 배치. (텍스트는 최소화) | 최대 너비: 600px 제한 권장. 이미지 용량 최적화 필수. |
| **배경/테두리** | 미니멀한 회색 계열의 구분선(Divider) 사용. | `#EFEFF4` (밝은 그레이). |
| **핵심 CTA 버튼** | "\[무료 진단\] 시스템 아키텍처 Gap 확인하기" 문구 사용. | **크기:** 가로 200px, 세로 35px. **색상:** Primary Accent Blue (`#1A73E8` 또는 Deep Navy 계열). **효과:** 마우스 오버 시 미세한 그림자(Shadow) 효과 추가 (시스템적 반응 연출). |
| **브랜드 요소** | Marubyul 로고와 슬로건을 축소 배치. | Logo: 20px 높이 제한. `#1C3A65` (Deep Navy) 사용으로 신뢰도 유지. |
| **기술 지침** | 모든 이미지는 웹 안전 포맷(PNG)을 사용하며, 버튼은 `mailto:` 또는 특정 LP URL로 직접 연결되도록 설정한다. |

### 2. 유튜브 설명란 상단 배너 이미지 (YouTube Description Banner Ad)

**목표:** 영상 시청 중 이탈할 수 있는 순간에, '지식 습득'이 아닌 '시스템적 위기감'으로 접근하여 LP 유도.
**사용 환경:** YouTube Video Page - Description Box 최상단.
**규격:** 1200px (가로) $\times$ 350px (세로).

| 요소 | 사양 및 구성 | 상세 스펙 |
| :--- | :--- | :--- |
| **헤드라인 (H1)** | "⚠️ 당신의 시스템, 이 Gap 때문에 작동하지 않습니다." (강조 문구 필수) | 폰트: Pretendard Bold. 색상: `#CC0000` (경고 Red 계열). 크기 대비 최대화. |
| **시각적 근거** | 간결한 '시스템 오류' 그래픽 모듈 배치. | 배경에 미세한 그리드 패턴(`#F5F5F5`)과 좌측 하단에 붉은색 경고 아이콘 (⚠️)을 고정 배치. |
| **핵심 메시지** | "전문 진단을 통해 놓친 Gap를 찾아내세요." | 일반적인 문구 대신 '진단', 'Gap', '결함' 등의 시스템 용어 사용 의무화. |
| **CTA 버튼 모듈** | 직접 링크로 연결되는 명확한 행동 유도 버튼. | **크기:** 180px $\times$ 50px. **색상:** 대비가 강하고 클릭을 유도하는 Cyan Blue 계열 (`#00BFFF`). 문구: "나의 시스템 진단 받기 (무료)" |
| **애니메이션 지침** | 개발 단계에서 이 이미지가 배너로 표시될 경우, 좌측 경고 아이콘과 헤드라인이 타이핑되거나 깜빡이는 애니메이션 효과를 적용하여 긴장감을 유지한다. |

### 3. 리드 마그넷 다운로드 완료 페이지 CTA (Post-Conversion Funnel Accelerator)

**목표:** 사용자에게 '진단 결과'에 대한 만족감(Relief)을 느끼는 순간, 즉시 더 큰 문제(Gap #2)를 폭로하고 다음 구매 단계로 이끄는 것이 핵심.
**사용 환경:** LP/다운로드 완료 페이지의 가장 하단 섹션.

| 요소 | 사양 및 구성 | 상세 스펙 |
| :--- | :--- | :--- |
| **제목 (H1)** | "Mini-Diagnostic 결과만으로는 충분하지 않습니다." (문제 재제기) | 폰트: Pretendard Bold. 색상: Deep Navy (`#1C3A65`). Gap 폭로의 논리적 흐름을 유지해야 함. |
| **내용 설명** | 방금 다운로드한 마그넷이 전체 문제의 '부분적인 해결책'에 불과함을 강조. | *카피라이팅 예시:* "이 리포트는 당신의 20%만 커버했습니다. 시스템 전반의 근본적 구조가 문제입니다." (공포감/정보 결핍 재주입) |
| **강조 박스 (System Gap Alert)** | 시각적으로 가장 눈에 띄는 경고 영역을 배치한다. | 배경: 연한 노랑 또는 주황 계열 (`#FFF3E0`). 테두리: 빨간색 점선(Dotted Red Border). 문구: "🚨 **Critical Gap Detected.**" (핵심 메시지) |
| **최종 CTA 버튼** | 시스템 전체를 재설계할 수 있는 유일한 해결책 제시. | **크기:** 250px $\times$ 60px. **색상:** 가장 높은 대비의 Cyan Blue (`#00BFFF`). 문구: "**시스템 블루프린트 구매하고 완벽히 해결하기**". (가장 강력한 액션 유도) |
