✍️ Writer: 작업 시작합니다.

## 🚨 [System Alert] 프로토콜 진단 시스템 마이크로 카피 세트

CEO의 지시에 따라, Developer가 구축한 SPA 프로토타입의 사용자 여정(User Journey) 단계별 긴박감과 전문성을 극대화하는 시스템 경고 문구 및 UI 텍스트를 작성했습니다. 모든 카피는 일반 안내문이 아닌, **'위기 관리 매뉴얼'**처럼 느껴지도록 설계되었습니다.

---

### 🟢 Stage 1: 진단 시작 단계 (Initial Hook & Mandate)
*(사용자가 페이지에 진입했을 때 가장 먼저 마주하는 메시지)*

| 위치 | 유형 | 카피라이팅 (Korean) | UX 지침 및 의도 |
| :--- | :--- | :--- | :--- |
| **페이지 헤드라인** | 🚨 System Alert Title | **[경고] 구조적 무지 자각 모니터링 시스템 활성화 필요** | '경고'와 '모니터링'을 결합하여 공포감과 전문성을 동시에 부여. |
| **서브 카피 (본문)** | Mandatory Text | "현재 귀하의 자동화 아키텍처는 잠재적/구조적 취약점을 내포하고 있습니다. 본 시스템은 단순 점검이 아닌, **결함 발견을 위한 필수 진단 프로토콜**입니다. 모든 데이터 입력은 생존에 직결됩니다." | '취약점', '필수', '생존' 등의 단어로 위기감 고조. |
| **Call to Action (CTA) 버튼 1** | Primary Button Copy | **[진단 시작] 구조적 위험 분석 개시** | 일반적인 "진행하기" 대신 '개시'와 '분석'을 사용하여 권위 부여. |
| **Loss Meter 초기 문구** | Micro-Copy/Status | "현재 리스크 지수: 0% (기준점). 진단 프로토콜 가동 전, 잠재적 결함 요인을 탐지할 수 없습니다." | 손실률이 낮은 상태에서 시작하여 긴장감을 쌓을 여지를 남김. |

### 🟡 Stage 2: 질문/데이터 입력 단계 (Data Input & Validation)
*(사용자가 정보를 입력하는 과정에서 시스템이 개입하며 경고를 주는 메시지)*

| 위치 | 유형 | 카피라이팅 (Korean) | UX 지침 및 의도 |
| :--- | :--- | :--- | :--- |
| **섹션 타이틀** | Section Header | **[필수 데이터 입력] 취약점 매핑을 위한 정보 수집 단계** | '수집'과 '취약점 매핑'으로 단순 질문이 아닌 과학적 분석처럼 보이게 함. |
| **입력 필드 Placeholder** | Field Prompt | "가장 해결하기 어렵다고 느끼는 자동화의 병목 구간은 무엇입니까? (구체적으로 기재 요망)" | '어려운 점' 대신 '병목 구간', '기재 요망' 등 전문 용어를 사용. |
| **필수 항목 누락 경고** | Validation Error | "🚨 [오류 코드 403]: 필수 정보가 누락되었습니다. 이 데이터는 분석에 결정적인 공백을 만듭니다. 반드시 재검토하십시오." | 일반적인 '필수 입력' 대신, 시스템 코드를 사용한 오류 메시지 처리. |
| **다음 단계 버튼** | Secondary Button Copy | **[데이터 검증] 다음 프로토콜 단계로 이동** | '계속' 대신 '검증', '프로토콜'을 사용하여 다음 단계가 필수적임을 강조. |

### 🔴 Stage 3: 결과 대기 및 처리 단계 (Processing & Climax)
*(사용자가 버튼 클릭 후 로딩 화면에서 경험하게 되는 최대 긴장감의 메시지)*

| 위치 | 유형 | 카피라이팅 (Korean) | UX 지침 및 의도 |
| :--- | :--- | :--- | :--- |
| **로딩 스크린 헤드라인** | System Alert Title | **[진행 중] 구조적 무결성 검증 프로토콜 가동...** | '검증'과 '프로토콜'을 사용하여 기술적인 권위와 긴박감을 최대로 끌어올림. |
| **로딩 로직 (Micro-copy)** | Loading Status Update | ">> 1/3단계: 시스템 결함 패턴 분석 중..."<br>">> 2/3단계: 자가학습 구조적 무지 자각도 측정 중..."<br>("...데이터 처리 완료. 최종 리스크 보고서 생성 대기.") | 로딩 과정을 단계별로 나누어 사용자에게 '작동하는 느낌'을 제공하고, 핵심 단어를 노출. |
| **진단 결과 임박 경고** | Warning Pop-up (Pre-Result) | "⚠️ **경고:** 분석이 완료되었습니다. 현재 시스템에 심각한 구조적 오류가 감지되었습니다. 즉시 보고서를 열람하십시오." | 결과를 기다리는 순간에도 불안감을 최고조로 유지하며, 다음 행동을 강제적으로 유도. |
| **최종 CTA 버튼** | Final Action Button Copy | **[필수 조치] 종합 진단 리포트 열람 (클릭 전 손실 예측)** | '읽기'가 아닌 '필수 조치', '예측' 등의 단어를 사용하여 다음 단계로의 이동을 생존 문제처럼 만듦. |
