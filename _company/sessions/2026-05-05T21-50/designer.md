## ✨ 산출물: ASV Funnel State Machine 인터랙션 디자인 사양서 v3.0

### 1. 목적 및 범위
*   **목적:** 사용자가 '측정 가능한 구조적 불안감(ASV)'을 느끼고, 최종적으로 고가치 컨설팅 구매로 이어지는 모든 단계의 감성적/시각적 경험을 극대화한다.
*   **범위:** ASV 점수 입력 $\to$ 측정 과정 (Progressive Disclosure) $\to$ Critical Failure State 진입 $\to$ CTA 및 결제 정보 입력 영역까지 전 과정.

### 2. 핵심 인터랙션 정의: 'Critical Failure' 상태 폭로 시퀀스
(최대 공포감 증폭 구간)

| 단계 | 시간 코드 (Timecode) | UI 변화/요소 | 애니메이션 로직 및 효과 | 타이포그래피 스펙 |
| :--- | :--- | :--- | :--- | :--- |
| **1. Pre-Failure** (경고 시작) | 0.0s $\to$ 0.5s | 배경에 미세한 노이즈 패턴(Noise Texture) 투사. 메인 점수 수치 주변에 경계선 깜빡임 발생. | `opacity`가 0.8에서 1로 급격히 변화하는 듯한 '글리치' 애니메이션 (좌우 이동). | **폰트:** Deep Navy/Cyan Blue 대비 유지. **색상:** Warning Yellow (`#FFC300`)을 점진적으로 삽입. |
| **2. Failure Trigger** (결함 폭로) | 0.5s $\to$ 1.5s | 화면 전체에 강렬한 `빨간색 경고 오버레이`가 빠르게 깜빡임(Flash). ASV 스코어 수치가 임계점(`ASV > Threshold`)을 초과하며 **강제로 변동**하는 시각적 연출. | **핵심:** 빨간색 (`#D91E2A`)의 10Hz 근접한 깜빡임 효과 (Strobe Effect). 배경에 무작위 노이즈와 함께 `Data Corruption` 글리치 패턴 오버레이. | **폰트 크기/굵기:** 기존 대비 150% 확대, Bold 적용. **텍스트 내용:** "SYSTEM FAILURE DETECTED" (시스템 오류 메시지처럼 고정). |
| **3. Deep Critical State** (공포 유지) | 1.5s $\to$ CTA 진입 직전 | 화면의 대부분이 빨간색 경고창, 노이즈 패턴으로 뒤덮임. 메인 콘텐츠는 왜곡되어 보이고(Distorted), 중앙에 결함 보고서 형식의 문구가 플래시처럼 나타남. | **효과:** 모든 요소가 미세하게 흔들리는 (Jittering) 효과 적용. 배경 텍스트/데이터들이 위에서 아래로 '떨어지는' 듯한 모션 처리. | **폰트:** Monospace 계열을 사용하여 기계적, 기술적 권위 부여. 경고 문구는 `[ERROR: ASV THRESHOLD EXCEEDED]` 형식으로 고정. |

### 3. CTA 및 결제 정보 영역 디자인 사양 (권위 극대화)
(사용자가 '구매'가 아닌 '시스템 복구/생존 장치 구매'를 하는 느낌을 주어야 함.)

#### 🅰️ 최종 CTA 버튼 (`Blueprint Acquisition`)
*   **비주얼 컨셉:** 단순 버튼 X, **[접근 권한 요청 모듈]**의 형태로 디자인.
*   **디자인 요소:**
    *   버튼 주변에 `데이터 스캔(Data Scan)` 효과를 구현 (Cyan Blue 라인이 좌우로 빠르게 움직이며 검증하는 애니메이션).
    *   버튼 자체는 Dark Gray/Deep Navy 바탕에 Cyan Blue의 테두리 및 활성화 상태 광택을 적용.
    *   **호버(Hover) 액션:** 버튼 위에 마우스가 올라오면, `[VERIFICATION IN PROGRESS...]`라는 텍스트가 타이핑 효과와 함께 나타났다가 사라짐.
*   **문구 가이드:** "ASV 시스템 복원 프로토콜 다운로드" 또는 "Blueprint 접근 권한 요청"

#### 🅱️ 결제 정보 입력 필드 (Payment Module)
*   **비주얼 컨셉:** 일반적인 웹폼 X, **[보안 인증 인터페이스]**처럼 보이도록 구성.
*   **디자인 요소:**
    *   입력 필드는 단순 박스가 아닌, 주변에 미세한 `그리드 라인`이 새겨져 있고, 활성화된 필드의 경계선만 Cyan Blue로 빛남.
    *   필드를 클릭하거나 값을 입력할 때마다, 해당 필드 옆이나 아래에 작은 **[DATA VALIDATION: OK]** 텍스트가 초록색으로 빠르게 깜빡인 후 사라지는 피드백을 제공.
    *   결제 수단 선택은 아이콘화하고, 각 아이콘 주변에 '암호화됨(Encrypted)' 표시를 시각적으로 삽입.

### 4. 구현 가이드라인 요약 (Technical Specification)

| 요소 | 색상 코드 (Hex Code) | 애니메이션 유형 | 핵심 로직 요구 사항 |
| :--- | :--- | :--- | :--- |
| **Critical Red** | `#D91E2A` | Strobe / Flash | 주파수 제어 필수. 단순히 빨간색을 넣는 것이 아니라, 시간차를 두고 강제 깜빡임 구현. |
| **System Noise/Glit** | N/A (Pixel Distortion) | Loopable Effect | 노이즈 텍스처와 글리치 패턴(Shifted RGB color channels)을 겹치는 방식으로 적용해야 함. |
| **Cyber Blue Accent** | `#00FFFF` (Cyan Blue) | Scanning / Pulsing | CTA 및 핵심 기능에만 제한적으로 사용. 빛나는 듯한 (`Glow`) 효과를 강조하여 첨단 기술 느낌 부여. |
