## 🎯 Master Funnel Flow (3단계 구조) 상세 설계

본 마스터 플로우는 사용자의 심리적 취약점(ASV 점수 하락)을 단계적으로 증폭시켜, 결국 외부 솔루션에 의존하게 만드는 **'시스템적 트랩 구조'**를 갖습니다.

| 단계 | 목적 (심리 상태) | 핵심 액션/콘텐츠 매체 | 주요 메시지 전환 |
| :--- | :--- | :--- | :--- |
| **Stage 1: 공포 유도 (The Hook)** | **인지적 결함 인식** *(“무언가 잘못되었다.”)* | 유튜브/인스타그램 숏폼 콘텐츠 (Writer) | 단순 정보 전달 $\to$ 구조적 시스템 결함 폭로. |
| **Stage 2: 데이터 포획 및 불안 증폭 (The Trap)** | **개인화된 공포 경험** *(“내 문제는 진짜 심각하다.”)* | 랜딩 페이지 인터랙티브 프로토타입 (Designer) | 추상적 공포 $\to$ 측정 가능한 수치(ASV Score)로 구체화. |
| **Stage 3: 구매 전환 (The Solution)** | **유일한 생존책 확신** *(“이것만이 유일한 해결책이다.”)* | 최종 CTA 페이지/웹 백서 (Writer, Designer) | 지식의 결핍 $\to$ 필수 시스템 설계도(Blueprint) 구매. |

## 🛠️ 단계별 에이전트 작업 목록 및 예상 산출물

| Funnel Stage | 핵심 목표 | 필요한 주체 | 요구되는 액션/작업 내용 (다음 스텝) | 예상 최종 산출물 (Deliverable) |
| :--- | :--- | :--- | :--- | :--- |
| **Stage 1: 공포 유도** | 트래픽 확보 및 ASV 문제의 존재 각인. | Writer, Designer | ① 숏폼 콘텐츠를 통해 '시스템 결함'이라는 개념을 대중화하고(글리치/레드 경고 연출), ② LMI 자가 진단 페이지로 **강제 유입**시키는 Call-to-Action (CTA) 설계 및 스크립트 확정. | ✅ 릴스/쇼츠 시퀀스 최종본 (4개 이상) <br>✅ 'ASV 점수 체크' 전용 랜딩 페이지 최상위 섹션 와이어프레임 |
| **Stage 2: 데이터 포획** | 사용자에게 개인화된 공포를 경험시키고 데이터를 수집. | Designer, Developer | ① 인터랙티브 프로토타입의 기술적 구현(API 연동) 및 안정성 테스트 (Developer 필수). ② 사용자가 점수를 입력하는 순간, Writer가 제시한 **'클라이맥스 카피'**가 시각적으로 폭발하며 불안감을 증폭시키는 로직 구현. | ✅ 작동 가능한 ASV Score 측정 API 백엔드 (Testable Code) <br>✅ Figma 기반 인터랙티브 Prototype V2.0 (Full Flow) |
| **Stage 3: 구매 전환** | 공포에서 벗어날 유일한 방법으로 솔루션 판매. | Writer, Designer | ① 최종 상품(Blueprint)의 가치를 '지식'이 아닌 '**생존 장치**'로 포지셔닝하는 카피 완성 (Writer). ② 구매 버튼 클릭 직전에 망설이는 사용자에게 심리적 압박을 주는 **Exit Intent Pop-up** 및 결제 페이지 UI/UX 구현. | ✅ 최종 판매 논리(카피) 확정본 <br>✅ 고단가 상품 전용 랜딩 페이지 마스터 파일 (구매까지의 모든 여정 포함) |

## 📈 다음 주 집중 KPI 및 측정 지표

다음 자율 사이클에서는 **'콘텐츠 제작 효율성 극대화'**와 **'퍼널 전환 최적화'**에 초점을 맞춥니다.

1.  **핵심 성과 지표 (KPI): Conversion Funnel Completion Rate**
    *   측정 목표: Stage 1 유입자 중 Stage 2까지 도달한 비율 및, Stage 3 구매로 이어진 최종 전환율(CVR)을 최우선으로 측정합니다.
    *   필요 활동: Stage 2 (LMI 계산기)의 A/B 테스트 그룹 설정을 시작하고, 어떤 후크 메시지(Writer 카피 버전)가 가장 높은 데이터 입력률을 보이는지 추적해야 합니다.

2.  **기술 및 자산 지표:** **ASV Score API 안정화율 (Target: 99% 이상)**
    *   측정 목표: ASV 점수 계산 로직이 모든 환경(모바일/PC)에서 오류 없이 작동하는 것을 최우선으로 합니다.
    *   필요 활동: Developer가 Stage 2의 통합 테스트 코드를 완료하고, Designer가 이를 바탕으로 실제 프로토타입을 완성해야 합니다.

3.  **콘텐츠 지표:** **숏폼 콘텐츠당 리드 마그넷 유도율 (Target: N/A $\to$ Y)**
