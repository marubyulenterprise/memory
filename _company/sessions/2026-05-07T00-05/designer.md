## 🚨 Red Alert 시스템 보고서 핵심 에셋 패키지 v1.0
요청하신 'Red Alert' 가상 진단 보고서의 핵심 상호작용 요소 및 비주얼 컨버전스 자산 세트를 제작했습니다. 이 에셋들은 모두 중앙 관제 시스템 UI를 기반으로 하며, 개발팀이 즉시 SVG/PNG 형태로 구현 가능하도록 상세한 스펙과 사용 지침을 포함합니다.

### 💾 패키지 개요
*   **주제:** 구조적 무지 자각(ASV) 진단 보고서 인터페이스
*   **톤앤매너:** 중앙 관제 시스템 (Centralized Control System), 기술적, 긴급함
*   **핵심 컬러 팔레트:**
    *   Primary Danger: `#CC0000` (위기/경고)
    *   Secondary Alert: `#FFC107` (주의/임계점)
    *   Background Base: `#0A192F` (딥 네이비, 시스템 백그라운드)
    *   Text/Accent: `#E0FFFF` (라이트 사이언 블루, 데이터 표시)

### 1. ASV 점수 게이지 컴포넌트 (SVG 기반 애니메이션 요소)

**[파일명 예시] `asv_gauge_svg.svg`**
*   **목적:** 사용자의 구조적 무지 지수를 시각적으로 보여주며, 하락 및 위기감을 증폭시키는 핵심 요소.
*   **구조:** 아날로그 바늘 게이지 + 디지털 수치판 조합.

| 요소 | 스펙/규칙 | 상세 설명 (개발자 가이드) |
| :--- | :--- | :--- |
| **게이지 본체** | SVG, 360도 회전형. | 시스템 메탈릭 질감 표현 (옅은 그라데이션). 배경은 `#1F2A49`로 설정. |
| **점수 영역 색상** | 단계별 변화: Green $\rightarrow$ Yellow $\rightarrow$ Red | 🟢 `(90-100)` 녹색 (안전) $\rightarrow$ 🟡 `(50-89)` 노란색 (주의) $\rightarrow$ 🔴 `(0-49)` 빨간색 (위기/경고). **현재는 강제적으로 Red 영역을 배경으로 깔아야 함.** |
| **바늘 (Needle)** | SVG, 금속 질감. | 바늘의 끝부분에 `#FFC107` 색상 경계 라인을 넣어 임계점 강조. |
| **디지털 출력** | 폰트: `Monospace`, 크기: 64pt. | 실시간 점수 표시 위치. 값이 떨어질 때마다 깜빡이는(Blink) 애니메이션 효과 필수 (CSS/JS 적용). |
| **위기 메시지** | 시스템 경고 배너 (`Alert Banner`). | 현재 ASV 점수가 임계점 이하로 떨어졌을 경우, 게이지 상단에 `#CC0000` 배경의 텍스트("CRITICAL DEVIATION DETECTED")를 플래시 효과와 함께 표시. |

### 2. '프로토콜 활성화' 버튼 컴포넌트 (SVG/PNG 기반)

**[파일명 예시] `protocol_activate_button.svg`**
*   **목적:** 단순 구매(Buy)가 아닌, 생존을 위한 시스템적인 **강제 행동 유도**. 권위와 절박감을 극대화해야 함.
*   **구조:** 일반 버튼 형태를 탈피하여 '시스템 오버라이드 패널'처럼 디자인.

| 요소 | 스펙/규칙 | 상세 설명 (개발자 가이드) |
| :--- | :--- | :--- |
| **기본 배경** | `#1A304F` (딥 블루-그레이). | 얇은 격자 패턴(Grid Pattern, 점선)을 배경에 깔아 기술적 느낌 강화. |
| **프라이머리 버튼 영역** | `Protocol Activation` 문구 삽입. | 일반적인 버튼 모양이 아닌, 사각형의 경계가 있는 '시스템 패널' 형태로 디자인. |
| **활성화 상태 (Hover/Click)** | 플래시 효과 + 색상 변화. | 마우스 오버 시 `#FFC107`로 테두리가 빛나며(Glow effect), 클릭 직전에는 배경이 잠시 깜빡이는(`[INITIATING...]`) 애니메이션 삽입 필수. |
| **CTA 텍스트** | `PROTOCOL ACTIVATION (Requires Clearance)` | 문구 자체에 '명령어' 같은 느낌을 주도록 소문자, 대괄호 등을 활용하여 구조적 권위 부여. |

### 3. ASV Funnel 결함 경고 모듈 (Reusable Asset)

**[파일명 예시] `asv_failure_module.png`**
*   **목적:** 콘텐츠 전반에 걸쳐 사용될 수 있는 '시스템 오류' 시각 언어 표준화.
*   **구조:** 중앙 집중형의 경고 메시지 박스.

| 요소 | 스펙/규칙 | 상세 설명 (개발자 가이드) |
| :--- | :--- | :--- |
| **배경 패턴** | 노이즈 필터 + 그리드 왜곡 효과. | 배경에 미세한 글리치(Glitch) 효과나 픽셀화된 왜곡 패턴을 오버레이하여 시각적 불안감을 조성. |
| **헤더 라벨** | `[SYSTEM ERROR CODE: ASV-302]` | 중앙 상단에 시스템 코드 형태로 경고 메시지를 배치 (권위 부여). |
| **메시지 본문** | `#CC0000`으로 강조된 핵심 문구. | "현재의 무지는 치명적 결함입니다." 등 직접적으로 공포를 자극하는 문구를 넣을 Placeholder 역할 수행. |
