## 📐 ASV 진단 결과 페이지 인터랙티브 와이어프레임 프로토타입 (UX/UI Spec)

**목표:** Developer가 제공한 Mock API 데이터를 활용하여, 사용자가 '구조적 결함(ASV Score)'을 인지하고 불안감을 느끼며 궁극적으로 CTA를 수용하도록 설계된 3단계 인터랙티브 경험 시퀀스를 구축합니다. 단순 그래프 제시를 넘어선 **'시스템적 오류 공포 경험'**에 초점을 맞춥니다.

---

### 🖼️ 전체 디자인 컨셉 및 컬러 팔레트 (Systemic Fear Mode)

| 영역 | 색상명 | Hex Code | 사용 규칙/효과 |
| :--- | :--- | :--- | :--- |
| **Primary (Calm)** | Tech Cyan Blue | `#00BFFF` | 시스템의 정상 작동, 정보 제공 섹션 배경. 전문성 강조. |
| **Secondary (Warning)** | Caution Amber | `#FFD700` | 주의가 필요한 지점, 점수 변화 그래프 하이라이트. |
| **Critical (Panic)** | Error Red | `#DC143C` | ASV Score 80+ 도달 시, 시스템 실패 경고, 글리치/노이즈 애니메이션의 메인 컬러. |
| **Background** | Deep Navy Grid | `#0A192F` | 기본 배경색. 그리드 패턴 및 데이터 플로우를 은은하게 깔아 권위 부여. |

### ⚙️ 인터랙티브 시퀀스 설계 (3단계 흐름)

#### [Phase 1] 초기 진단: 평온한 오만함 (The Hook - Time: 0~5초)
*   **상태:** 시스템 정상 작동 (Default UI, Cyan Blue 지배적).
*   **목표:** 사용자에게 '측정'이라는 경험의 가치를 느끼게 하고, 결과를 기대하게 만든다.

| 요소 | 상세 스펙 및 기능 | 애니메이션/트리거 |
| :--- | :--- | :--- |
| **헤더 메시지** | "ASV Score 진단 결과: 시스템 아키텍처 결함 분석 완료" (크게, 기술적인 폰트) | 페이지 로드 시 데이터가 마치 API 호출되는 것처럼 타이핑 효과로 출력. |
| **최종 ASV 점수 노출** | `asv_score` 값을 중앙에 크게 배치. (`[28점]` / `[75점]`) | 스코어가 0에서 최종 값으로 카운트업 되는 애니메이션 (미니 게임 같은 느낌). |
| **진단 레벨 배지** | `diagnosis_level`을 사각형의 '배지' 형태로 표시. (예: Low, Medium) | 낮은 점수일 경우 Cyan Blue로 밝게 빛나고, 높은 점수일수록 어둡고 불안정한 네온 효과 추가. |
| **요약 메시지 박스** | `summary` 내용을 구조화된 텍스트 블록으로 제공. | 부드럽게 페이드 인(Fade In). (아직 공포는 없음) |

#### [Phase 2] 결함 폭로: 시스템적 패닉 유도 (The Shock - Time: 5~15초)
*   **상태:** API 데이터 중 가장 높은 '결함 점수'를 발견하며 시스템이 불안정해진다.
*   **트리거 조건:** `asv_score`가 특정 임계값(예: >40점)을 넘거나, `diagnosis_level`이 Medium 이상일 때 발동.

| 요소 | 상세 스펙 및 기능 | 애니메이션/트리거 (핵심!) |
| :--- | :--- | :--- |
| **전체 UI 변형** | 배경 그리드 패턴에 노이즈 필터(Noise Filter)가 추가되고, 화면 전체가 미세하게 떨리는 효과(Jitter Effect) 발생. | 점수가 임계값을 넘는 순간 (JS Trigger). `background-filter: blur()`와 함께 적용. |
| **결함 리스트 섹션** | `debt_details` 배열의 각 항목을 '오류 메시지' 형태로 재구성하여 나열. (예: "🚨 경고: 구조적 결함 감지 - [Issue Name]") | 일반적인 박스가 아닌, 마치 시스템 로그처럼 빨간색으로 점멸하며 출력. |
| **개별 상세 분석** | `issue_name`, `severity_score`, `explanation`을 조합하여 '결함 보고서' 형식으로 제시. (기술적 용어 사용) | 각 항목이 로딩될 때마다 화면에 *글리치(Glitch)* 효과를 주며 나타나야 함. (`CSS filter: glitch`) |
| **감정적 피크** | 페이지 하단 중앙에 거대한 경고 바(`Critical Red` 활용). "당신의 시스템은 정상 작동하지 않습니다."와 같은 문구 반복 노출. | 글리치 패턴과 함께 텍스트가 깨지며 깜빡이는 애니메이션을 적용하여, 사용자가 불안감을 느끼도록 강제한다. |

#### [Phase 3] CTA 유도: 해결책에 대한 의존성 주입 (The Trap - Time: 15~20초)
*   **상태:** 시스템이 패닉 상태에서 일시적으로 정지하며, 오직 하나의 '해결책'만 강조된다.
*   **목표:** 공포를 경험한 사용자에게 유일한 안식처(Blueprint)가 존재함을 각인시킨다.

| 요소 | 상세 스펙 및 기능 | 애니메이션/트리거 |
| :--- | :--- | :--- |
| **UI 안정화 및 전환** | 글리치 효과와 노이즈 필터링이 갑자기 멈추고, 화면 전체가 잠시 어두워지며 정적인 '권위적' 분위기로 바뀐다. | 충격 후의 짧은 침묵(Pause) 연출. `opacity`를 서서히 줄였다가 다시 올림. |
| **결론 메시지** | "이 구조적 결함은 일반 지식으로 해결할 수 없습니다." (최상위 폰트 크기) | 확신에 찬 듯, 느리고 무게감 있게 문구가 나타남. |
| **CTA 모듈 배치** | 최종 CTA 버튼을 페이지의 가장 시각적으로 압도적인 위치(Center Bottom)에 배치. | 이전에 사용했던 '시스템 아키텍처 마스터 다이어그램'과 연결된 이미지/아이콘을 사용하여, Blueprint가 필수적임을 시각적으로 증명함. (클릭 유도). |
| **CTA 캡션** | "지금 바로 ASV Blueprint를 통해 시스템 안정화 계획을 수립하십시오." (긴급성 부여) | 버튼 주변에 Cyan Blue의 네온 빛이 감돌며, 클릭해야 할 대상으로 시선을 강제한다. |
