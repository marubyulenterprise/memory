### 💡 [스크립트 1] API 의존성 환상 - '어제까지 되던 게 오늘 안 되는 공포'
**[주제]:** 플랫폼 종속성 리스크 (Platform Dependency Risk) 무시.
**[ASV 핵심 메시지]:** 시스템의 안정성은 도구가 아니라, 다중 경로 설계에 달려있다.

| 시간대 | 내용/화면 구성 지침 | 나레이션 톤 & 스크립트 (ASV 강조) | 자막/효과 지침 |
| :---: | :--- | :--- | :--- |
| **0-3초** | [강렬한 후킹] 화면에 빨간색 경고 메시지(ERROR)가 빠르게 깜빡이며 시작. 불안정한 기계음 BGM. | (빠르고 위협적인 톤) 잠깐! 당신의 자동화 파이프라인, 정말 안전하다고 착각하고 계신가요? **🚨 시스템 오류 발생 직전입니다.** | 자막: 🔥 경고: 지금 바로 확인해야 할 치명적 결함 |
| **3-10초** | [문제 제기/공포] 'API 연동' 다이어그램이 갑자기 붉은색으로 변하며 끊어지는 애니메이션. 무력감을 주는 카메라 워크. | (전문가 톤) 대부분의 초보자는 API 연결만 성공하면 끝이라고 생각합니다. 하지만, **한 서비스의 정책 변경** 하나에 모든 것이 마비되는 구조적 결함을 간과하고 있습니다. | 자막: ❌ 도구 사용법이 전부가 아니다! / 플랫폼 종속성 리스크 (빨간색) |

### 💡 [스크립트 2] 프롬프트 중심 사고 - 'AI는 마법 상자가 아니다'
**[주제]:** 시스템 아키텍처 관점의 사고 부재. (Prompt = Output이라는 착각)
**[ASV 핵심 메시지]:** AI는 최종 결과물일 뿐, 근본적인 데이터 구조화가 선행되어야 한다.

| 시간대 | 내용/화면 구성 지침 | 나레이션 톤 & 스크립트 (ASV 강조) | 자막/효과 지침 |
| :---: | :--- | :--- | :--- |
| **0-3초** | [강렬한 후킹] 손으로 'STOP' 제스처를 취하며 화면에 경고 UI 오버레이. 혼란스러운 데이터들이 지나가는 효과. | (단호하고 비판적인 톤) 잠시만요. ChatGPT에게 질문을 던지는 것, 그것이 전부가 아닙니다! **⛔️ 당신은 지금 AI의 능력을 근본적으로 오해하고 있습니다.** | 자막: 🔥 STOP! 프롬프트 만능주의에 속지 마라 |
| **3-10초** | [문제 제기/공포] 'Prompt In $\rightarrow$ Output Out'이라는 단순화된 흐름도가 깨지고, 그 앞 단계의 공백(Gap)이 빨간색으로 강조됨. | (전문가 톤) AI는 마법 상자가 아닙니다. 결과물은 입력 데이터와 **그 데이터를 구조화하는 프로세스**에서 나옵니다. 전처리 과정, 로직 분기... 이 핵심 단계를 무시하면, 아무리 좋은 프롬프트도 쓰레기가 됩니다. | 자막: 📉 문제의 원인: Input Data Cleansing 부재 (구조적 결함) |
| **10-20초** | [해결책 제시/CTA] 복잡한 데이터 흐름을 보여주는 시스템 다이어그램이 깔끔하게 정리되는 모션 그래픽. | 진짜 자동화는 '질문'하는 방법을 아는 게 아니라, **데이터를 어떻게 설계하고 흘려보낼지** 구조를 이해하는 겁니다. 이 시스템적 사고방식 자체가 가장 큰 결함입니다. (잠시 멈춤) 완벽한 프로세스 진단이 필요하다면, 지금 바로 Blueprint를 확인하세요. | 자막: ✅ 시스템 아키텍처 관점 확보 / CTA: [Blueprint] 나의 데이터 흐름을 점검하라 |

### 💡 [스크립트 3] 전처리/로직 결함 - '데이터가 말해주는 위험 신호'
**[주제]:** 데이터 정제 및 로직 분기(Conditional Logic)의 부재. (최적화되지 않은 입력값 사용)
**[ASV 핵심 메시지]:** 결과물보다, 어떤 데이터를 가져올 것인지에 대한 '선택 과정'이 시스템을 결정한다.

| 시간대 | 내용/화면 구성 지침 | 나레이션 톤 & 스크립트 (ASV 강조) | 자막/효과 지침 |
| :---: | :--- | :--- | :--- |
| **0-3초** | [강렬한 후킹] 빨간 경고음과 함께 화면에 'INVALID DATA'라는 문구가 크게 나타남. 빠르게 자료들이 섞이고 오류를 일으키는 시각 효과. | (충격적인 톤) 잠깐! 당신이 지금 사용하고 있는 데이터가, **이미 시스템을 망가뜨리고 있습니다.** 데이터를 그냥 쓰지 마세요! | 자막: 🔥 경고: 입력값이 치명적 결함이다! / 데이터 구조 점검 필수 |
| **3-10초** | [문제 제기/공포] 'Raw Data' 더미와 깔끔한 'Clean Data'가 대비되는 화면. 원본 데이터를 쓰다가 시스템이 멈추는 애니메이션 연출. | (전문가 톤) 가장 흔하고 무서운 실수는, 데이터의 **‘질(Quality)’**과 **‘흐름(Flow)’**을 고려하지 않는 것입니다. 구조화되지 않은 Raw Data를 그냥 넣으면, 아무리 강력한 엔진도 작동할 수 없습니다. | 자막: 🚫 원시데이터 사용 금지 / 전처리 로직 결함 (Critical) |
| **10-20초** | [해결책 제시/CTA] 데이터 필터링 및 정제 과정(Filter $\rightarrow$ Logic $\rightarrow$ Output)이 마치 공정 라인처럼 차분하게 시각화됨. | 자동화는 데이터를 '수집'하는 게 아니라, 필요한 정보만 '추출하고 재배치' 하는 고도화된 프로세스입니다. 이 과정을 시스템적으로 설계해야 합니다. (강조하며 템포 조절) 당신의 데이터 흐름은 현재 정상입니까? 지금 바로 진단받으세요! | 자막: ✅ 구조적 무지 탈피, 데이터 파이프라인 확립 / CTA: [진단 요청] 나의 데이터 경로를 재설계하라 |
