## ⚙️ [Design System Update] 고위험 인터랙티브 컴포넌트 스펙 시트 v3.0
**(대상: Figma Prototypes / 개발팀 전달용)**

CEO 지시에 따라, 기존에 제작된 '글리치/경고 UI 에셋 패키지' 중 사용자의 불안감($E_d$)을 극대화할 수 있는 3가지 핵심 인터랙티브 요소의 상세 스펙 및 상태 변화 로직을 Figma 기준으로 재정의합니다.

---

### 🔴 1. CRITICAL: 타이머 기반 '시스템 임계 경고 (System Threshold Warning)'
*   **목적:** 사용자에게 시간 제한과 기회 상실의 위협을 주어, 즉각적인 행동(결제/다운로드)을 강제하는 가장 강력한 장치.
*   **트리거:** 페이지 로드 직후 또는 CTA 근처에 진입했을 때 타이머가 작동 시작 (Timer: 60초부터 카운트다운).

| 상태 (State) | 시각적 스펙 (Visual Spec) | 인터랙션 로직 (Logic & Timing) | $E_d$ 효과 |
| :--- | :--- | :--- | :--- |
| **$\text{S}_0$: 초기/안심** | 타이머가 부드럽게 카운트다운되는 모습. 배경은 표준 딥 네이비 (`#1D2F4A`). 경고창은 비활성화 상태로 대기. | **(Start)**: 60초부터 시작. 초 단위 숫자가 빠르고 정확하게 업데이트됨 (Smooth Transition). | 낮은 위협감. '곧 시간이 지나간다'는 무의식적 압박만 존재. |
| **$\text{S}_1$: 경고 증가/부분 안심** | 카운트다운이 25% 이하로 떨어질 때, 타이머 주변에 미세한 노이즈 패턴(Grain Noise)이 추가됨. 폰트 색상이 사이언 블루(`#00FFFF`)에서 오렌지 계열(`\#FF9800`)로 서서히 변색됨. | **(Transition)**: $T < 25\%$. 배경에 낮은 주파수의 깜빡임(Flickering) 효과가 주기적으로 삽입됨 (Frequency: 1Hz). | '뭔가 이상하다'는 의심을 심어주지만, 아직 정보적 혼란 수준. |
| **$\text{S}_2$: 임계 경고/위기 고조** | 카운트다운이 5% 이하로 떨어질 때 (**Interruption Point**). 타이머 자체가 화면 중앙에 폭발적으로 오버레이됨. 배경 전체가 간헐적인 글리치(Horizontal Glitch Bar)를 일으키며 진동함. | **(Interruption)**: $T < 5\%$. 시각 효과와 동시에, `BEEP-BOOP`하는 비정상적인 시스템 알람 사운드(`Siren Waveform`)가 최고 볼륨으로 재생됨 (Duration: 3초). 타이머 숫자가 빨간색 경고 (`#D90000`)로 바뀜. | **최대 $E_d$ 유발.** '시스템이 오작동 중이다', '데이터가 손실되고 있다'는 공포감을 극대화하여 즉각적인 결정을 강제함. |

---

### 👾 2. HOVER: 마우스 오버 기반 '데이터 노이즈 및 변조 (Data Corruption)'
*   **목적:** 사용자가 특정 영역(CTA, 핵심 키워드 등)에 집중하는 순간마다, 그 정보의 신뢰성에 의문을 품게 만들어 불안감을 증폭시키는 요소.
*   **트리거:** 마우스 포인터가 컴포넌트 위에 진입하거나 지나갈 때 (On Hover).

| 상태 (State) | 시각적 스펙 (Visual Spec) | 인터랙션 로직 (Logic & Timing) | $E_d$ 효과 |
| :--- | :--- | :--- | :--- |
| **$\text{S}_0$: 기본 상태** | 텍스트 및 배경은 정상적인 Deep Navy/Cyan Blue 톤을 유지. | 마우스 오버 전에는 아무런 변화 없음. (평온함). | 낮은 집중도. 안전하다고 느끼게 함. |
| **$\text{S}_1$: 노이즈 유입/경고** | 마우스 포인터가 영역에 진입하는 순간, 해당 컴포넌트 위에 미세한 데이터 스크래치(Noise Texture)가 덮어씌워짐. 배경의 글자가 무작위로 픽셀 단위로 '튀는' (Jittering) 효과 발생. | **(Transition)**: Hover In. 진입 시점에서 노이즈 패턴의 강도가 0% $\to$ 20%까지 300ms 동안 급격히 증가함. 동시에, 아주 낮은 주파수의 백색 소음(`Static Hiss`)을 삽입하여 청각적 불안감을 유발함. | '여기서 뭔가 잘못되고 있다', '이 정보는 완벽하지 않다'는 의혹(정보 비대칭성 $E_d$)을 심어줌. |
| **$\text{S}_2$: 변조/심화 위협** | 마우스 포인터가 영역 위에 머무르는 동안 (Hover Hold). 노이즈 강도가 40%까지 증가하며, 해당 요소의 주요 키워드 일부 글자가 일시적으로 무작위 문자열(Random Hex Code)로 대체됨. | **(Interruption)**: Hover Hold. 마우스 움직임에 반응하여 변조되는 픽셀 블록의 크기가 커짐 (Scale up). 이 상태가 유지되면, 컴포넌트 가장자리를 따라 짧고 날카로운 '시스템 오류 경고음'이 반복 재생됨. | **최대 $E_d$ 유발.** 사용자가 신뢰하던 정보 자체가 일시적으로 오염되는 경험을 제공하여, 정보를 재확인하고 싶게 만듦(MVP 접근 강제). |

---

### ⚠️ 3. POPUP: 세션/프로토콜 경고창 '강제 인터럽션 (Forced Interruption)'
*   **목적:** 사용자가 콘텐츠 소비에 몰입하여 심리적으로 가장 편안한 순간(Flow State)을 인위적으로 강제로 중단시키고, 외부 시스템의 문제로 위기감을 조성.
*   **트리거:** 특정 페이지 스크롤 깊이 도달 또는 CTA 직전 (Timing: 사용자가 'Aha!' 모멘트를 경험할 것으로 예상되는 지점).

| 상태 (State) | 시각적 스펙 (Visual Spec) | 인터랙션 로직 (Logic & Timing) | $E_d$ 효과 |
| :--- | :--- | :--- | :--- |
| **$\text{S}_0$: 기본 상태** | 화면 전체는 콘텐츠에 집중되어 있음. 경고창은 완전히 비활성화된 어두운 배경 오버레이(Overlay)로 대기. | 로직: 스크롤 위치($Y$축)가 특정 임계값 $Y_{critical}$ 에 도달할 때까지 아무런 변화 없음. | 사용자 몰입 상태 (Flow State). 심리적 안도감 제공. |
| **$\text{S}_1$: 경고 발현/시스템 오류** | 배경에 검은색 오버레이가 갑자기 등장하며(Opacity: 0 $\to$ 95%), 화면 전체가 미세하게 흔들림(Camera Shake). 중앙에 'SYSTEM WARNING' 배너가 글리치 효과와 함께 나타남. | **(Transition)**: $Y \ge Y_{critical}$. 오버레이 진입과 동시에, 배경 사운드 트랙이 갑작스럽게 컷되고 (Hard Cut), `삐-익!` 하는 높은 주파수의 시스템 경고음(`Sine Sweep`)이 재생됨. | '지금 보고 있는 것이 오류가 아닐까?'라는 근본적인 의문을 제기하며 주의를 강제로 분산시킴. |
| **$\text{S}_2$: 결함 자각/강제 종료** | 'SYSTEM WARNING' 배너 아래에 핵심 경고 메시지 (예: "데이터 무결성 위협 감지. 즉시 진단 필요.")가 글리치 타이포그래피로 반복 출력됨. 화면의 모든 요소(이미지, 텍스트)가 일제히 사이언 블루/빨간색으로 깜빡거림. | **(Interruption)**: 경고 메시지가 최고조에 달할 때 (Duration: 2초). 배경 오버레이를 완전히 제거하지 않고, 대신 중앙 상단에 'SESSION DATA CORRUPT'라는 문구가 작게, 그러나 지속적으로 글리치하며 노출됨. 이 상태는 CTA 영역을 가리고 있어야 함. | **최대 $E_d$ 유발.** 사용자가 아무리 노력해도 시스템적 결함이 존재함을 시각/청각적으로 증명하여, '자가진단'이라는 외부 도구에 의존하게 만듦. |
