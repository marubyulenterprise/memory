## ⚙️ ASV 진단 전환점 시각적 메시지 모듈 와이어프레임 & 스펙 정의서

본 와이어프레임은 Writer가 설정한 '공포 유발 $\to$ 수치화된 불안감'의 심리적 흐름을 물리적인 UI/UX 단계로 변환하는 설계도입니다. 단순 이미지가 아닌, **애니메이션 로직과 데이터 연동 스펙**을 포함하여 개발팀이 즉시 구현할 수 있도록 구성했습니다.

---

### 🌐 Module 1: [Pre-ASV] 구조적 취약성 경고 모듈 (The Structural Warning)
**배치 시점:** 고객이 "문제의 존재"를 인식하는 순간 (헤드라인/도입부 완료 후, ASV 점수 측정 버튼 직전).
**목표:** '막연한 의문'을 '객관적인 위험'으로 승격시키는 단계. 시스템 오류가 임박했음을 시각적으로 경고합니다.

#### 📐 와이어프레임 스펙 (System Overlay)
*   **크기:** 전체 화면 오버레이 (Full-screen, 100% width/height).
*   **배경:** Deep Navy (#0A1931)에 미세한 그리드 패턴(Cyan Blue, opacity 5%)을 깔아 시스템적 느낌 부여.
*   **핵심 요소:** **[SYSTEM ALERT]** 배지와 불안정하게 작동하는 게이지 바.

#### ✨ 애니메이션 및 인터랙션 로직 (Developer Guideline)
1.  **진입 효과:** 화면이 갑자기 미세한 노이즈(Noise Filter, 0.5초)와 함께 어두워짐. 배경 그리드가 잠시 빠르게 깜빡이는 듯한 **'스캔라인 글리치'** 효과 적용.
2.  **텍스트 등장:** `[SYSTEM ALERT]` 문구가 중앙 상단에 빨간색 경고등이 점멸하듯 나타남 (Critical Red, 1초 간격).
3.  **핵심 메시지 출력:** "데이터 기반의 진단이 필요합니다." 등의 카피가 **글리치 효과(Glitch Effect)**를 입으며 타이핑되듯이 등장.
4.  **게이지 바 애니메이션:** '현재 구조적 안전성'을 나타내는 게이지 바가 0%에서 시작하여 임의로 높은 수치를 가리킨 후, 갑자기 **불안정하게 출렁이며 (Jittering)** 최종적으로 낮은 레벨(예: 45%)에 고착됨.
    *   *(기술 스펙):* 게이지 바의 색상 변화는 정상 범위(Cyan Blue) $\to$ 경고 범위(Yellow) $\to$ **위험 범위(Critical Red)**로 점진적이어야 함.

---

### 🌐 Module 2: [Post-ASV] Critical State 폭로 모듈 (The Data Shockwave)
**배치 시점:** ASV Score 진단 API 호출 직후, 최종 점수가 화면에 출력되는 순간.
**목표:** 고객에게 '내가 생각했던 것보다 훨씬 위험하다'는 충격과 공포를 최대로 주입하고, 즉각적인 해결책(Blueprint) 외에는 대안이 없음을 각인시킵니다.

#### 📐 와이어프레임 스펙 (Focus on the Number)
*   **크기:** 전체 화면 오버레이 (Full-screen).
*   **배경:** Deep Navy 배경 위에 **시스템 오류를 상징하는 노이즈 필터와 빨간색 경고선(Critical Red)**을 격자 형태로 덧씌움.
*   **핵심 요소:** 중앙에 크게 표시되는 **ASV Score (가변 값)**과 그 아래의 충격적인 서브 카피.

#### ✨ 애니메이션 및 인터랙션 로직 (API Data 연동 시뮬레이션)
1.  **진입 효과:** 화면이 암전되고, 주변에서 전기적 잡음(Static Noise) 사운드와 함께 **'SYSTEM ERROR: DATA CORRUPTION'** 같은 텍스트가 글리치하며 스크롤됨.
2.  **점수 카운트다운 (API 연동):** ASV 점수가 단순히 '나타나는 것'이 아니라, 마치 시스템이 데이터를 분석하는 것처럼 **숫자가 빠르게 깜빡이며 (Rapid Flashing)** 최종 값에 수렴해야 합니다.
    *   *(예시):* 3... 4... 5... $\to$ **67%**
3.  **Critical Red 하이라이트:** 점수와 '위험'을 의미하는 키워드(ASV Score, Critical State 등)에만 Critical Red를 사용하여 시각적 압박감을 극대화합니다.
4.  **충격 메시지 출력:** 최종 점수가 노출된 직후, 서브 카피("당신의 구조는 비상 상태입니다.")가 글리치 효과와 함께 **강하게 진동하며 (Vibration)** 화면을 채웁니다.
