### 2. 비주얼 디자인 시스템 상세 스펙

#### **① 컬러 팔레트 (Color Code)**
| 역할 | 이름 | Hex Code | 사용 목적 |
| :--- | :--- | :--- | :--- |
| Primary Background | Dark Abyss | `#030A1C` (Deep Navy/Black) | 기본 배경색. 모든 글리치와 대비를 극대화하여 깊은 심해 같은 느낌 부여. |
| Accent Color 1 | Warning Glitch | `#FF6B6B` (Bright Red) | '위험', '실패', '경고' 등 최악의 상황을 알릴 때 사용. 타이머, 경고 메시지 하이라이트. |
| Accent Color 2 | System Blue | `#00FFFF` (Cyan Blue/Neon) | 시스템적이고 전문적인 정보(코드, 흐름도, 성공/진단 데이터). 가장 '기술적'인 느낌을 담당. |
| Warning Text | Alert Yellow | `#FFD700` (Gold/Yellow) | $E_d$ 스코어 수치나 중요 알림에 사용. 시선을 즉각적으로 끄는 역할을 한다. |

#### **② 타이포그래피 및 계층 구조 (Typography)**
*   **Primary Font:** 'Orbitron' 또는 유사한 산세리프/디지털 느낌의 모노스페이스 폰트. (기술적, 시스템적인 권위 부여)

#### **③ 핵심 애니메이션/인터랙션 로직 (The $E_d$ Engine)**

| 요소 | 상세 스펙 | 발생 트리거 | 목적 |
| :--- | :--- | :--- | :--- |
| **A. 글리치 오버레이** | 배경 전체에 무작위로 1~3프레임 간격으로 가로 방향의 색상 왜곡(Horizontal Displacement)과 노이즈 패턴을 주기적으로 삽입. (CSS Filter: `hue-rotate` 및 `translate`) | 페이지 로드 시점부터 지속. | 안정감을 박탈하고, 시스템 자체가 불안정하다는 느낌 부여. |
| **B. $E_d$ 스코어 바** | [0% $\rightarrow$ 100%] 형태로 표시되는 게이지. 초기 값은 '낮음'으로 설정 후, 페이지 로드와 함께 강제로 빨간색 영역(High Risk)까지 애니메이션 상승. | Page Load / Scroll Down (섹션 B 진입 시). | 사용자가 자신의 결함을 수치로 자각하게 만든다. |
| **C. 카운트다운 타이머** | 굵은 글씨체와 `System Blue` 강조색을 사용하며, 숫자가 깜빡이는 듯한(Blinking Cursor) 효과 적용. 시간 감소 시 배경에 미세한 경고음(Ticking Clock + Low Drone) 추가. | 섹션 E 진입 직전부터 시작 (가정). | 행동의 지연이 곧 손실임을 각인시킨다. |
| **D. 에러 코드 시퀀스** | 타이머 옆에 `[E_d: 78% FAIL]`, `[ACCESS DENIED]`, `[INITIATING PROTOCOL B]`와 같은 코드가 무작위로 빠르게 출력(Typewriter Effect)되다 주기적으로 'CRITICAL' 메시지로 수렴. | 섹션 E (구매 버튼 근처). | 기술적 전문성을 과시하며, 지금 당장 이 시스템을 정상화해야 한다는 압박감을 조성한다. |
