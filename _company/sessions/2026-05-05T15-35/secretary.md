### 📋 테스트 시나리오 매트릭스 (Test Case Matrix)

| 단계 | 시나리오 목표 | 핵심 기능/로직 | 성공 조건 (Pass) | 실패 조건 (Fail) | 담당 에이전트 | 필수 산출물(검증 지점) |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **1. 공포 유발/진입** | 시청자가 ASV Score 측정의 필요성을 인지하고 자발적으로 진단 페이지에 접근한다. | **[Content $\to$ Page Transition]** - 콘텐츠 내 결함 폭로(Glitch, Critical Red) 연출이 명확하게 CTA를 유도해야 함. | 1. 영상/숏폼 끝에서 ASV 측정 필요성이 시각적/청각적으로 강제 인지됨.<br>2. 클릭 유도 버튼(CTA)의 트래킹 및 랜딩 페이지가 정상 호출됨. | 1. 콘텐츠 메시지와 CTA 사이에 괴리감 발생 (Lack of Urgency).<br>2. CTA 클릭 시 에러 화면이 뜨거나, 로직 없이 일반적인 소개 페이지로 이동함. | Writer / Designer | [영상/숏폼] 클립 V3.0 + [랜딩] ASV 점수 입력 UI 프로토타입 |
| **2. ASV 점수 측정** | 사용자가 개인화된 데이터를 입력하고, 즉각적으로 ‘측정 가능한 공포(LMI)’를 경험한다. | **[Input $\to$ Measurement]** - 사용자 입력 데이터가 실시간으로 '손실 공포' 지표와 연결되어 점수가 계산되고 시각화됨. | 1. 사용자가 데이터를 입력할 때마다 ASV Score 그래프가 유기적으로 하락함.<br>2. 점수 측정 과정 중 로딩/계산 시간이 *불안감*을 증폭시키는 효과를 내야 함 (의도적 지연).<br>3. 계산 결과(점수)와 함께 구체적인 '결함 포인트'가 텍스트로 노출됨. | 1. 데이터 입력 오류 시 명확한 피드백이 제공되지 않음.<br>2. 점수 측정 로직이 단순 산술 연산으로 느껴져 공포감이 부족함 (너무 쉬움).<br>3. 점수 변화에 대한 설명이 추상적이어서 사용자가 위기감을 느끼지 못함. | Developer / Designer | [API] LMI 계산 API 테스트 코드 + [UI/UX] 점수 하락 애니메이션 시퀀스 |
| **3. Critical State 진입** | ASV Score가 특정 임계점(Critical Threshold) 이하로 떨어질 때, 심리적 압박이 최고조에 달한다. | **[Fear Amplification $\to$ Problem Definition]** - 시스템 아키텍처의 근본적인 결함(ASV Gap)을 폭로하고 해결책 없이는 생존 불가임을 주입한다. | 1. UI/UX 전체가 'Critical Red' 톤으로 전환되며, 글리치 효과와 경고음이 최대화됨.<br>2. 시스템적 문제의 원인이 *사용자 본인의 부주의* 또는 *정보 격차* 때문이라는 논리가 명확하게 제시됨.<br>3. 이 단계에서 단순한 '솔루션' 언급 대신, **'필수 장치(Blueprint)'**가 유일한 답으로만 인식되게 함. | 1. Critical State 진입 시의 비주얼 임팩트가 약함 (너무 평범하거나, 너무 과도해서 공포를 상실함).<br>2. 시스템적 결함 폭로 후 해결책에 대한 언급이 모호하고, '나중에'라는 느낌을 줌. | Designer / Writer | [Design] Critical State 전환 애니메이션/카피 가이드라인 + [Copy] 위기감 증폭 스크립트 V4.0 |
| **4. 리드 마그넷 확보** | 공포와 불안이 최고조에 달한 시점에, 다음 단계 행동을 유도하여 정보 포획(Lead Capture)을 완료한다. | **[Capture $\to$ Next Action]** - '무료 진단/워크숍 신청' 등 구체적이고 즉각적인 후속 조치로의 흐름이 설계된다. | 1. 사용자가 스스로 문제를 해결할 수 없다는 확신(Desperation)을 느낀 상태에서, CTA가 제시됨.<br>2. 리드 마그넷 신청 절차는 간편하며 (최소 정보만 요구), 성공적으로 이메일/전화번호를 확보함.<br>3. 획득된 정보에 대한 '감사 메시지'와 함께 다음 단계 학습 로드맵이 즉시 발송됨. | 1. CTA가 너무 약하거나, 사용자가 고민할 여지를 남겨둠 (구매 의사결정 지연).<br>2. 리드 마그넷의 가치가 낮아 보여서(Low Value), 정보 제공에 대한 동기 부여가 부족함. | Developer / Secretary | [Dev] 캡처 폼 API 연동 테스트 + [Secretary] 후속 이메일/자동화 워크플로우 초안 |
