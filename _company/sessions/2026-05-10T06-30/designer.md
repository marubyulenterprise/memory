## 📐 Anomaly Signal V2.0 컴포넌트 키트 스펙 시트
*(대상 개발팀: Developer / 목표 환경: Mobile Web First, High Contrast)*

**[디자인 컨셉]**
'시스템 오류 경고 (System Failure Alert)'의 심미적 표현을 극대화합니다. 색상 코드는 Deep Navy와 Cyan Blue를 기본으로 하며, 위험 신호는 고대비 Red/Orange 계열로 강조합니다. 모든 컴포넌트는 그리드 기반으로 모듈화됩니다.

---

### 1️⃣ [필수 요소] Loss Index 위젯 (Loss Visualization Widget)
*   **목적:** 추상적인 '손실 공포'를 시각화된, 전문적인 수치로 제시하여 구매 긴급성을 최고조로 올립니다.
*   **모바일 스펙:** 320px 폭 기준 최적화.

| 요소 | 디자인/스펙 상세 (Figma Layer Name) | 색상 코드 (HEX) / 애니메이션 지침 | 인터랙티브 가이드 (Developer Note) |
| :--- | :--- | :--- | :--- |
| **메인 게이지 바** | 직사각형 그래프 형태. 현재 인덱스 값을 시각적 높이로 표현. | 배경: `#1A237E` (Deep Navy). 위험 구간: `#D32F2F` (Danger Red). | **[애니메이션]** 페이지 로드 후, 0%에서 시작하여 1초에 걸쳐 현재 Loss Index 값까지 부드럽게 상승(Smooth Rise)해야 함. |
| **Loss Score 숫자** | 위젯 중앙 상단에 가장 크게 배치되는 수치 (예: **-27%**) | 색상: `#FF5252` (Alert Red). 폰트 크기: `3rem`. | **[애니메이션]** 게이지가 완성될 때, 이 숫자가 '카운트업(Count Up)' 효과로 도달하는 것처럼 깜빡이며 등장. |
| **추이 그래프 라인** | 가상의 시간 흐름을 따라 변동성을 보여주는 라인 차트 (파형). | 색상: `#4DD0E1` (Cyan Blue). 굵기: `2px`. | **[애니메이션]** 게이지 상승 애니메이션과 동시에, 이 파형이 '데이터 플로우(Data Flow)'처럼 왼쪽에서 오른쪽으로 흐르며 그려지도록 구현. |
| **라벨링 박스** | "Anomaly Signal V2.0 / 누적 기회비용 손실 지수" | 배경: 투명. 텍스트: `#B0BEC5` (Light Gray). | 정적인 정보 전달 영역. 위젯 자체의 전문성을 보조. |

### 2️⃣ [필수 요소] 경고 메시지 배너 (Critical Warning Banner)
*   **목적:** CTA 버튼 바로 상단/하단에 배치되어, 최종 구매 결정을 앞둔 순간 시스템적으로 개입하여 불안감을 극대화합니다.
*   **모바일 스펙:** 전체 폭 100%. 높이: 최소 64px.

| 요소 | 디자인/스펙 상세 (Figma Layer Name) | 색상 코드 (HEX) / 애니메이션 지침 | 인터랙티브 가이드 (Developer Note) |
| :--- | :--- | :--- | :--- |
| **배경** | 고대비한 어두운 배경. 경고의 느낌을 주는 질감 추가 (Digital Glitch effect). | 색상: `#B71C1C` (Dark Red/Maroon). | **[애니메이션]** 이 배너는 페이지 전체에 걸쳐 미세하고 규칙적인 '깜빡임(Subtle Flicker)' 애니메이션이 적용되어야 함. (시스템 경고의 시각화) |
| **메시지 텍스트** | "⚠️ 즉시 진단 필요: 현재 시스템은 위험 임계점에 도달했습니다." | 색상: `#FFFDE7` (Off-White). 폰트: Bold, 대문자 권장. | **[애니메이션]** 메시지가 나타날 때 '글리치(Glitch)' 효과와 함께 타이핑되듯 등장해야 함. |
| **강조 아이콘** | 경고 트라이앵글 (⚠️) 및 시스템 오류 코드 (`ERR:`) 배치. | 색상: `#FFC107` (Amber Yellow). 크기: 24px. | **[애니메이션]** 배너가 활성화되면, 이 아이콘들이 주기적으로 미세하게 깜빡이거나(Blink) 떨리는 효과를 주어 지속적인 주의 환기를 유도해야 함. |

### 3️⃣ [지원 요소] 구조적 결함 유형 아이콘 세트 (Structural Defect Icons)
*   **목적:** Basic, Full, Prime 각 플랜의 가치를 추상적이고 권위 있게 상징합니다. 단순한 '개선'이 아닌 '구조적 진단'을 받았다는 느낌을 줍니다.
*   **스펙 스타일:** 사이언 블루와 그리드 패턴 기반의 모던하고 테크니컬한 라인 아트(Line Art) 스타일로 통일.

| 결함 유형 (Plan Level) | 아이콘 컨셉 및 의미 부여 | 색상 코드 (HEX) / 사용 가이드 | 활용 예시 문구 매칭 |
| :--- | :--- | :--- | :--- |
| **Basic Defect Scan** | 🔍 **(Micro Scope/Scanner)**: 표면적이고 작은 오점을 찾아내는 시각화. | Cyan Blue (`#03A9F4`). 라인 두께: 2px. | "사소한 결함 포착" (Misalignment Point) |
| **Full Blueprint Diagnosis** | 🏗️ **(Blueprint/Structure)**: 전체적인 설계도와 구조적 흐름을 파악하는 시각화. | Royal Blue (`#3F51B5`). 라인 두께: 2.5px. | "근본 원인 제거" (Structural Weakness) |
| **Prime Resilience Package** | 🛡️ **(Shield/Core System)**: 시스템 전체를 보호하고 복원하는 핵심 방어막 시각화. | Deep Navy (`#1A237E`). 라인 두께: 3px. | "최대 복원력 확보" (Resilience & Core System) |
