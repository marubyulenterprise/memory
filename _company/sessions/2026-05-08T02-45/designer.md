## 🛠️ Loss & Alert Design System Kit (v1.0)
이 키트는 Marubyul의 핵심 가치인 '시스템적 위협과 손실 공포($X$)'를 시각화하고, 사용자에게 즉시 행동을 강제하는 데 필요한 세 가지 필수 컴포넌트로 구성되었습니다.

---

### 🔴 [Module 1] 기하급수적 손실 측정 배경 (The Loss Meter Background)

**목표:** 사용자가 화면 전체에서 지속적으로 '손실'을 인지하고, 시간 경과에 따른 위협감을 느끼게 합니다.
**기술 사양:** CSS 애니메이션 및 Figma 컴포넌트 레이어 구조 정의.

#### 1-1. 시각적 요소 (Visual Elements)
*   **메인 카운터 영역:** 손실액($X$)을 가장 크게 표시하는 중앙 집중식 공간.
    *   **폰트:** Pretendard Black (가장 높은 가독성과 위압감).
    *   **색상:** #FF3B30 (경고 레드) / 현재 값: 0원 $\to$ 최대 손실액(예: 5,000만원)까지 증가.
*   **배경 루프 패턴:** 데이터 노이즈와 글리치 효과가 결합된 은하수 같은 불안정성을 표현합니다.
    *   **색상 팔레트 (Deep Tech):**
        *   `#0A192F` (메인 배경 - Deep Navy)
        *   `#64FFDA` (액센트/데이터 흐름 - Cyan Blue)
        *   `#FF3B30` (위협 강조 - Critical Red)

#### 1-2. 구현 지침 (Implementation Guide)
| 요소 | 사양 / 애니메이션 타입 | CSS/Figma 가이드라인 |
| :--- | :--- | :--- |
| **글리치 레이어** | `background-image`를 활용한 노이즈 패턴 + 주기적 스크롤 오프셋. | `@keyframes glitch { 0%, 100% { transform: translate(0); } 50% { transform: translate(-2px, 2px) skewX(1deg); } }` (반복 적용) |
| **손실 흐름** | `#64FFDA` 색상의 작은 점들(Particle)이 무작위로 하단에서 상단으로 빠르게 이동하며 데이터 플로우를 시각화. | `animation: particle-flow 5s linear infinite;` (속도 조절 가능) |
| **손실 카운터** | 숫자가 일반적인 증가가 아닌, 마치 시스템 오차처럼 불규칙하고 폭발적으로 수치 업데이트되는 효과(Counter Up/Down). | JavaScript 로직 필수. `setInterval()`을 사용하여 손실액 값을 갱신하며, 애니메이션 프레임 전환 시 글리치 효과를 짧게 삽입 (0.1초). |

### 🚨 [Module 2] 임계치 초과 경고창 (Critical Red Pop-up Modal)

**목표:** 사용자의 주의력을 강제로 포획하고, '지금 당장 조치가 필요함'을 시스템적 위협으로 각인시킵니다.
**기술 사양:** 모달(Modal) 컴포넌트 및 인터랙티브 가이드라인.

#### 2-1. 디자인 구조 (Structure)
*   **표시 조건:** 손실액($X$)이 미리 설정된 임계치(Threshold)를 초과했을 때만 작동합니다.
*   **위상 변화:** `[Inactive] $\to$ [Warning: Yellow/Orange] $\to$ [Critical Red]`

#### 2-2. 시각적 사양 (Visual Specs)
| 항목 | Critical State (최고 위협) | 일반 경고 상태 (주의 필요) | 인터랙션 가이드라인 |
| :--- | :--- | :--- | :--- |
| **배경 오버레이** | `#CC0000` (진한 카민 레드, 90% 투명도) | `#FFC107` (강렬한 경고 오렌지, 70% 투명도) | 화면 전체에 부드러운 페이드 인/아웃 애니메이션 적용. |
| **핵심 메시지** | "⚠️ 시스템 오류 발생! [손실액] 임계치 초과." | "🚨 위험 감지: 데이터 흐름 불안정." | 폰트는 경고문이 나타나는 순간 `Scale Up` 효과를 주어 강제 주목 유도. |
| **세부 정보** | *지금 행동하지 않을 경우 발생 예상 추가 손실액:* $\text{X}만원$ | *권장 조치:* 빠른 검토가 필요합니다. | 이 부분의 텍스트는 깜빡이는(Blinking) 커서 효과를 적용하여 즉각적인 정보를 전달해야 합니다. |
| **CTA 버튼** | **[시스템 복구 및 생존 확보]** (레드 아웃라인 필수) | **[자세히 알아보기]** (오렌지 배경) | CTA는 모달의 중앙 하단에 고정 배치되며, 클릭 시 Red Alert 상태가 해제되는 경험을 제공해야 합니다. |

### 🚀 [Module 3] 긴급 행동 유도 버튼 세트 (Urgent CTA Module Set)

**목표:** 단순 구매를 '시스템적 위협으로부터의 탈출' 또는 '생존 본능에 따른 필수 보험료 납부'로 포지셔닝합니다.
**기술 사양:** 모듈형 컴포넌트와 상태별(State-based) 디자인 정의.

#### 3-1. 버튼 세트 구성 (Components & States)
| 이름 | 용도 및 위협 수준 | 기본 색상 코드 (HEX) | 호버/활성화 시 변화 | 크기 비율 (Width:Height) |
| :--- | :--- | :--- | :--- | :--- |
| **Critical CTA** | 시스템 복구, 생존 본능 기반 필수 조치 (최고 위협) | `#FF3B30` (Red Alert) | 1. 배경이 더 진한 레드(`#CC0000`)로 변화하며 2. `Scale Up` 효과를 주어 클릭감을 극대화. | 16:4 (가장 넓게, 가장 긴급하게) |
| **Urgent CTA** | 위기 경고 해소, 즉시 검토 권유 (중위협) | `#FF8C00` (강렬한 오렌지) | 배경이 약간 어두워지고(`#CC7700`) 그림자 효과(Box Shadow)를 추가하여 입체감을 부여. | 12:3 (표준 CTA 크기) |
| **Secondary CTA** | 부가 정보 확인, 다음 단계 안내 (저위협/정보 제공) | `#64FFDA` (Cyan Blue) | 배경색을 유지하며 테두리만 두껍게(`border-width: 2px`) 강조. | 10:3 (보조적인 역할 명확화) |

#### 3-2. CTA 카피 가이드라인
*   **지양할 문구:** 구매하기, 더 알아보기, 시작하기
*   **강제 적용해야 할 문구:**
    *   `[시스템 복구/위기 해소]`: (가장 강력함)
    *   `[손실액 $X$를 막을 수 있는 유일한 방법]`: (직접적인 위협 강조)
    *   `[생존 본능 기반, 즉시 보험료 납부]` (가장 포지셔닝된 문구)
