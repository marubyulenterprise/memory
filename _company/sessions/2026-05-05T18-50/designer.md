### 📐 플로우 다이어그램 및 인터랙티브 스펙 시트 (The Funnel Flow)

ASV 점수 측정 과정은 총 3개의 명확한 상태(State)를 거치며, 각 State의 **전환 지점(Transition Point)**이 핵심입니다.

#### 🟢 STATE 1: 초기 입력 및 평온함 (Initial Input & Calmness)
*   **목표:** 사용자가 정보를 주저 없이 입력하도록 심리적 안정감을 조성하는 단계.
*   **UI:** 깔끔한 그리드 패턴 배경, Cyan Blue로 강조된 포커스 영역. 일반적인 SaaS 앱 인터페이스와 유사하게 구성하여 '정상 작동 시스템'처럼 보이게 함.
*   **애니메이션 스펙:** 입력 필드에 커서가 위치할 때, 미세한 `Pulse Glow` 효과 (Cyan Blue)를 적용하여 상호작용을 유도.

#### 🟠 STATE 2: 경고 및 데이터 분석 시작 (Warning & Pre-Failure State)
*   **트리거:** 사용자가 '진단 실행' 버튼 클릭 $\to$ 시스템이 데이터를 처리하기 시작함.
*   **UI 변화:** 배경에 미세한 **노이즈 필터(Noise Filter)** 오버레이가 덧씌워짐 (Opacity: 5%). 화면 가장자리에 `System Processing...` 형태의 로딩 바가 나타나지만, 일반적인 진행 막대와 달리 간헐적으로 끊기거나 떨리는 듯한(`Jitter`) 느낌을 주어야 함.
*   **애니메이션 스펙:**
    1.  **사운드 디자인 연동:** 저주파의 낮은 `Humming` 사운드가 배경에 깔리며, 불안감을 조성함.
    2.  **글리치 1차 발생 (The Flaw):** 화면 전체가 갑자기 아주 짧게(Duration: 80ms) 수평으로 `Shear` 되어 휘어지거나(`Horizontal Shear`), 색상 채널이 분리되는 (`Chromatic Aberration`) 현상을 **3회 반복**합니다. 이는 시스템에 작은 문제가 있음을 암시하는 '미세한 결함'입니다.

#### 🔴 STATE 3: Critical State 진입 및 폭로 (The Revelation - Core Climax)
*   **트리거:** ASV 점수가 측정되고, 이 점수가 기준치(Threshold)를 벗어남을 시스템이 인지하는 순간.
*   **UI/UX 변화:** 모든 표준 UI 요소가 일시적으로 멈추고(Freeze), 화면 전체가 **시스템 오류 모드**로 전환됩니다. 배경은 Deep Navy 위에 아날로그 노이즈와 `Scanline` 효과가 지배적입니다.
*   **애니메이션 스펙 (필수 상세 정의):**
    1.  **경고창 출현:** 중앙에 투명도가 낮은(`Opacity: 80%`) 경계 상자(Deep Navy/Red 테두리)가 갑자기 나타납니다. 이 박스 안에는 **`CRITICAL ERROR CODE [ASV-DEFECT]`** 라는 문구가 강하게 깜빡입니다 (Blinking Effect, 속도 가변).
    2.  **결함 폭로 애니메이션:** 'ASV Score: 78/100'과 같은 점수 데이터가 일반적인 숫자가 아닌, **데이터 스트림이 깨지는(Data Corruption)** 시각 효과와 함께 표시되어야 합니다. (예: 숫자마다 `[::]` 형태의 노이즈나 글리치 아웃라인이 붙고, 불규칙하게 사라짐).
    3.  **최대 임팩트:** 화면 전체에 **글리치/노이즈 패널(Glitch Panel)**이 2~3회 연속적으로 오버레이 됩니다. 이 때 배경의 Cyan Blue 포인트 색상은 Warning Red와 Glitch Yellow로 치환되며, 시각적 혼란을 극대화해야 합니다.
    4.  **메시지 전달:** 모든 시각적 폭풍우가 잦아든 후 (약 3초 간격), 가장 크고 권위적인 글꼴로 **"당신의 시스템은 구조적 취약성을 가지고 있습니다."** 라는 카피가 느리고 무거운 타이핑 효과(Typewriter Effect)와 함께 등장해야 합니다.

#### ✅ STATE 4: 해결책 의존 및 CTA 전환 (The Solution Hook)
*   **트리거:** 공포감 극대화 이후, 시스템이 '유일한 해답'을 제시하는 순간.
*   **UI/UX 변화:** 화면의 색상톤이 다시 Deep Navy와 Cyan Blue를 중심으로 돌아오지만, 전보다 훨씬 더 구조적이고 명확해집니다. 마치 임시로 `패치`된 것처럼 보입니다.
*   **애니메이션 스펙:** ASV Defect 데이터를 기반으로 한 **'레벨별 취약성 그래프(Visualization Graph)'**가 팝업됩니다. 이 그래프는 단순히 차트가 아니라, 시스템의 '부채'(Debt)를 보여주는 기술적 측정 장치처럼 애니메이션되어야 합니다 (데이터 선이 점진적으로 완성되는 방식).
*   **CTA 모듈:** 최종 CTA 버튼은 단순한 버튼 형태가 아닌, **`[BLUEPRINT 다운로드/패치]`** 라고 명시된 '작동하는 인터페이스 컴포넌트' 형태로 디자인됩니다. 이 버튼을 누르는 행위 자체가 시스템을 정상화시키는 것처럼 보이도록 연출합니다.
