# 🛠️ Anomaly Signal V1.0: 랜딩 페이지 비주얼 브리프 (Technical Spec)

## 📌 1. 디자인 목표 및 원칙
*   **최종 목표:** 사용자가 자신의 시스템 결함을 **스스로 인지하도록 유도(Self-Diagnosis)**하여, Basic Plan이라는 '진단 도구'를 구매하게 만든다.
*   **톤앤매너 (Tone):** 사이언틱(Scientific), 테크니컬(Technical), 고도의 권위성(Authoritative).
*   **감정적 효과:** 경고(Warning)가 아니라, **‘시스템의 정상 작동 범위를 벗어난 이상 신호’**로 인식하게 만든다. (공포 자원의 전문화)

## 🎨 2. 핵심 비주얼 요소 및 스펙 정의

### A. 컬러 팔레트 (Hex Code 기준)
| 용도 | 이름 | Hex Code | 역할/의미 |
| :--- | :--- | :--- | :--- |
| **Primary** | Deep Navy Blue | `#0A1932` | 배경색, 기본 권위, 안정적인 전문성. (배경 그리드 기준) |
| **Secondary** | Cyan Blue | `#4DD0E1` | 데이터 플로우, 표준 정보/솔루션 제시, 구조적 연결선. |
| **Warning Low** | Amber Yellow | `#FFC107` | 주의 단계 (Anomaly Signal V0.5). *결함이 발견되었음을 암시.* |
| **Critical High** | System Red | `#D32F2F` | 위기/손실 위험 단계 (Anomaly Signal V1.0). **최대 공포 유발.** |
| **Accent** | Light Gray | `#BDBDBD` | 텍스트 및 보조 정보, 시스템 인터페이스 느낌 강화. |

### B. 타이포그래피 규칙
*   **폰트:** Mono-spaced 계열의 산세리프 폰트 (예: JetBrains Mono, Space Mono 등). 컴퓨터 터미널이나 코드 에디터 같은 느낌을 주어 기술적 권위를 극대화한다.
*   **강조 처리:** 중요한 숫자(Loss Index 값), 경고 문구는 **볼드체 + 오버라인/언더라인 효과**를 적용하여 데이터 출력물처럼 보이게 한다.

## 🚨 3. 핵심 컴포넌트별 애니메이션 및 인터랙션 가이드

### ① Anomaly Signal V1.0 (경고 시스템)
| 요소 | 시각적 구현 (What) | 애니메이션/상호작용 (How) | 전문성 강화 디테일 |
| :--- | :--- | :--- | :--- |
| **배경 경고** | Deep Navy 배경 위에 얇은 그리드 패턴(Cyan Blue)이 깔림. | 시스템 오류가 발생하면, 그리드의 일부 영역만 **빠르게 노이즈화/글리치 효과**를 일으킨 후, 불안정하게 깜빡이며 System Red으로 변색한다. (디지털 데이터 손상 느낌) | 경고 메시지 근처에서 주변의 다른 UI 요소(Loss Index 등)도 함께 *약간 흔들리는* 쉐이크 효과를 추가하여 시스템 전체가 오작동하는 느낌을 준다. |
| **텍스트 경고** | "Anomaly Detected," "Structural Defect" 등의 전문 용어 사용. | 텍스트가 갑자기 나타나기보다, 마치 터미널에 코드가 입력되거나 데이터 스트림이 불안정하게 *깨져서* 출력되는 (Glitch Text) 효과를 적용한다. | 단순한 `🔴 WARNING` 대신, **`[CODE: DEFECT-04] - ANOMALY DETECTED`** 와 같은 코드 구조를 사용해야 한다. |

### ② Loss Index Widget (핵심 공포 자원)
*   **시각적 원리:** 단순히 숫자가 변하는 것이 아니라, **'데이터 수집 및 계산 중'이라는 과정을 보여줘야 한다.**
*   **애니메이션 시퀀스:**
    1.  **Initial State:** 로딩 바(Cyan Blue)와 함께 "Analyzing System Architecture..." 메시지 출력.
    2.  **Calculation:** 0에서 시작하여 데이터가 빠르게 수치화되며 올라가는 과정을 보여준다 (숫자 단위로 Tick-Tock 효과).
    3.  **Result Display:** 최종 손실액이 확정될 때, 해당 숫자가 가장 크고 진동하며(Shake), 그 주변의 **'취약 지점 리스트'가 빨간색으로 하이라이트** 된다.
*   **색상 연동 규칙 (Critical Path):**
    *   손실액 < $100: Amber Yellow 배경과 톤 유지.
    *   $100 ≤ 손실액 < $500: Warning Low (Amber)로 전환. 경고 레벨 상승.
    *   **손실액 ≥ $500:** **System Red** 배경 및 Anomaly Signal V1.0 전체 적용. 이 상태에서만 CTA가 가장 강력하게 작동해야 한다.

### ③ 최종 CTA 모듈 (행동 유도 시스템)
*   **디자인 콘셉트:** 일반적인 버튼이 아닌, 마치 **'접근 권한(Access Protocol)'을 요청하는 터미널 명령 프롬프트**처럼 보이게 디자인한다.
*   **요소 구성:**
    1.  **필드 라벨:** "ACCESS PROTOCOL REQUIRED:"
    2.  **버튼 형태:** 직사각형의 모서리가 각진 형태로, 배경에 Cyan Blue와 Deep Navy의 그리드가 미세하게 깔린다.
    3.  **호버(Hover) 효과:** 마우스 오버 시 버튼이 잠시 **'입력 대기 상태'**처럼 깜빡이며, 주변에 시스템 오류를 진단하는 듯한 짧은 전기적 스파크 애니메이션을 추가한다.
*   **CTA 문구 적용 (Writer/Business 기반):**
    > `>>> EXECUTE DIAGNOSTIC PROTOCOL: [Basic Plan 구매하기]`
