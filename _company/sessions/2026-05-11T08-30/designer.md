# 🚨 Loss Index Dashboard Design System Specification V2.0

## 🎨 1. 마스터 팔레트 정의 (The Core Palette)
| 역할 | 명칭 | Hex Code | 용도 및 의미 |
| :--- | :--- | :--- | :--- |
| **Background** | 시스템 배경 | `#0A0F1C` (Deep Navy/Black) | 메인 UI 배경. 깊고 안정적인 느낌 부여. |
| **Primary Accent** | 정상 작동색 | `#00FFFF` (Cyan Blue) | 표준 정보, 성공 메시지, 기본 그리드선. 신뢰성 기반. |
| **Warning Color** | 주의 경고색 | `#FFCC00` (Amber/Yellow) | $L_{index}$ 0.3 ~ 0.5 구간. 위험 인지 시작점. |
| **Critical Color** | 임계 위협색 | `#FF4444` (Vivid Red) | $L_{index}$ 0.7 이상 구간. 즉각적 행동 요구. |
| **Text/Accent** | 강조 텍스트 | `#FFFFFF` / `#CCCCCC` | 정보 전달의 기본 톤.

## ✨ 2. 핵심 컴포넌트별 디자인 가이드라인 (3 Pillars)

### A. $L_{index}$ 게이지 (Loss Index Gauge Component)
$L_{index}$를 시각화하는 메인 대시보드 요소입니다. 단순한 바(Bar)가 아닌, 살아있는 '위협 지표'처럼 작동해야 합니다.

| 스펙 항목 | 사양 상세 내용 | 기술적 요구 사항 및 타이밍 |
| :--- | :--- | :--- |
| **형태** | 원형 게이지 (Circular Gauge)와 수직 바(Vertical Bar)의 하이브리드 구조. 중앙에 현재 $L_{index}$ 값(%)을 대문자로 표시. | React State Hook 연동 필수. 값이 변할 때마다 애니메이션 트리거. |
| **애니메이션 (값 변화)** | 1. **Transition:** 값이 변하는 순간, 기존 게이지 바가 *글리치 효과*를 동반하며 새로운 값으로 채워지는 방식(Fill-Up/Drain)을 사용. <br>2. **Timing:** `Ease-Out Cubic` 함수 적용. 총 애니메이션 시간: **400ms**. | CSS 변수 (`--lindex-value`) 활용하여 실시간 업데이트 구현. |
| **색상 로직** | - $L_{index} \le 0.3$: Primary Accent (Cyan Blue) $\to$ Warning Color (Amber). <br>- $0.3 < L_{index} < 0.7$: 경고색(Amber)에서 시작하여 위험도에 따라 **빨강으로 점진적 색상 보간** (`Interpolation`) 발생. <br>- $L_{index} \ge 0.7$: Critical Color (Vivid Red). | 값의 임계점 도달 시, 게이지 전체가 *미세한 노이즈/깜빡임(Flicker)* 효과를 추가하여 공포감 증폭. |
| **글리치 패턴** | 값이 급변할 때 (예: 0.4 $\to$ 0.8): 화면 좌우로 짧고 날카로운 수평 왜곡(`Horizontal Glitch Shift`)을 2회 삽입합니다. 각 왜곡은 **50ms 간격**, 너비는 화면의 $1\% \sim 3\%$ 범위에서 무작위하게 발생해야 합니다. |

### B. 경고 오버레이 (The Alert Overlay Module)
시스템이 구조적 결함을 인지했을 때, 전면을 가리는 모듈입니다. 가장 높은 감정적 임팩트를 주어야 합니다.

| 스펙 항목 | 사양 상세 내용 | 기술적 요구 사항 및 타이밍 |
| :--- | :--- | :--- |
| **표시 방식** | 화면 전체를 덮는 반투명 직사각형 오버레이 (Semi-transparent Rectangular Overlay). 배경은 `#0A0F1C`에 `opacity: 0.85` 적용. | 모든 콘텐츠 위에 Z-index 최상단으로 고정 배치. |
| **애니메이션 (등장)** | 경고 메시지가 등장할 때, 단순히 페이드인(Fade In) 하는 것이 아니라, 화면 가장자리에서 빠르게 *스크롤되면서 진입*하는 애니메이션을 사용합니다. <br>1. **Transition:** 좌우에서 겹쳐지며 진입 (`Sliding from Left/Right`). <br>2. **Timing:** 총 애니메이션 시간: **300ms**. | 메시지의 내용은 `Inter` 또는 `Roboto Mono`와 같은 모노폭(Monospace) 계열의 폰트를 사용하여 코드를 보는 듯한 느낌 부여. |
| **글리치 효과 (강도)** | 경고 등급에 따라 글리치 강도를 다르게 적용합니다. <br>1. **Warning:** 미세한 색상 채널 분리 노이즈 (Chromatic Aberration)만 적용. <br>2. **Critical:** 전체 텍스트가 **불규칙하게 깜빡이며(Strobe Effect)**, 주변에 짧은 `Scanline` 패턴을 오버레이합니다. 깜빡임 주기는 $100 \text{ms} \sim 200 \text{ms}$ 사이에서 무작위로 발생해야 합니다. |

### C. CTA 배너 (The Solution Funnel Banner)
공포를 인지한 사용자에게 '유일한 해결책'을 제시하는 구매 전환 유도 요소입니다. 긴장감을 해소하며 전문적인 권위를 보여줘야 합니다.

| 스펙 항목 | 사양 상세 내용 | 기술적 요구 사항 및 타이밍 |
| :--- | :--- | :--- |
| **형태** | 화면 하단에 고정되는 박스 형태 (Sticky Footer Banner). 배경색은 대비가 강한 톤(예: Deep Navy와 Cyan Blue의 조합)을 사용. | 콘텐츠 스크롤 여부와 관계없이 항상 최하단에 존재해야 함. |
| **애니메이션 (강조)** | 배너가 화면에 로드되거나, 중요한 구매 타이밍이 되었을 때, 단순히 나타나는 것이 아니라 *전기적인 충격파(Electric Pulse)*가 퍼지며 등장합니다. <br>1. **Transition:** 중앙에서 시작하여 4방향으로 파동처럼 확장 (`Ripple Effect`). <br>2. **Timing:** 총 애니메이션 시간: **500ms**. |
| **핵심 강조 (Blueprint)** | 'Blueprint 다운로드' 버튼은 단순히 클릭 가능한 버튼이 아니라, *데이터 전송을 받는 듯한* 비주얼 효과가 필수입니다. 마우스를 올릴 때(Hover), 버튼의 테두리 주변으로 Cyan Blue색 에너지 라인이 흐르면서 미세하게 펄스(Pulse)합니다. |
| **카피 강조** | CTA 문구는 "당신의 시스템을 재부팅하십시오"와 같은 해결 지향적, 명령형 어조를 사용해야 하며, 글자 간격(`Letter Spacing`)을 넓게 주어 '중요성'을 부각합니다. |
