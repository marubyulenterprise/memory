## 🔴 [최종] Critical Red Alert 비주얼 에셋 패키지 (Mockup & Spec)
CEO님의 지시에 따라, 지금까지 확정된 '손실 공포(Loss Aversion)' 테마와 시스템적 권위를 결합한, 개발 즉시 적용 가능한 최종 비주얼 컴포넌트 및 스타일 가이드라인을 제공합니다. 모든 에셋은 사용자에게 **'이것을 모르면 생존에 위협적이다'**라는 감정적 경험을 목표로 합니다.

---

### 🎨 1. 시스템 VI (Visual Identity) 표준 재정립

#### A. 컬러 팔레트 (Hex Code 기반)
| 이름 | Hex 코드 | 용도 및 의미 부여 | 비고 |
| :--- | :--- | :--- | :--- |
| **Deep Background** | `#0A132C` | 기본 웹 배경색 (암전된, 시스템의 깊은 어둠). 공포감 유발. | *Navy-Black* |
| **Primary Accent (System)** | `#00FFFF` | 정상적인 데이터 플로우, 성공적 진단 결과 표시 (기술적 신뢰). | *Cyan Blue* |
| **Secondary Warning** | `#FFCC00` | 경고 임계치 근접 (Yellow Alert). 주의 단계. | *Safety Yellow* |
| **Critical Failure Red** | `#CC0000` | 최대 위협, 손실 발생, 필수 조치 필요(Mandatory Action). | *Deep Crimson* |
| **Neutral Text/Line** | `#AAAAAA` | 보조 텍스트 및 구분선. 시스템의 차가운 느낌 유지. | |

#### B. 타이포그래피 가이드라인 (폰트명 지정)
*   **메인 헤드라인 (H1, H2):** Pretendard Bold / Impact. (굵고 단정하며, 시각적 위압감을 주는 샌세리프 계열).
    *   *활용 원칙:* 대문자 사용을 적극 권장하여 시스템 메시지처럼 보이게 한다.
*   **본문/설명:** Pretendard Regular / Light. (가독성 유지 및 전문적인 정보 전달).

### 🖥️ 2. 핵심 컴포넌트 Mockup 상세 스펙

#### A. Loss Meter Widget (손실 측정기) [Mockup]
*   **목표:** 시각적 불안정성과 손실액($X$)의 실시간 변동을 통해 구매를 강제하는 장치.
*   **레이아웃/구조:** 좌우 대칭형 게이지와 숫자 카운터를 결합한 시스템 패널 형태.
    *   **(Mockup 설명):** 전체적으로 #0A132C 배경에, 손실액의 변화가 시각적인 '데이터 플로우'처럼 느껴지도록 Cyan Blue와 Red Crimson을 사용합니다.

| 상태 (State) | 시각적 특징 (Visual Spec) | 애니메이션/트랜지션 스펙 |
| :--- | :--- | :--- |
| **1. Normal** (안정적) | 게이지 바의 70% 이상이 `#00FFFF`로 채워짐. 숫자 $X$는 작고 차분함. | 부드러운 데이터 플로우(Sine Wave) 애니메이션 적용. |
| **2. Yellow Warning** (위험 감지) | 게이지 바가 급격히 붉은색으로 변하며, `#FFCC00` 색상의 경고 패턴이 깜빡임. 숫자 $X$의 변화폭이 갑자기 커짐. | `blink-yellow` 클래스 적용 (2초 주기). 위젯 주변에 미세한 노이즈(Glitch Effect) 추가. |
| **3. Critical Red Alert** (필수 조치 필요) | 게이지 바 전체가 `#CC0000`으로 덮이고, 배경 전체에 빨간색 경고 패턴(Grid Overlap)이 오버레이됨. 위젯 주변에서 `🚨 CRITICAL FAILURE DETECTED` 문구가 깜빡임. | **강제 트랜지션:** 애니메이션을 급격히 끊기게 (Stutter/Jitter effect). 모든 요소가 3초 동안 강렬한 빨간색의 진동(Vibration) 효과를 보여줌. |

#### B. Red Alert Banner Component (경고 배너) [Mockup]
*   **목표:** 페이지 어디에 붙어도 시선을 빼앗는, '무시할 수 없는' 위협 메시지 전달.
*   **위치/크기:** 고정(Fixed Position) 헤더 또는 푸터 영역 상단에 위치. (최소 60px 높이 확보).
*   **디자인 특징:**
    1.  배경색: `#8B0000` (어두운 벽돌 레드).
    2.  시각 요소: 좌측에 **🚨 [WARNING]** 아이콘 세트 배치. 오른쪽 끝에는 'ESC' 또는 'PROTOCOL' 등의 단어를 반복하는 텍스트 애니메이션을 넣어 불안감을 조성.
*   **활용 가이드:** 이 배너는 스크롤 시에도 사라지지 않아야 하며, 사용자가 페이지를 나갈 때까지 지속적으로 위협을 상기시켜야 합니다.

### ✨ 3. 인터랙티브 요소 디자인 (Action Components)

#### A. CTA 버튼 재설계: '생존 프로토콜' 기반
*   **핵심 원칙:** 단순한 클릭 유도가 아닌, **위기에서 탈출하는 행동(Mandatory Action)**으로 프레이밍해야 합니다.
*   **버튼 디자인 (Primary):**
    *   **배경색:** `#CC0000` (Critical Red).
    *   **텍스트:** 흰색 (`#FFFFFF`).
    *   **모서리 처리:** 사각형 또는 시스템 경고 박스처럼 각진 형태로 설계하여, 유기적인 느낌을 배제합니다.
    *   **효과:** 마우스를 올리면 버튼이 미세하게 '전류가 흐르는 듯한' 글리치 효과(Glitch Effect)를 주어 즉각적인 반응성을 보여줍니다.

| 강제적 CTA 텍스트 옵션 | 사용 맥락 | 의도하는 행동 심리 |
| :--- | :--- | :--- |
| **[🔴 PROTOCOL ACTIVATE]** | 최종 결함 진단, 패키지 구매 (가장 강력) | '규칙적인 절차를 따라야 한다'는 시스템적 강제성. |
| **[🚨 ESCAPE THE LOSS]** | LP 최상단(Hero Section), 위험 회피 유도 | 위협으로부터 도망치거나 벗어나고 싶은 본능 자극. |
| **[🛡️ SECURE MY ASV REPORT]** | 구체적 산출물 구매, 보험 가입 느낌 부여 | 손실을 막기 위한 '보험'이라는 논리적 합리성 제공. |

#### B. 아이콘 셋 표준화 (Iconography)
*   **스타일:** 라인(Line Art) 기반의 모노톤 벡터 아이콘. 시스템 인터페이스에서 볼 법한, 기계적이고 차가운 느낌이 중요합니다.
*   **필수 아이콘 세트:** 경고(🚨), 데이터 플로우(➡️), 결함/구멍(❌ 또는 ➖), 보안 자물쇠(🔒).
