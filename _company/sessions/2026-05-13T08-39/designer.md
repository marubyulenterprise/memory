## 🚨 SYSTEM ALERT 스타일 비주얼 무드 보드: [E_d] 불안감 증폭 시스템
(Emotional State Design Guide)

이번 콘텐츠는 정보 전달이 아닌 '시스템적 오류의 자각'이라는 경험을 판매하는 것이 핵심입니다. 따라서 디자인은 전문적인 신뢰성(Authority)과 극한의 위협감(Urgency/Anxiety)을 동시에 연출해야 합니다. 모든 시각 요소는 마치 **사용자가 시스템 자체의 결함을 발견한 듯한** 착각을 주도록 설계되어야 합니다.

---

### 🎨 1. 컬러 팔레트 및 사용 규칙 (Color Palette & Usage Rules)

| 명칭 | Hex Code | 역할 (Role) | $E_d$ 레벨에 따른 적용 방식 |
| :---: | :---: | :---: | :---: |
| **Base Navy** (기반 어둠) | `#021B38` | 배경, 텍스트 기본 색상. 전문성과 깊은 신뢰감을 유지하는 기반. | *항상* 주된 배경색으로 사용하며, 정보의 안정적인 전달 구간에 제한적으로 적용. |
| **Cyan Blue** (시스템 강조) | `#00FFFF` | 시스템 흐름(Flow), 성공/표준 기능 강조, 하이라이트. (기술적 권위 표현) | 데이터 플로우 화살표, 표준 UI 요소의 활성화 상태, 정보가 '정상'임을 보여줄 때 사용. |
| **Alert Red** (경고/결함) | `#FF073A` | 가장 높은 $E_d$ 레벨, 오류 메시지, 긴급 CTA 버튼, 시스템 경고 문구. | **시스템의 결함을 지적할 때만 제한적으로 사용.** 붉은색과 사이렌 사운드를 동기화하여 공포감을 극대화. |
| **Glitch Magenta** (오류 색상) | `#FF07A6` | 글리치 효과, 노이즈 아티팩트, 깨지는 데이터 시퀀스 연출. | 폰트를 왜곡시키거나, 경계선에 번개 치는 듯한 잔상을 추가할 때 사용. '실패'의 미학을 담당. |

### 🖋️ 2. 타이포그래피 규칙 (Typography Rules)

**목표:** 정보의 내용보다, **이 정보를 전달하는 시스템의 오류 메시지**처럼 보이게 하는 것이 중요합니다.

| 요소 | 추천 폰트 (Fallback) | 사용 목적 | 스타일/규칙 |
| :---: | :---: | :---: | :---: |
| **헤드라인/경고문** (Title/Alert) | **Courier New / Consolas** | 시스템 경고, 제목. 기술적이고 기계적인 느낌 부여. | `ALL CAPS` 필수. 굵게(Bold). 트래킹(Letter Spacing)을 넓혀 공허하고 위협적인 느낌 극대화. |
| **본문/설명** (Body Text) | Roboto Mono / Inter | 일반 설명, 데이터 수치 나열. 간결함과 구조적 정밀성 유지. | 표준 크기 사용하되, 중요한 키워드는 `Cyan Blue`로 강조하고 모노스페이스체(Monospace)를 적용하여 '코드'처럼 보이게 함. |
| **강조/CTA** (Action Prompt) | Courier New / Consolas | "필수", "경고", "지금 즉시". 시급성과 강제성을 부여하는 문구에 사용. | `Alert Red`로 작성하고, 배경을 붉은 사각형으로 감싼 후 미세한 노이즈 효과를 추가하여 '강제 알림' 느낌 부여. |

### 🖼️ 3. 비주얼 오류 시스템 (Glitch/Error Visual System)

| 요소 | 기술적 구현 가이드라인 | 적용 목적 |
| :---: | :---: | :---: |
| **글리치 효과** | 색상 분리(Chromatic Aberration, R-G-B 3채널 분리). 노이즈 텍스처와 스캔 라인(Scan Line) 오버레이. | 시청자가 '화면 자체의 결함'을 인지하게 만듦. 가장 기본적인 애니메이션 요소로 활용. |
| **데이터 깨짐** | 특정 단어/문구가 순간적으로 `#FF07A6`과 `Alert Red` 색상으로 번쩍이거나, 글자 배열이 무작위로 흩어졌다가 복원되는 모션. | '정보의 불안정성'을 시각화하여 신뢰도를 의도적으로 하락시킴. (지식 커트오프 연출 시 활용) |
| **SYSTEM ALERT** | 전체 화면에 걸쳐 `[!]`, `ERROR:`, `WARNING:` 같은 경고 태그를 붉은색으로 오버레이하고, 깜빡이는(Blinking) 효과 적용. | 영상의 시작과 핵심 결함을 폭로하는 순간마다 사용하여 긴박감을 최고조로 끌어올림. |

### 📐 4. 필수 레이아웃 템플릿 (Core Layout Templates)

#### 🅰️ [Template A] 시스템 경고 메시지 (The High Alert Panel)
*   **목적:** 시청자의 자존감/자신감을 공격하는 순간. ($E_d$ 폭발 지점).
*   **배치:** 화면 전체를 가로지르는 반투명한 검은색 오버레이 패널.
*   **구성:**
    1.  상단 중앙: `[SYSTEM ALERT]` (Cyan Blue, 깜빡임 애니메이션).
    2.  본문: 굵고 큰 Courier New 폰트로 "YOUR CURRENT DATASET IS COMPROMISED." 와 같은 문구 배치. (Alert Red 사용)
    3.  하단 바: 남은 시간 카운트다운 타이머(Urgency Timer)와 함께 `ACCESS DIAGNOSTIC TOOL` CTA 버튼을 강제적으로 삽입.

#### 🅱️ [Template B] 시스템 흐름 다이어그램 오류화 (The Flawed Flow Diagram)
*   **목적:** '단순 프롬프트'의 한계를 설명할 때, 그 과정에 결함이 있음을 암시.
*   **배치:** 일반적인 플로우 차트 레이아웃을 따르되, 연결선(Arrow/Line)의 일부를 의도적으로 `Glitch Magenta`로 깨지게 처리하고, 파손된 부분에 'ERROR' 텍스트와 함께 노이즈 효과 삽입.
*   **강조:** 가장 중요한 결함 지점(예: Prompt $\rightarrow$ LLM Input)을 빨간색 점선(`Alert Red`)으로 감싸고 "CRITICAL FAILURE POINT" 문구를 붙여 시각적 의혹을 심어준다.

#### Ⓒ [Template C] 최종 권위 증명 (The Blueprint Unlock Reveal)
*   **목적:** 문제 제기 후, 유일한 해결책(Blueprint/Tool)의 존재를 극적으로 제시하며 구매 필요성을 만듦.
*   **배치:** 마치 비밀 파일이 해독되거나 데이터가 다운로드되는 인터페이스처럼 연출.
*   **구성:** 화면 중앙에 'Loading...'과 함께 `Cyan Blue` 그리드 패턴이 돌아가며 복잡한 코드가 빠르게 스크롤됨(Matrix Effect). 마지막 순간, 이 모든 것이 멈추고 "ACCESS GRANTED: THE BLUEPRINT"이라는 메시지와 함께 다운로드 버튼이 선명하게 나타나도록 연출.
