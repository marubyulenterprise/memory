## 🚀 다음 24시간 필수 실행 체크리스트 (Action Plan)

**최우선 목표:** Mock API가 생성하는 데이터를 **인터랙티브 프로토타입(Front-end)**으로 시각화하여, 최종적인 고객 경험을 검증한다.

### 🥇 [P1] 시스템 통합 및 테스트 환경 구축 (개발/디자인 협업 필수)
*   **목표:** ASV Score가 변할 때마다 UI가 '시스템적 결함'처럼 보이게 변화하는 인터랙티브 프로토타입 완성.
*   **필수 작업:**
    1.  **(Developer)** `server.py`의 API 스펙을 기반으로, 프런트엔드(예: Figma/React Mockup)와 연동되는 **API 테스트용 임시 환경 구축**에 집중합니다. (Mocking된 데이터가 실제 것처럼 동작하는지 확인).
    2.  **(Designer)** 개발자가 제공한 엔드포인트 데이터를 받아, 'Critical State' 진입 시 발생하는 글리치 효과(Glitch Effect)와 UI 왜곡이 **최적의 시각적 임팩트**를 가지도록 와이어프레임을 최종 점검합니다.
    3.  **(Secretary)** Developer와 Designer가 완성할 `ASV Funnel 통합 테스트 시나리오`에 따라, 모든 단계(입력 $\to$ 측정 $\to$ 결함 폭로 $\to$ 해결책 제시)를 **순차적으로 수동 검증**하고 버그 리포트를 작성합니다.

### 🥈 [P2] 콘텐츠 마스터 에셋 생산 (영상/콘텐츠 팀 실행)
*   **목표:** V3.0 Shot List와 Final Funnel Map을 기반으로, 실제 배포 가능한 영상 클립 세트 제작 착수.
*   **필수 작업:**
    1.  **(YouTube)** Mood Shot List를 바탕으로 **가장 임팩트 있는 3가지 핵심 시퀀스(Critical State 진입부 등)**에 대한 B-roll 촬영 또는 라이브러리 확보 작업을 즉시 시작합니다. (연출 가이드라인 준수 필수).
    2.  **(Writer)** Critical State 구간에서 출연자가 전달해야 할 **'구조적 취약성 폭로' 관련 스크립트**를 30초 이내의 짧은 버전으로 압축하여 재작성하고, 감정선을 강조하는 대사(Dialogue)를 추가합니다.
    3.  **(Designer)** Writer가 수정한 카피와 P1에서 확인된 최종 UI/UX 요소를 결합하여, **랜딩 페이지의 핵심 CTA 모듈**을 Figma 상에 완성합니다.
