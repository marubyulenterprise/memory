### 🚨 [핵심 산출물] Error Sequence Technical Specification Sheet (v3.0)

본 사양은 개발팀이 즉시 구현 가능한 수준의 상태 전이(State Transition), 시각적 애니메이션, 그리고 코드 레벨의 가이드라인을 포함합니다. 모든 요소는 사이언 블루/딥 네이비 기반의 전문성을 유지하되, 공포감을 증폭시키는 방향으로 설계되었습니다.

#### 1. 오류 메시지 계층 구조 (Hierarchy of Warning Codes)
오류를 단순한 실패가 아닌 '진단 가능한 단계'로 분리하여 사용자에게 위기 체감도를 부여합니다.

| 레벨 | 코드/이름 | 위험도($R$) | 시각적 목표 | 애니메이션/사운드 지침 | CTA 유도 방향 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Level 1** | `WARN_LOGIC_FLAW` (경고) | 낮음 (Low) | 정보성 왜곡. 시스템의 일부만 불안정함. | 화면 좌측 상단에 노이즈 글리치 발생. 배경 색상 미세하게 변동(Cyan -> Dark Blue). 사운드: 낮은 톤의 반복적인 '삑' 소리. | **"결함을 자가진단 해보세요."** (좌측 하단 버튼) |
| **Level 2** | `CRIT_DATA_INTEGRITY` (심각) | 중간 (Medium) | 데이터 흐름 단절 발생. 정보 신뢰도 하락. | 화면 중앙에 '데이터 파편화(Data Fragmentation)' 시퀀스 재생. 글자가 깨지며 사라지는 애니메이션 필수. 배경 전체 노이즈 증가 및 깜빡임 효과 적용. 사운드: 멈칫거리는 전자기기 오작동음. | **"진단 장치에서 원인을 분석하세요."** (중앙 메인 버튼) |
| **Level 3** | `FATAL_SYSTEM_ERROR` (치명) | 높음 (High) | 시스템 전체의 논리적 결함 강제 노출. 사용자의 의심 극대화. | 화면이 순간적으로 '검은색 그리드'로 뒤덮이며, 중앙에 빨간 경고 코드(Hex: #FF3333)가 붉게 점멸하며 폭발하듯 나타남. 모든 표준 에셋 요소(헤더/푸터 포함)를 강제 왜곡시키는 애니메이션 적용. 사운드: 날카로운 사이렌과 함께 전원이 꺼지는 듯한 '웅-'하는 저주파 진동음. | **"🚨 당신의 시스템을 검증해야 합니다."** (가장 크게, 중앙 최상단 CTA) |

#### 2. 데이터 흐름 단절(Data Stream Disruption) 효과 사양
사용자가 가장 공포를 느낄 지점은 '흐름의 중단'입니다. 다음 시퀀스를 적용합니다.

1.  **[TRIGGER]**: 시스템이 중요한 데이터를 로드하거나 처리하려 할 때 (예: 마스터 다이어그램을 스크롤할 때).
2.  **[VISUALIZATION]**: 데이터가 마치 **디지털 파편(Digital Shard)**처럼 화면 위로 솟아오르거나, 왼쪽에서 오른쪽으로 흐르는 그리드 라인이 중간에 갑자기 끊기며 `...` 형태의 아스키 아트 오류 문자열(`????`)이 짧게 플래시됩니다.
3.  **[TECHNICAL SPEC]**: 이 과정은 일반적인 로딩 바(Loading Bar) 애니메이션을 *대체*해야 합니다. 기존 로딩 바가 채워지는 것이 아니라, **끊어진 데이터를 재조립하려는 시도처럼 보이게** 설계합니다. (애니메이션 루프: `Load -> Disruption -> Retry`)
4.  **[EFFECT]**: 이 효과를 주기적으로(예: 30초마다) 배경에 미세하게 백그라운드 노이즈로 깔아두어, 사용자 무의식중에 시스템 불안감을 느끼게 합니다.

#### 3. 최종 에셋 패키지 구성 (Developer Handoff Package Contents)
다음 요소를 포함하는 컴포넌트 라이브러리 형태로 개발팀에 제공합니다.

1.  **`Component_Error_Container`**: 모든 오류 상태를 감싸는 최상위 컨테이너. 배경 그리드 왜곡 필터와 글리치 노이즈 오버레이(Overlay) 기본값을 적용.
2.  **`Asset_Code_Display`**: 계층별 코드를 표시하는 컴포넌트. 코드명(`WARN_LOGIC_FLAW`)과 설명 텍스트의 위계적 배치 및 색상 강도를 정의 (Deep Navy 배경, Cyan Blue 글자).
3.  **`Animation_Data_Shard`**: 데이터 파편화 애니메이션을 위한 모션 그래픽(Lottie/SVG 기반) 세트. 특정 시간 간격에 맞춰 재생되도록 타이밍 스펙 포함.
4.  **`CTA_Urgency_Module`**: 모든 오류 시퀀스 하단에 배치되는 공통 CTA 모듈. 이 모듈은 단순 버튼이 아니라, **'진단 장치 접근권 확보를 위한 인터페이스'**처럼 보이게 설계해야 합니다. (버튼 대신 'ACCESS MODULE' 형태 사용)
