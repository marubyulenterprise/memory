### ⚙️ 기술적 제작 지침 및 필수 스펙 요약 (Technical Specs Sheet)

1.  **색상 팔레트 일관성:** 모든 다이어그램의 연결선과 강조 요소는 **Cyan Blue Hex Code (#00BFFF)**를 기반으로 하며, 오류 경고는 **Deep Red Hex Code (#CC0000)**를 사용한다.
2.  **시각적 무게 중심:** 배경은 단순한 단색이 아닌, 미세하게 보이는 그리드 패턴(Grid Pattern Overlay)을 적용하여 전문성과 구조적인 느낌을 유지해야 한다. (최소 1% 투명도).
3.  **CTA 모듈 작동 로직:** Funnel CTA Module은 시청자가 '해결책'의 필요성을 가장 강하게 느낀 순간(약 9분 지점)에 맞춰 등장하며, 단순한 버튼 클릭 유도가 아닌, **"이 시스템 구조를 당신에게 적용할 방법이 필요하다"**라는 문구와 함께 다운로드 링크가 연동된 인터랙티브 요소로 설계해야 한다.
4.  **전환 효과(Transition):** 섹션 간 전환 시에는 절대 컷(Cut)을 사용하지 말고, **데이터 플로우처럼 연결되어 다음 주제로 흐르는 애니메이션 (Data Flow Transition)**을 사용하여 영상의 통일성과 전문성을 유지한다.
