### 📊 ASV 기반 수익화 Funnel 로직 및 가격 정책 재정의 (Developer 전달용)

CEO 지시에 따라, '측정 가능한 공포(ASV Score)'를 핵심 트리거로 사용하는 3단계 판매 논리(Funnel Logic)와 각 단계별 구체적인 KPI/데이터 수집 포인트를 정의했습니다. 이 구조는 단순한 제품 판매가 아닌, 고객의 *필수 생존 장치 구매*라는 경험을 설계하는 데 초점을 맞췄습니다.

---

#### 💡 핵심 논리: 공포 $\to$ 간극 인식 $\to$ 구원 요청 (Fear $\to$ Gap $\to$ Rescue)

| 단계 | ASV Score 구간 (트리거) | 고객 심리 상태 | 목표 감정적 경험 | 판매 목적 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 진단/후킹** | *모든 점수* | 불안감 유발, 충격, 자각 (Aha! Moment) | "이대로는 안 돼." | 리드 데이터(Email) 확보 및 권위 확립 |
| **2. 저가 솔루션 구매** | *중~저 ASV* | 절망 $\to$ 희미한 기대감 | "최소한 이것부터 막아야 해." | 초기 현금 흐름 창출 (Cash Flow), 고객 등급화(Qualification) |
| **3. 고가 시스템 구독** | *극도로 낮은 ASV* | 공포, 위기감, 결핍 (Desperation) | "이게 아니면 망한다." | 핵심 매출 발생 (MRR/LTV 극대화) |

#### 💰 단계별 상세 설계 및 개발 요구사항 정의

##### 1단계: 무료 진단 & 리드 확보 (The Hook)

*   **상품:** ASV Score 측정 서비스 (무료 체험판).
*   **목표 KPI:** 이메일 주소 입력 완료율 (Conversion Rate of Email Capture), 페이지 체류 시간.
*   **핵심 액션:** 점수 확인 직후, **'ASV 점수가 낮을수록 해결책의 필요성이 커짐'**을 강력하게 어필하며 다음 단계로 강제 유도(CTA).

| 데이터 수집 포인트 | 기능 요구사항 (Developer) | 개발 Notes / 카피라이팅 방향 |
| :--- | :--- | :--- |
| **ASV Score 측정** | 사용자 입력값 기반 점수 산출 및 시각화 (Loss Bar, Critical State UI 필수). | 점수가 낮을수록 그래프가 빨간색 경고 영역으로 급격히 진입하는 애니메이션 강조. |
| **리드 캡처 CTA** | ASV 점수 확인 직후(스크롤 하단 또는 오버레이) '다음 조치' 버튼 노출. (이메일 입력 필드). | *필수 카피:* "현재 ASV 점수는 단순 진단을 넘어선 근본적 결함이 존재함을 의미합니다. **최소한의 방어책**부터 마련해야 합니다." |
| **Funnel 전환 로직** | 1단계 완료 $\to$ 2단계(워크시트/미니 가이드) 랜딩 페이지로 자동 리다이렉션 (또는 강제 CTA 노출). | - |

##### 2단계: 저가 솔루션 구매 (The Nudge / Qualification)

*   **상품:** 'ASV 점수 개선을 위한 초급 워크시트' 또는 '시스템 오류 진단 체크리스트'.
*   **가격 정책(Pricing Tier):** **$19 - $49** (저가형, Impulse Buy 유도).
*   **목표 KPI:** 구매 전환율 (CVR), 최초 결제 고객 확보 비율.
*   **핵심 액션:** 1단계에서 느낀 공포를 '실질적으로 관리 가능한 작은 행동'으로 분산시켜 즉각적인 만족감과 성취감을 제공하고, **더 큰 문제의 존재를 암시**하며 다음 단계로 연결.

| 데이터 수집 포인트 | 기능 요구사항 (Developer) | 개발 Notes / 카피라이팅 방향 |
| :--- | :--- | :--- |
| **판매 페이지 구조** | 1. Pain Point 재강조 $\to$ 2. 저가 상품 제시 $\to$ 3. *결함의 한계* 지적 (The Gap) $\to$ 4. 고가 솔루션 언급 (Teaser). | 구매 직전에 "이 워크시트는 **증상**만 완화할 뿐, 시스템 근본 원인은 건드리지 못합니다."라는 문구를 삽입하여 불안감 유지. |
| **결제/데이터 수집** | 결제 완료 시, 다음 단계(Blueprint)에 대한 '독점적인 할인 코드' 또는 '다음 레벨 진단 기회'를 제공하며 이메일 확보 재확인. | - |

##### 3단계: 고가 시스템 구독 (The Core Value / Recurring Revenue)

*   **상품:** **Marubyul Blueprint 시스템 정기 구독권.**
*   **가격 정책(Pricing Tier):** **월 $99 ~ $199** (구독 모델 SaaS), 혹은 연간 할인가.
*   **목표 KPI:** 월간 반복 수익률 (MRR), 이탈률 감소율 (Churn Rate).
*   **핵심 액션:** 2단계에서 얻은 '불안정함'을 해결하기 위해 **지속적이고 체계적인 관리(System)**가 필요하다는 논리를 전개.

| 데이터 수집 포인트 | 기능 요구사항 (Developer) | 개발 Notes / 카피라이팅 방향 |
| :--- | :--- | :--- |
| **판매 페이지 구조** | 1. 시간 경과에 따른 ASV 점수 하락 시뮬레이션 제시 $\to$ 2. Blueprint가 제공하는 '지속적 안전장치' 목록화 (Feature) $\to$ 3. 높은 가격을 '보험료/필수 인프라 비용'으로 포장. | *핵심 카피:* "단발성 해결책은 임시방편일 뿐입니다. 시스템의 **구조적 결함**을 막기 위해서는 지속적인 모니터링과 업데이트가 필수입니다." (공포 재활용) |
| **결제/데이터 수집** | 구독 플랜 선택 시, 사용자의 목표 달성 기간(예: 3개월 후 ASV 점수 정상화 예상일)을 계산하여 제시. | 결제 페이지에 '구독 취소율 방지'를 위한 강력한 가치 제안 문구를 반복 노출해야 함. |
